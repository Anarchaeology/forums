No-Name items appearing / Buildings not being drawn
The no-name items (such as elevators in team missions not showing, other no-names in inventory) issues and buildings not being drawn on screen issue can be linked to problems with the 11.0-14.1 patch.

The patch hanging at 99% done was corrupting the resource database, and thus the no-name items and other graphic anomolies.

So if you are suffering from those errors, and remember the 99% hanging tomfoolery with the patch, you can fix this by doing the following:

1) Uninstall the game with the add/remove programs in the control panel

2) Manually delete the Anarchy Online directory

3) Reboot, and reinstall the game. Patch up using these patches (making sure the launcher isn't open when you patch- you can't patch a running program!):

ftp://download.anarchy-online.com/pa...11.0-v14.0.exe

and then

ftp://ftp.funcom.com/cd/patches/AOPatch_v14.0-v14.1.exe

That should clear up those problems.

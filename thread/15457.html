What I think would fix AO
Have no idea if it is possible from a programming standpoint, but I think the following would vastly improve the game. Comments, gripes, suggestions welcome.

1. Get rid of title caps and ip limits. Allow the player to spend as much ip as he wants in a given skill.

2. Change implants. Allow 1 implant slot available per 100pts of body developement, the first slot being free. The player decides which slot. Implant requirements would be based on the skills boosted by the clusters. Remove any and all body developement buffs and items that boost body developement. Implants would be quality neutral with only the cluster quality having any significance.

3. Implement the over equiping penalties as planned. Maybe even lower grace %.

4. Remove one of the inits (melee or physic). These should be combined.

5. Remove "fist" damage and attacks. Give martial artists a "style" weapon that they equip like an ordinary weapon that represents their ma attack. These weapons would be susceptible to duel weild requirements.

6. Adjust mobs as needed.

Okay, I was too brief. First off, let me just say that I wouldnt expect Funcom to make broad changes in the game like this, Im just throwing around ideas for a properly designed rpg system, since Funcom has no clue.

1. Why get rid of ip caps per level and title caps?
AO already has a set amount of ip given at each level, classes with different skill costs, and races with different skill costs. This is enough to create a reasonably balanced system. Imposing more restrictions than needed stifles player creativity and uniqueness. I know many of you think that this would cause min/max or bad allocation problems. Bad allocation is already taken care of with IP resetting. I will have to explain why it wont cause min/max problems in another post since it requires a lot of explanation on good rpg design, class and race balance, etc. etc.

2. Why change how implants work?
The current implant system is full of loopholes and encourages extremely twinked characters. In order to keep a level based system like AO meaningful, there has to be a reasonable range that characters fit into at their level.

3. Why have over equipping penalties?
If the system was designed properly there would be no need to have the penalties. Well its not, so you need it for the same reasons as #2.

4. Why remove one of the close combat inits?
Why have two in the first place? You dont have bow initiative and firearm initiative. Its superfluous. It has fragmented what weapons are useable by melee classes.

5. Whats this about martial arts fists and such.
Okay, this may be silly. The original thought was to allow the martial artist class to have the same access to weapon upgrades as other classes and to squash the bugs associated with martial arts, fists, weapons, etc. The server already assigns a fist weapon, I would just rather see the player have more control over this.

6. Adjust mobs again, why?
Mob xp has to be based on maximum possible skill per level of the character. This is a constant no matter how you build your toon. Again I will have to explain this further in another post for the same reasons as #1.

Or better yet, improve the current "private channel" system, allowing, say, org leaders to create and administer org related chats, with functions for adding and removing chat members, list members, add a MOTD etc...

Some of the larger orgs/guilds have several sub organizations needing their own chats, and manually inviting members to private chats all the time can be tiresome.

I know some chat bots exist, but they are not a good solution, as they :

- Are not FC endorsed
- Tie up player characters
- May cause problems on the chatserver if not properly implemented
- Are a security hazard for those using it, as they have to supply login information, which may or may not be transmitted in a secure manner.

The best, and safest solution would be for FC to implement the tools needed for org management.

Artifact Entertainment has some interesting plans around this for an upcoming game called Horizons :

http://artifact-entertainment.com/press/20020517.php

Typical tools a guild needs are ( besides a website and a forum ) :

- Guild member management tools, with export functions to generate / maintain user lists and ranks. Also functions for handling sub-organizations within the guilds.

- In-game user definable chat channels, either with member level access ( add/remove chat members ) or a chat password that can be given to those who should have access, with the ability to list people currently in the chat.

- Event planning tools, using the member list, complete with timezones, to schedule events to fit member play times as well as possible.

- "Sticky" announcements on guild chats informing people who log on about upcoming events etc.

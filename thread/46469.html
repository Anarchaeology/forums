List of Token Board / Token use Ideas..vote if you like
Ok everyone here is a list of ideas for token boards and tokens in general. Some are reused from other threads and conversations ( so I didn't think all these up ). If you like any/some/none of these ideas, feel free to post your opinions on them.

1. Terminal or NPC for trading in your token board and having X number of tokens depending on your level deducted from your token count in exchange for a new blank token board and a no drop IPR point adding idem. X could be 1-300 tokens depending.

2. Specials item terminals that have items in them that cost tokens instead of credits. This idea could expand to rare items or some boss only loot as well. The cost would have to be steep for the really rare stuff (like 600+ tokens for Grid Armor 3 or 4). These terminals could also only have "token only items" that have "tokens earned" requirements on them as wear requirements.

3. Add token requirements or tokens cost as a requirement for "cosmetic surgery"

4. Add powerful "summoned" type items that can be purchased with tokens. These items could be all sorts of things but would have timers on them that last 5-120 minutes (depending). PS - add a field in the ID panel for the item so You know how much time is left on it. These special weapons could come fully loaded but have a fixed number of uses/ammo (hence you can't reload them).

5. Add new Vehicles or Vehicle options (like pink Cars) to the system and require tokens to be used to purchase/upgrade them. Add me a Combat Pony and Ill be set!

6. Add a new Miir terminal that requires tokens and has cool "combat type cloaks" that can be worn in combat but don't give any major bonuses. Uniform coats, flashy coats, maybe ones that add small bonuses and special commissioned ones that are actually new looking AND have good ACs. (Add me the combat thong )

--There are other ideas Im sure Feel free to add them and Ill expand the list. Enjoy.

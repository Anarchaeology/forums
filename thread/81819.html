Adv run buffs
A little known fact (at least outside of the adv community it seems) is that some of the adv run buffs stack with the fixer run buff.

Free Movement will give you +100, and the Wolf line of morphs will give you from +100 to +390 to run speed, depending on which one you get.

And although I think you HAVE to go via grid for the quest, if you could find a way to go through just whompas then Parrot will give you +1300 run, +170 to evades AND make you able to fly.

How to enter Omni Ent on your own as a lvl 40 clanner:

(This should be done before the race starts.)
Grid to Harry's, pass over to 20K.
You can use the ferry that you can see from the grid term.
Beware the omni guards patrolling the ferry landing.
You might also be able to swim across, but beware the sharks.

Use the scan terminal in 20K and praise the neutrals for putting one there.
Use the wompah to Omni Ent.
There is one guard on the other side of the wompah, but he wanders around.
This is a lot safer then braving the four lvl 200 guards at the grid exit.

Whenever you need to enter Omni Entertainment again you just /terminate, runbuff and run through the wompah.

Footnote: If non-fixers try this they'd better be able to grid or they will have to run back from 20K.

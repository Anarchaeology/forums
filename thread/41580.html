Loot bag
When doing solo missions, I have to manually put a lot of loot in my main inventory view into a backpack. Usually, even if I don't loot the stims and some treatment/nano kits, I still need 2 bags to hold my loot. At mid-level and up, this can get really annoying.

Two suggestions:

1. Add a new bag item called "Loot bag" and items that are picked up (not traded) automatically go in it. If there are multiple loot bags in the player's inventory, it fills up the first one, then the next.

2. Add a new icon in the "right-click-and-hold" menu for bags that says, "mark this bag as loot bag". If the bag icon changed with overlay picture of a pick-up action icon, that would be an icing on the cake. Obviously, there should be a "mark this as a normal bag" option as well.

Anyone else for loot bags?

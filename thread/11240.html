Yes, I think there should be a method of removing nanos from both players and NPC.

Doctors have Epsilon Purge that tries to remove all harmful nanos from the target, but I'm not sure if any other class has a similar nano.

I'm going to expand on the original idea presented a bit to make these nanos more useful.

I think there should be something that also allows you to remove a reflect or damage shield (i.e. helpful nanos) from a target as well as removing harmful nanos such as roots / snares.

The nano program would be similar to a computer virus running on the targets NCU. So the proposed nano would seem suited to those classes who are good in Computer Literacy, Nano Programming or Breaking & Entering would be well suited for running these types of nanos.

The proposed nano would randomly terminate one or more running nano programs on the target. The nano programs terminated wouldn't be restricted to just "harmful" nanos. For those nanos capable of terminated more than one running nano program, only one random nano program would be removed from the target per tick.

Some harder to obtain versions (mission or trade skill only) of these nanos would only target a particular class of nano program (i.e. PSI, Medical, Space, Prot, Combat) for termination.

Of course, since the program removed is totally random, these cannot be used on other players except in PvP.


1) Higher QL version of the nano would be capable of removing higher QL programs (or could just base it off of NCU usage of the running nano)
2) Higher QL version of the nano would target higher QL programs first before targeting lower QL programs.
3) Higher QL version would have a faster tick.
4) Each tick the target has a chance to terminate the computer virus program early.
5) Nano skills needed would be Time & Space, Sensory Improvements and/or Psychological Modifications.
6) The executor would receive a message indicating what nano program (if any) was terminated on the target.
7) Cannot stack or refresh these on the target.


However, right now simply casting a DoT or DD nano on yourself is usually enough to allow you to remove a root / snare.

Top 2 problems with AO
Anarchy Online is a fine game. However if these three problems are addressed, I think it will be Much better for everyone!

#1

The inventory system MUST be improved. Plain and simple.
-shuffling inventories and banks
-infinite supplies of totally useless items
-drag one at a time clunky system
**These keep me digging into my packs for faaar to much time and with all the technology on Rubi-ka, SURELY there would be a way to systametize inventory! Do it by category, make it Easier for me to manage items. It could be searchable, etc.. Like a VISUAL File Manager.

Poor inventory system seems like a tactic to increase time people are playing, but I stronly feel that it detracts from my gaming experience. I want to PLAY, not move items all my life!!


#2 Lag.
If it means deleting unplayed characters, items!!, or whatever it takes- reduce in-game slowness, memory leaks, Lag. The last patch signifigantly increased game server lag and we demand good response time to cast nanos with timing.


#3 Too many safe zones
The game is realistic, Newbs do require alot of hand holding, and it is discouraging to get PKed repeatedly
However, there HAS to be Several convenient, Frequently Travelled places (near town) to be Attacked by others and to fight others in free-for-all style. Conflict is the name of the game and at the moment the conflict is too Orderly, predictable, safe, and Boring!!

MMD was moving in that direction but is not travelled frequently enough to be too much fun. Guards were put in the cities preventing some players from getting to the other side's arenas. Do we Have to buy the new pack to get ANY good team Pvp? It seems so. The game is about teamwork and Fighting! So let em team up and FIGHT, funcom! So what if joe gets PKed on his way to some shops, or to bank?

The Major problem with PKing used to be Item Loss- which is not a factor now. So PK away for FUNs sake!

Make the zones roving, as if there are minor glitches in the system. The unpredictability will be very exciting.

#4
Missions are too necessary and repedetive. More Static dungeons!! These are great! Give the teams reason to go out and hunt. Some will hunt, some will do missions, some static dungeons. Right now we do the Same Missions Over and Over and Over because Every Year it is the SAME. Let's vary it up, keep it rolling..

Good job so far.


See you in the GAME!

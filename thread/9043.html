NDA?
Heh... I bet that frigging screen i must accept from time to time is not an NDA (Nondisclosure agreement).

I must admit i havent read it through for a while but as i recall it prohibs people to alter the packets or the game data itself. Thus, one can use the content of the data packets in using and making the third party external softwares.

For example, the map utilities and server information tools. Almost the same thing as the general idea of AOMD: Take the same data what you will receive anyway, format it and make it more easilly accessible.

I see no violation of the EULA agreement in this but naturally i could be sewerelly wrong. Maybe some official answer could clear this matter somewhat? =)

Edit: After some thinking i remembered the EULA also prohibts making all kinds of emulators of sorts. AOMD is very darn near the concept, but is it afterall? It does display the mission objective item and reward, ql levels and the mission location. Some could say that this is a mission booth emulator but afterall, one cannot generate missions with it, so it does not emulate the mission generation process but simply re-formats the received data into more easier way to access and interprete it.

In response to the queries concerning whether or not AOMD is considered 'exploiting' or 'cheating' by funcom...It is not. I was recently speaking with an ARK and asked him about AOMD.

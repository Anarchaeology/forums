Agents will always be broken
Well it all comes down to FunComs incompatible design of the Agent class from day one. The Agent has never been compatible for PvP and PvM at the same time.

Agents need concealment for PvM, but is not even needed for PvP. You do not need any concealment skill to AS in PvP. Since you cannot sneak up on someone that can plainly see you on their computer monitor walking around in sneak mode. So FunCom assumes we are always concealed in PvP, I guess.

If an Agent sneaks, eveyone can see him. This major flaw made the Agent silly in PvP, as if no one could see you sneaking around in any zone, much less a political zone. TAB, TAB, TAB >>>>>>> "Look, an Agent over there. Shoot him!" Or maybe "Run away, an Agent is sneaking over there!"

With all the right buffs, an Agent used to be uber concealed from mobs, so Agents were sneaking through missions. So people cried foul, and FC nerfed concealment, several times in several ways. Now concealment is a joke for everything, but you still need it in PvM to get off an AS.

Aimed shot damage - Any high level Agent can tell ya, AS does worthless damage 80% of the time. Worthless I say, when you think of all the IP put into it, and the recycle time & requirements to even attempt it. Burst and Full Auto give a much higher return for your IP investment.

So concealment/sneak is broke, lets delete the skill all together maybe. As a side note, sneak mode shuts off if anyone in your team does a team buff, or the engineer's Sympathetic Armor cycles off/on.

Next patch FunCom wants to make player characters actually turn invisable. Will this invisability apply to non-aligned factions only? If so, then what about if your Clan character is actually teamed with Neutrals or the Omni-Tech folks? What if my Clan Agent switches sides to Omni, as a spy, and I later team with my guildmates, still as an Omni, who will see me then? Who will I be invisable or visable to? Makes it hard to coordinate attacks if you can't see your own team mates.

I'm sure next patch won't change this - Will we still see nano bot damage posting from invizo Agents that are using a cloaking device? How about DoTs posting from an invizo Adventurer? Yeah, you can't see him, but you know he is near cause you keep seeing damge posting from his cloaking device. How about nano buffs, will we see an invizo character buffing themselves?

As it is now, if I team with a neutral, I can TAB that person, as well as the opposite faction. When will FunCom fix it so I do not TAB my team mates, if they happen to be Neutral or of the opposite faction??

I say, just make Aimed Shot cycle faster and give it a base 50% chance to crit. And if you want to see fur fly, then put an additional skill on all weapons with AS, add concealment to the weapon's skills. This way AS is tied to Concealment, and no more Concealment checks need to be made. Only if you have the proper skills in concealment, can you perform an Aimed Shot. With all the Concealment buffs around out there, the skill may have to be as high as the rifle skill, or close to it. Ithica Traders would love that change eh?

See how broken the Agent, Aimed Shot and the entire Concealment skill are!?!? What a mess!

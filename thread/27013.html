MORB,

As a programmer who's dealt with Windows and it's quirks, I can tell you without a doubt that when window is minimized, if you query its X, Y coords you will get the negative 32,000 returns.

You need to query the window state to make sure it is normal and not minimized or mazimized if you want to reuse this data for the next startup.

Yer other option is to simply not save the coordinates if they don't make 'sense'. ie: don't save the data if you see negative numbers for x or y.

Chat Window Enhancements
1. Customizable chat colors.
2. Customizable chat font size.
3. Resizable chat window.
4. Customizable background color and opacity of chat window.

Allow the user to set up their color preferences, based on what they consider to be priority chat types. If they want to have their team chat the same color as /tell, so be it. If they want the shopping channel to be bright purple, so be it. Background color/opacity would make the problem of shifting from a bright environment to a dark one (and the corresponding problem in reading light or dark text) a user problem, and allow Funcom to concentrate on important bugs like, oh, I don't know -- the Mission system?

Chat types that would be handy to be able to customize the colors? Wel, see Everquest. They have a pretty good handle on it.

I would love to be able to drop the font size down a bit, fit more lines of text in, and shrink the window down. Battle spam is nice to see, but trying to read other text interspersed can be a pain.

Considering that AO already allows customizable 'skins', I would think that this customization would be a logical (and very nice) progression to take.

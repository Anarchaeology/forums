They're mainly for title level 3 players trying to level up. One is referred to as little d and the other normally called Big D. If you're the appropriate level you'll probably have to run SW from Hope to get there as I don't expect you'll have enough complit to use the grid there.

There is a 3rd static dungeon not too far from there that few people know about. If you have map of mort with the machines upgrade it shouldn't be too hard to find.

I don't want it to become super crowded like the others so I'm going to make you hunt for it. I would often solo it in the title 3 cap when the team in Big D was full and little d was in use.

Hope that helps.

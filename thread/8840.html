1) Create a folder in your AO folder called 'Scripts'

2) Write out the script you want in something like notepad

3) Save the script into the Scripts folder you just made. Name it with whatever word you want to use to start the script in game.

4) Delete the .txt extension on the script (in folder options, make sure the "hide file extensions of known file types" box is unchecked) Use the "rename" function.

5) In game, use /<script filename> to get the script to work.

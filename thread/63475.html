List of pending request changes
When I turned L100 with my enforcer I put down a large number of threads with suggestions for improvement and bugs.
I am now L142. Some of the reported problems will be adresssed in 14.6/14.7, but many more are still out there.
Please take a good look at these problems, and fix them.

Request: Change the XP system for gray mobs
http://forums.anarchy-online.com/sho...threadid=54729
Currently if a mob is gray, you get 1 exp, no matter what.
This is insane, because many gray mobs are still pretty dangerous especially the gray boss mobs.
I would like an experience system that gives exp based on how dangerous a mob is, not what level he is, because it's level is NOT a good indication of how dangerous he is.

Request: Give Trade skills better xp
http://forums.anarchy-online.com/sho...threadid=54739
Trade skills don't let you level as you promised us in your game release PR. Also Traders don't get the ability to make enough interesting stuff to be really appreciated. Please give tradeskill workers more exp and give us more items that can be made my traders.

Request: A trading system that DOES work
http://forums.anarchy-online.com/sho...threadid=54743
Current ingame trading is spammy and inefficient. Please give us an ingame trading option that allows us to have items longer shown then that 1 second spam in the shopping channel.

Request: Changes for Enforcers
http://forums.anarchy-online.com/sho...threadid=54736
Lot of changes that really help giving more fun gameplay.
Now updated for new patch.

Request: Mission stats
http://forums.anarchy-online.com/sho...threadid=54751
Make missions more interesting by showing nice stats at the end

Request: Make a better map for the grid
http://forums.anarchy-online.com/sho...threadid=54738
Please replace the white circle in the hud map, with something more helpfull.

Request: More quests for all
http://forums.anarchy-online.com/sho...threadid=54737
Add more variety and quests to the game for all players, not just the low level clanners, or high level players.

Request: Make Hammer Dinos less powerful
http://forums.anarchy-online.com/sho...threadid=54732
Practical example of the above mentioned dangerous gray mobs problem who don't give exp.

Requests: Several other small requests together
http://forums.anarchy-online.com/sho...threadid=54746
Many small suggested changes together, too many to list them here all. But all these small changes can really improve gameplay!

Bug: Icons of items missing
http://forums.anarchy-online.com/sho...threadid=54726
These bugs are still there

Bug: Weapons constructing is very messed up
http://forums.anarchy-online.com/sho...threadid=54728
Still very terrible... fix it soon!

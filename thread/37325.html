What i really hate and would like to see changed
I'm only 54, so i guess it get worst later. But i would like to know :

1- Root Spell lasting 2 min. What's the deal with that, most of the time the mob cast that on you just before dying and you end up not being able to move for a good 2 min. It's very annoying. roots spells should last 30 sec maximum, no need to make something unable to move for 2 minutes or more !

2- Run Speed Debuff. You know that one that make you run like the 6 Millions Dollars Man ? You end up with a run speed of -200 or so. Once again, what's the deal of making that last up to 5-6 min ???? It's NOT necessary, it's very, very annoying.

3- DOT. I've noticed that most mobs always cast that just before dying, once again you have to sit and wait for a min or two for the program to end. Why don't make the program expire when the mob die instead ?

4- Deprive Skill (Major and Minor). But especially Major, they last way too long. In my book a spell like that should last for the duration of the fight. That mob is casting that thing on you and when you kill it only thing left to do is to sit and wait....

See a patern here ? Too much downtime, when i go on a mission i don't want to always sit waiting for a root to end, a deprive skill to end, a DOT to end or a run speed debuff to end. Hope you're gonna do something about that.

Thanks for reading !

yeah
I know that roots, dot's and other inhibiting nanos are a pain.. Especially if the last mob in a mission casts a snare on you.

But, lowering the duration would hurt player-classes that use them.

for a LONG time people have begged for a treatment-kit style device that can be used while standing but requires you to not be in a fight that removes roots, snares, debuffs ect. And the idea is still a good one.

As far as I am concerned, the "casting inexperience to break roots and snares" is an exploit. Sure, funcom knows about it, and sure a lot of people do it.. But a lot of people rob, steal, and kill too, doesn't make it good.

Funcom needs to fix the debuff-rootbreaking and at the same time intorduce a usable alternative:

1) a basic nano in vaired QL's for removing roots/snares should be about the QL of the root it is trying to break. And should use the same amount of nano as a root/snare of the same level.

2) a stim/kit that one can use while standing to remove roots/snares requiring that target is not in a fight. Also others could maybe be implemented to remove DoT's and possibly debuffs (though traders and agents might be able to exploit this by removing the negative effects after a wrangle or false profession, so that would need to be prevented.)

This fix is long overdue.

The 'nickname' IS your 'name' to the game. It's the one unique part of your name (across all dimensions, if they have more than one, to allow them to let people travel between dimensions.


So, when you create a character, you pick one. It lets you have it if it's not already in use. Apparently, the game then chooses a 'First and Last' real name for you, which you will eventually be able to change, for cash, etc. The first and last names are NOT unique, any number of folk can have the same ones.

When you target someone, all you see over them is the 'unique' nickname.

The 'ID panel' shows the full name if you call it up on someone.

Perhaps the most problem comes in in the fact you can't, apparently, have a 'blank' first or last name (bought, that is).

So if you're 'Manus', to use an example given above, he'd have to be (random names) "Joe 'Manus' Felgercarb", untill he can change it, but he can't become just 'Manus' Fari. Whether or not he can become "Guildmaster 'Manus' Fari" is unknown... perhaps benevolent gods would allow that sort of thing, at least for those with legitimate 'in game' titles.

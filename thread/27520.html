Skills emulator - new version
New version of AOSkillEmu at http://rustot.by.ru
- damage calculation fixed
- implants emulation added

Some not obvious interface features - right button allows to emulate buffs, double click set min/max values.

If emulated IPs is not precisely equal with your value, it is not a bug. On each skill changes applying, you can loss 1 IP owing to error of rounding. Therefore, when IPs error is approximately equally with your level (ie difference ~100 at level 100) it is OK.

If you will see more appreciable mistake in emulated values, please describe it in detail, with your character dump. Be sure, that there are no any things changing your skills on your body (it is not only implants!)

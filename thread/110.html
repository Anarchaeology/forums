I really enjoyed my profession until recently, but don't feel like playing such a gimp anymore. Any advice appreciated if I missed something that could make Kroll fun again.

More suggestions
Well, some more ideas...

+ Nanos

* Search Engine Line
Basically, unless the Grid has regressed a lot since the 21st century, it probably can be used too as a mean to access information. The purpose of this line is to gather information about MOBs/PC and use it to the Fixer's advantage.
Should require Time&Space (general Grid access), Sense Impr (link to our brain) and possibly Bio Met (working on the target bio data)
- Basic Information Gathering : returns the level, HP, Nano, Max and Min AC, Worst and Best Evade of the target.
- BBS Scanning : the program runs a quick search of anything posted reguarding the target and feeds the information into the Fixer's brain. Give some bonus to evades and critical hit chances against *this* creature.

* Cell Scanning Line
The cell scanners work by digitalizing the target, and saving this information. Our Grid transportation line works by digitalizing the target and sending it to the Grid. We already have the first part right This line allows to do a Cell Scan from anywhere, by digitalizing the target, and then hacking into a remote Cell Scanner to save the data.
Requires PsyMod, SensImp, MatMet (basis for Grid Phreak) and BioMet (processing the bio data).
The scan is however imperfect. Some part of the unsaved XP are not saved (like 20%). If this still feel too powerful, the nano could also cost some XP. But that would sure make Fixers more useful in groups

* Movement Prediction Line
Raises evades, by linking a simulation of the opponents movements into the Fixer's brain. This way, he's better able to predict the next actions of his foes.
Requires PsyMod & SensImp (classical buff)

* NCU Protection Line
Some kind of anti-virus (offensive nanos can be assimilated to virii). Tries to terminate hostile nano programs running on the Fixer's NCU. Basic nanos could just buff the Nano Protection skill. More advanced ones could periodically attack a random hostile nano program with the Fixer's Nano P skill (like, giving a second, third... chance to resist the nano).

* NCU Hacking Line
Attempts to run a virus on the target NCU. Low level ones (bloatwares) could just sit there doing nothing but taking NCU space (though outputting some messages to the poor user about how version 16.67 is way better than the old one, about the interresting features of the bloatware and so on -- very annoying ;-P). Advanced ones actually try to attack periodically random nano programs and terminate them (resisted by Nano P skill).

* IA Hacking Line
This line deals with hacking into cybernetic opponents. Some effect might be HLT (just stops the target from attacking, deaggroing it), underclocking (debuffs inits), re-programming (enemies become allies, and vice-versa), gremlins (DoT)...

* Transportation Line
The Mark Location nano
An ability for *two* Fixers to set a temporary whompa-like link between them. Damages to one of them would also affect the other, and runs a DoT on the Fixer till it's cancelled (thus, they could only be run for a short time).

+ Traps
I actually like the new locked doors And it seems there are some new traps too (blind, rollerrat) Some more suggestions :
- Alarm Trap : rings an alarm. Fixer's aggro raises a huge notch. MOBs in the room automatically aggro. After a while, MOBs from immediately surrounding room are attracted to the room with the alarm.
- Corrosive Acid : splashes the Fixer with acid, running a DoT with chem damage on him.
- Run debuff : debuffs the Fixer's speed.
- More summon MOB traps
- Morph Traps : morphs the Fixer into something silly and harmless (a rabitt, a cockroach...).
- Area Effect Trap : like boom traps, but affect the whole room (for Team Missions, don't let this Atrox Enforcer near chests!).
Traps should also destroy the chest's content (after all, we can suppose the nano trap uses the content of the chest to feed itself... Not to mention that all this acid pouring on the yalmaha in it must do nothing good to it ;-P).

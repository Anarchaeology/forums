One possible way to get high level players in test is to do it through the character creation. This segement seems to be totally separate from the AO load (the 'AO is loading' message comes up after character creation now). So what you could do is to allow players to select a starting level in the test load of the character creation. This would give them an equivalent IP count to allocate when they arrive on Rubi Ka.

The downside is that the character creation testing would not be 100% valid, but its a small part, and likely worth the trouble to get better high-level player testing.

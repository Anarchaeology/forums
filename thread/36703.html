Why MMORPG developers should probably employ cryptographers.
The three reasons MMORPG developers should employ cryptographers. The first is proven, the second and third are speculation.

1. Secure source for backup player information. If the server were to place all the character information, in encrypted, and thus inaccessible, form on the players' computer, then if the database were lost, the clients could be polled for the information to repair it. Simply a spare tire. I'd never go so far as to call client side storage reliable, but it COULD be secure.

2. Encrypt player information on the client side, to reduce the threat of identity theft. If the players', saved, password is encrypted, and decrypted against a key provided by a secure socket layer by the server, NOT saved, before being provided by another secure socket layer, it reduces the possibility of a third party program accessing the password. This could be tricky, but I still think it could be done.

3. I suspect that if the server were to provide a random number seed, and the software pseudo random number generator to the client, and then had the client handle PC-NPC fights locally, logging EVERYTHING, and sent that log back after the fight so the server could duplicate it to check for aimbot modification, the fights, at least, could be made less laggy. I suspect that the information could be hashed one-way so that an aimbot would have to spend a LOT of cycles to figure out the optimum circumstances, based on the one given random imput, to fix the fight.
For PC-PC fights, or PC-PC-NPC fights, a socket could be established between the clients, plural, and each handle the job in the same way, based on the logs, but it'd be as fast to rely on FunCom for this, except this would allow for less lag when the limiting factor was server-side lag.

Thus, by placing a cryptographer on the programming team, FunCom could very likely make the game more hacker resistant, less prone to server-side loss of information, and possibly less laggy where combat is concerned.

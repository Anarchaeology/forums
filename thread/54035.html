Ravenmad thanks for the bump


I have been in a few chats with others on this subject,
and the consesus seems to be that this is a problem with the inventory code

Since the object code to pick up object a, detect a click event, the shift right click event and the click results are all wokring, it points to a problem with the inventory code

The three scenarious are:
#1 - objectA interacts with objectB, result objectA stays, ObjectB goes away, new ObjectC is created and turned over to the inentory for handling in the client. This is the case with a hacking tool on a sealed weapons recepticle as an example

#2 - objectA interacts with objectB, result objectA goes away, ObjectB goes away, new ObjectC is created and turned over to the inentory for handling in the client. This is the case when a cluster is added to an implant.

There are several issues already unfixed and long bugged with inventory. The cant see item unless your zone, the full pacfk with extra row on bottom you cant use, etc....

But problem known for a long time or not, it's a big deal when it starts happening all over.

Because now we also have this scenario
#3 - objectA interacts with objectB, result objectA stays, ObjectB stays, no tradeskill message occurs, orincorrect objects message. This is the problem with "cluster wont go into implant"

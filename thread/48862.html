PvP Unfairness
The problem with pvp is that it is unbalanced for every proffesion, the reason for this (i think) is because the designers of the game saw that classes like doctors were wanting to pvp and then tried to make the game to suit them a bit more. This seems a bit unfair since anyone choosing a doctor should be choosing a non pvp class (How many doctors do you see on the battlefield of a war , doctors not field medics either). People just say that the crat isnt a pvp class without asking for him to be made better in pvp, yet for doctors people just wont accept that a doctor is not cut out for pvp (they are now but they shouldnt be), It would be much better if there were set pvp classes and set pvm classes, The only way i can see doctors around in pvp is if they were part of a team but seeing as team pvp rarely happens that wouldnt really count. Obviously everyone has the right to pvp but cant everyone just get a different class to pvp with. I think doctors (and a few other classes) should be more geared towards pvm so that pvp can be left to the enforcers and soldiers and such things so pvm can be left to the engys and docs etc..

The gist of that is that there should be pvp and non-pvp classes so the unfariness of making a class that is not made for combat into an elite fighter is gone (e.g making dmg 50% so fights lasted longer and docs didnt just die in 3 shots)

Obviously the problem with this is that a lot of people who already have chars such as doctors who have spent a lot of time
making them into fighting machines and it wouldn't really be fair to simply remove them from pvp now.

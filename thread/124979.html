Keys for Mission Boxes
My idea is..... /drumroll

Keys for Mission Boxes.
This is not my only idea i have several related to this one.

My problem is B&E is a blue skill, and i almost cry every time i have to dump ip into it.

So how about this...
Mobs/Boss cary misssion keys....

Mobs cary 1 charge keys for the looting of chests.
Boss carys a key that when used unlocks all the boxes.

Note: keys only work on collected places dungeon no exploits there you know.

B&E can still use their advantage as people who can sneak around looting withought fighting mobs.

Also so there is enough keys for each box you can count the number of boxes automaticly for each mission and do a mathmatical formula to match the number of counted mobs.
Set it so that a percentage drop for each key is done and increases if that mob did not drop a key. So in theory at 100% completion all keys could be found.

Resons i think this might be a good idea.

1) B&E is blue to a few classes
2) If it is locked there must be a key somewhere right?
3) Creats a "game like" atmosphere as you can use the key on one chest one time
4) may encourage people to kill the boss
5) save time from people having to use ther b&e skill if they have it

heck i dont even know what good b&e is for a ql 190+ misssion ... probably max huh?

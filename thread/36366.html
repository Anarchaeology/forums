We are here to serve you
Welcome to RubiCom. It is the newest communications channel for the citizens of Rubi-Ka. RubiCom plans on offering many services in the future, but we would currently like to offer our group matching technology to all of you. Simply notify the bot that you are in need of a group, and then go about your normal business. When a group can be formed, all participants will be notified, and then a private chat channel can be set up to handle the details. No more wasted time standing around. No more frustration.

RubiCom is a free service that is available to all, Omni, Clan and Neutrals alike. We only wish to help the productivity of all those on the planet. Your work produces many benefits that extend far beyond the bounds of Rubi-Ka. In helping you, we help ourselves.

The software is in beta release while we get the bugs out. It is also missing a few key features like a looking for more command to quickly find a replacement for member that has left your party, or a Side filter for those that really cant get along with their neighbor. These are at the top of the to do list and should be available soon. Feel free to post any additional suggestions or problems here.

Spread the word. The more people (and Atroxes...Hehe. Just making a funny big guys) that use RubiCom, the easier finding teams will be.

One quick note before we jump into the commands. There are a lot of them and the list will be growing, but the only command that you really need to know is the basic LFG command. Simply type:

/tell RubiCom LFG

That tells the bot that you want a group. The rest is gravy. Oh, and you can use

/tell RubiCom help

to learn more later.



BASIC SYNTAX:

/tell RubiCom (command) (parameters)


COMMANDS:

LFG [OFF] [BS|PM] [GUILD]
Notifies the bot that you are currently looking for a group.
  • OFF: Tell the bot that you are no longer looking for a group. If you have players that are grouped with you (See below), those links will be broken.
  • BS|PM: Request teams that are going to that location
    If no location is given then you are available for any location. This is obviously a very limited list. To simplify things right now, only the most popular locations are selectable.
    1. BS: Broken Shores
    2. PM: Pleasant Meadows
  • GUILD - This will allow you to be seen by the GuildList command (see below), but the bot will not try to match you up with a group. Guild members can use this command if they want to try to group with guild members first.

Example:
/tell RubiCom LFG
/tell RubiCom LFG BS
/tell RubiCom LFG OFF
/tell RubiCom LFG GUILD


LVL #
Sets your level in the bots database. The bot will default to the level specified in your public file ( Funcoms site) but since that can get out of date, this will let you manually set it.

Example: /tell RubiCom LVL 98


STARTGROUP
This command will allow other players to group with you. You will become a group leader and other players will be able to group with you. Then when you send a LFG command to RubiCom, the bot will keep all of you together when forming groups. See GROUPWITH command for more info.

Note: This command will cancel any LFG request you have previously placed. Once all the other players have grouped with you, you must reissue a LFG command .


GROUPWITH (playername)
Use this command if you want to go hunting with friends and still use the bot. When the player identified by (playername) requests a group, the bot will keep you together when setting the groups up. You can only use this command for one player. If you use the command again it will override the previous one.

The player you want to group with must issue the STARTGROUP command before you can group with them.

Up to 5 players can identify the same person to group with and you can only group with a player that has not used the GROUPWITH command on someone else. (No chaining). So for example if 3 people wanted to group together, 2 would use the GROUPWITH command on the third. Then that person would use the LFG command to actually request a group.

The LFG command can't be used with GROUPWITH. Once you say you are grouping with someone else, they are the one that will use the LFG command, not you. You will automatically get invited to any group they get invited to.

If (player name) is blank or OFF then any previous GROUPWITH command will be canceled.

Example:
Hextor: /tell RubiCom STARTGROUP
Player1: /tell RubiCom GROUPWITH Hextor
Player2: /tell RubiCom GROUPWITH Hextor
Hextor: /tell RubiCom LFG BS

The above example will have Hextor, Player1 and Player2 all looking for a group together to go hunting in Broken Shores. The last LFG command is important. Until it is issued, you are not looking for a group. Also, once the LFG command is issued, no more players can use GROUPWITH on the group leader. If more players need to be added, the group leader should reissue the STARTGROUP command, let the additional players GROUPWITH them, then issue the LFG command again.


STATUS
Gives your current status in the system. If you are looking for a group, this command will also give you the number of players that are looking for a group close to your level. This is an approximation and does not account for any filters you have in place. It is meant to give a general idea of your chances for finding a group. The level range that it uses for this count will increase over time.

FYI: This is what the bot does when it tries to form groups. It starts out at 10% of you level and increases the longer you have gone without finding a group. The bot also tries to form groups with a good composition of professions. It starts off requiring a tank, healer and mezzer. Over time these restrictions are also relaxed in an effort form groups when the players arent available.

Example:
/tell RubiCom status


GUILDLIST
Lists players in your guild or guild alliance (see GuildR command) that are looking for a group near your level. If players are grouped together, their names will be enclosed in ( ).

Example:
/tell RubiCom GuildList

Sample output: SinglePlayer 23 Fix, (GroupedPlayer1 24 Bur, GroupedPlayer2 22 Enf)


GUILDR
"Guild relation" command. It allows the guild leader to form an alliance or declare war on another guild. This is only usable by guild leaders.

syntax: /tell RubiCom GuildR A|W|N (Guild name)

A = Alliance
W = War
N = Neutral

The guild name must match the guild name on Funcom's site exactly. Also someone from that guild must have used RubiCom at least once. The bot only downloads guild information when it needs it, so if no one from the guild has used the bot, it will not know anything about that guild.

Guilds that have formed an alliance will be able to see each other's guild members in the GuildList command. For an alliance to be formed and active, the leaders of two guilds must use this command on each other's guild. The effect is not transitive. If Guild A is in an alliance with Guild B and Guild B is in an alliance with Guild C, Guild A is not in an alliance with Guild C.

Note: When this command is used, a message will be send to the targeted guild's leader.

The War option has not been implemented yet.
The Neural option simply undoes a war or alliance.

Example:
/tell RubiCom GuildR A Division 9 RSGE


GUILDINFO
Shows your guild's current alliances and war declarations. You must be in a guild to use.


HELP [StartGroup|GuildR]
Gives a brief list of the RubiCom commands. It has three parts, the general help and help for advanced features

Syntax:
Example:
/tell RubiCom HELP
/tell RubiCom HELP StartGroup
/tell RubiCom HELP GuildR



Note: In its current form, only citizens that have access to a vehicle should probably use RubiCom. The global nature of the bot makes quick travel a necessity.

We do our best, but you can't catch everything, some bugs don't even show up on live for quite sometime because they are so infrequent.

However, this one was pretty obvious, though it took me several minutes to realise quite how serious it was, and much more testing to be sure of what was happening. Others had spotted the same bug in other forms.

Whilst more numerous smaller patches seem a good idea, the effort involved in actually doing a patch of any size: write->debug->build patch->qa patch->test patch - repeat as needed, then build final patch, down servers for several hours... you get the picture. You might end up using more time doing the stuff around a patch than actually writing the code and designing the content.

That said, over 2 months is getting a bit extreme...

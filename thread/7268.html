I'm by no means an expert....
I think that below lvl 75 you will not loose items when killed in a political/mayhem zone. After lvl 75 you will loose both non-saved xp and items found, except no drops(I think this is correct.)

An example to illustrate: If you at lvl 50 save and then travel to some %25 zone. You do you missions and on your way back you get ganked. You will only loose the unsaved xp, nothing else.

If you are lvl 76 you will lose both the xp and all non-drop items(and maybe money too).

And just a hint... High lvl is in my humble opinion 125+. There was a time when lvl 60-80 was high lvl, but I think that time is past.

As for the part about running into a 75% area(not server zone shift) they are still able to kill you since combat was initialted before you entered the %75 zone. If you zone(ie. a server or playfield shift) they cannot follow you and attack. Plz correct me if I'm wrong.

So high runspeed is a must if you don't want to fight. :-) Just set agg/def to max def, and run like the wind... No shame in it... If you don't want to fight it's a legit strategy.

My experience - and the fix.
Blue screens, failure reading .dll files, sudden crashes, etc.... You name it - I had it. Here's the story of a man who spent close to 500 dollars trying to rule out the causes of his system's problems.

System description (before replacements): 1.8 GHz DELL Dimension 4500, 1 GB RAM (forget what type, but at the time of upgrade was the fastest RAM on the market), 20 GB Western Digital HD, Windows XP Home Edition. GeForce2 MX 400 64 MB graphics card.

1. Reinstalled WinXP. About 30 times (yes, ran out of renewal licences and had to call Microsoft for extension). Updated videocard drivers about 40 times with the latest versions. AO would not work properly - same problems.

2. Replaced Hard Drive. Hard Drive worked fine. AO would not work properly - same problems.

3. Replaced Motherboard with genuine DELL motherboard. AO would not work properly - same problems.

4. Replaced CD-ROM device. AO would not work properly - same problems.

5. Removed Norton Antivirus 2003 (registered online version). AO would not work properly - same problems.

6. Used the Windows utility mentioned prior in this article to check RAM compatibility and stability. The test failed miserably.

7. Replaced NVIDIA GeForce2 MX 400 with RADEON 9200 series 128 MB videocard, and with genuine DELL-designed 1 GB RAM. BINGO!

The memory test ran from the floppy disc showed remarkable passing test rate. System works fine - no more crashes.

*I do not by any means recommend you guys go through the hoops like I did. Instead, run the windows memory test from the floppy, and see if your RAM is the root problem of your system's performance. If you need to upgrade your RAM, visit www.4allmemory.com - they will make sure you get the RAM that will be 100% compatible with your system. For the cheapest possibly graphics card upgrades, visit www.newegg.com .

Well, I got a pretty similar config to many peeps here:

Athlon XP 1700+
VIA KT266A
512 MB RAM
GeForce 2 MX 400
40 GB HD

the main difference is - I'm not running Windows eXPerimental. I have Win 2000 and the last bluescreen I had was ... 5 or 6 months ago.

But to give you some hints:

1. Check your mainboard BIOS settings:

- RAM timings
- AGP settings
- CPU settings

Most BIOS systems offer a low-profile default setting with no tuning options enabled. Load them. If the problem still persists, it's not a mainboard/CPU problem.

2. Check your Windows System Config

Drivers? Latest approved ones, not beta. Boot Windows in "safe" mode to check if you have 2 drivers installes (yes, that can happen). Driver settings
IDE - is Busmastering and correct DMA-mode enabled (both should be on for the HD, but not all CD-ROMs have DMA, check manual)
AGP - Multiplicator? Sideband?

3. If all this is set correctly and you STILL get errors, then install a clean Windows 98 (the very first, not the SE). Install NOTHING else, just some gfx benchmark like 3DMark2001 or 3DMark03. Set it to "continuous" so it restarts ad infinitum. Let it run that way for 12 hours. If it crashes, you got a hardware problem somewhere. If it does not crash - well, back to software, try using older drivers (less performance but more stability at times).

Oh, and yes - Intel's systems tend to be less difficult, but AMD is faster - especially with the Nvidia nForce Ultra 400 and an Athlon XP 3000+.

As for gfx cards - Radeon is currently faster and offers more overclocking potential due to better fabrication, but ATI is not famous for it's drivers and support once the hardware is no longer sold. NVidia has slightly slower cards, a bit less performance (10-20%) and costs a bit more. But the drivers are better and the support is good - you can be sure that your card will be supported in 3-4 years. And from my experience, Nvidia drivers also tend to be less difficult to handle. This might not be a problem in a simple gaming system, but if you have a complex system, ATI drivers can be a real pain. Oh, and Nvidia has far better OpenGL support.

BTW: If you're running on less than 512 MB and have XP / 2000 installed, BUY RAM! XP and 2000 use 200 MB for system and cache, and the AO client goes up to 300 MB at times. And apart from that, RAM = speed.

Note: I'm upgrading to Athlon 3000+ / nForce U 400 / 1 GB RAM / GF 5200 Pro next month.

This error is classic of Windows 2000 and Windows XP. Generally when receiving this error it is due to the fact that the MEMORY being used in your pc is in someway incompatible. Generally, make sure that you have not mixed ECC/Non-ECC (9 vs. 8 chips) or if SDRAM 100 and 133mhz... I know this sounds odd, but thats what triggers that error. If it happens quite often, you should buy some real quality memory (Like Kingston Value Ram and use their memory configurator..). Often, cheapy memory doesn't identify properly to some memory controllers and hence, doesn't work too nicely.. this applies to most all memory systems, RDRAM, DDR, SDRAM.

If you've mixed and matched memory, i'd reccomdend pulling the pieces and start with the largest first.. until you reach stability, or simply buying quality memory.

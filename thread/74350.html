Future Use of the Beta Server
Greetings

I think the current beta server should be left running as one of two entities:

Option One: Leave it open and start allowing the players who currently have access to start testing Shadowlands, and then open it to more players as the testing would progress.

Option Two: Convert the server to being a Test server. Keep it as is, buffing system in tact, so that there would be a wide range of player levels, as some people will not opt for buffing. It would then create a situation where things could be tested properly across all levels.

I would prefer option one, but of course, the two options could always be combined, having it become a test server after Shadowlands.

Server Side Bug Fix
Hey Everyone

The Live Servers are up after the server side bug fix

Here are the issues that it addressed:
-We have made a change to the mission system; your missions will now be closer to the terminal where you get them.
-Fixed a bug causing hostile AE nanos to affect caster and friendly team members.
-Fixed some problems with the new org system.

The last thing on the original fix list was this
-You should now be able to complete locate person/item missions.

There are still some issues with this. If you do these missions you will from time to time not receive any reward. We know about this issue and we are working with a fix on it. Please do not petition about this.

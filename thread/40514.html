IP recovery per level
IPR points are great idea, but there are some who say that there aren't enough IPR points in the game to truely explore the skill system of AO.

I'd like to suggest a skill deterioration system to augment the current IPR system.

Works like this:
After level 50, for every level gained, if a certain skill is not used in the previous level, it loses a set number of skill points and returns the IP equivalent to your IP pool. This set number of skill points equals the max number of skill points allowed to be raised per level. If a certain skill is not used for 2 levels in a row, the skill loses 2x the max points allowed to raise.

Example:
Say I am allowed to raise my FirstAid by 4 points per level and every FirstAid skill point costs me 300 IP. I hit level 51 but I did not use my FirstAid skill while I was level 50. The FirstAid skill goes down by 4 points and 1200 IP is returned to my IP pool.

Say I hit level 52. I still have not used my FirstAid skill and it goes down by 8 points. 2400 IP is returned to the IP pool. The maximum multiplier is 3x so that the skills don't deteriorate too fast.

This only applies to skills. The abilities (str, sta, agi, sen, int, psy, body dev, and nanopool) will not be affected.

I know that IP cost for a skill point goes up slightly every skill point, but I kept it constant for the sake of argument.

What do you guys think?

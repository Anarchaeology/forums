OOC: Can we please try to get along and not get so dramatic with the OOC stuff?
OOC:

I don't want to start one of those "OMG! RP is dying and not like it was back in the good ol' days!" threads, but I'm seeing a lot more bickering OOC (or maybe it just seems that way) and it's causing problems. If we're going to interact and RP with each other's characters, we need to leave RL out of it because it ALWAYS causes problems. There is a real person behind that character with real feelings and there is no reason to bring RL into RP unless you are working out a story or something.

So, be nice to each other and respect each other's feelings.

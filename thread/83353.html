Soldier Skill Request: Burn Through
Skill should:
add to the weapon:
OnHit: CastStunNano Target Burnt-through Armor 7%
_________
Burn through should be dependent on the soldiers damage type:
Modify Wearer ReflectProjectileAC -10
Modify Wearer ProjectileAC -230

Modify Wearer ReflectEnergyAC -10
Modify Wearer EnergyAC -230

Modify Wearer ReflectRadiationAC -10
Modify Wearer RadiationAC -230

Modify Wearer ReflectFireAC -10
Modify Wearer FireAC -230
____________________

Basically the nano should be the same that the hellspinner casts.
____________

Let me explain how it should work.
You cast that nano (self only).

Whenever a shot hits the target, there is a test if 'burn through' is cast on the damage receiver. If the skill is triggered the target gets cast the burn through effect on him.

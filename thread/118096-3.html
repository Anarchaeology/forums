If you want to remove the 'level' tag from crashing nano programs and keep the game skill based, then when this offensive nano program is cast it compares the skill requirements of any running nano programs to the skills of the 'host'. (i.e. the character who has the propgram running.) If the host could cast the nano him (or her) self, the program could not be terminated, even if the program is cast by another profession. However, if the host could not cast the nanoprogram him (or her) self, there is a chance that the program would destabilise and crash.

This also has the advantage that Nano-intensive professions (NT, MP, Doc, 'Crat) would not be too adversely affected; i.e they could have hefty nano programs running in their systems as nano programs are the core of their profession.

This keeps it a 'skills' based game, still open for a bit of twinking, but I suspect that it would be impossible to be invulnerable at low levels.

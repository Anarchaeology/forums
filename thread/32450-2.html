I would have a set of commands

"/map open username" Let username send coords to your map

"/map close" Makes it so no one can send waypoints to the map

"/map send username" Sends the current waypoint on your map to the map of username

"/map send username zone X Y" Sends the x,y coords in an optional zone to username

"/map send username here" Sends the current location to username

In all of these if you place "team" for username, it sends to the team.

This also opens up the possibility of letting somebody make a navigation bot. You could tell the bot where you are and where you want to go, and the bot could send you waypoints.

PLAYER.FLAG_COMBAT_PLAYER = true
PLAYER.FLAG_COMBAT_NPC = false

function INCOMING_BUFF(bufIn as BuffBlob) as boolean

if (bufIn.TYPE = "HEALING") and (PLAYER.FLAG_COMBAT_PLAYER = true) then

if teamCheck(bufIn.CASTER,PLAYER.NAME) = false then
INCOMING_BUFF = false
exit function
end if

end if

INCOMING_BUFF = true

end function

I used a function called teamcheck in the code to check for a team relationship between the buffing player and the recipient.

And the zone % doesn't matter. Unless you only want non-teamed players to be able to heal within 25% and 0% zones.

Then it'd be this:

PLAYER.FLAG_COMBAT_PLAYER = true
PLAYER.FLAG_COMBAT_NPC = false

function INCOMING_BUFF(bufIn as BuffBlob) as boolean

if (bufIn.TYPE = "HEALING") and (PLAYER.FLAG_COMBAT_PLAYER = true) then

if (teamCheck(bufIn.CASTER,PLAYER.NAME) = false) and (ENVIRONMENT.GAS > 25) then
INCOMING_BUFF = false
exit function
end if

end if

INCOMING_BUFF = true

end function

IP Reset: Should it be Volluntary?
The IP reset should be mandatory to correct characters who used exploits to dupe IP.

IP should be reimbursed by resetting everyones abilities/skills to level 1 base stats and giving IP based on level. Simply returning spent IP to the pool will *not* correct those who were able to keep all abilities/skills maxed when *that* bug was still in game.

Also, all "Rings of Knowledge" should be completely removed from the game before the IP reset. Delete them from players' inventories like you did the Knight Armor. I have seen ebay auctions selling as many as 40 of these rings. Get rid of them.

Map Nav should be reset as well and everyone's maps/upgrades should be deleted. Maps are so damn cheap you wouldn't *need* to reimburse anyone, but to do so you could just make maps and upgrades buy and sell for 0 credits for a limited time.

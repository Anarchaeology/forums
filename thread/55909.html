Please note that a DestroyItem command (technically it's called "Eat", but DestroyItem is a bit more clear...hehe...) happens in conjunction with a SummonItem command.

So, basically... It summons a new item, then deletes the old one.

Interestingly enough, it looks like you have to be (for instance) and Engineer to equip the item, yet only a non-engineer can spawn higher QL versions of the item.

Now...I'm ASSUMING that it does not spawn itself. It probably spawns ANOTHER one of the figures.

Therefore, say you're using this:
http://v020u46eff.maximumasp.com/AOD...sp?AOID=202412

Small Ebony Figurine, QL 200, Martial Artist req

A non-MA could right-click on the item and turn it into a QL 201 "SOEF" hash summon. So it turns into one of the 201 figures--and probably not one with a Martial Artist req.

This can be inferred from "The Figurine turns her head slightly."

So, basically...if you wanted to get at one of the higher QL ones...you would probably have to map out the order in which they spawn themselves based on the original (probably path for each profession--so 12 paths total I'm guessing) and play have some fun passing it between yourself and a very trustworthy friend. lol

Considering it goes up to QL 256, that could mean a lot of passing an resummoning... And depending on how Funcom arranged the summons, could be a pretty unpredictable progression requiring a lot of trial and error. (Hopefully they're common enough to end up messing up by going past the "one you want"!!)

Does that make any sense? I'm kinda tired...don't know if my explaination cut it. =)

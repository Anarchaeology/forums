Yeah, this patch it pretty good, keep it up FunCom. In regards to all of the PVP imbalance, I think that combat would be much fairer just so long as every prof has a counter for any kind of attack, nano, or strategy.

Example-

- If you get rooted: You have unroot nanos and items

- (For an engi): Special attacks killing you?- Engineer special attack defence nano

- Debuffed?: Use a rebuff nano

- Damage against you is too good?- Damage shields, reflect shields, AC buffs, healing

Etc.

Not all of these are necessarily implemented for every prof. so far, but I think it would make a normally complicated PVP balance situation easier.

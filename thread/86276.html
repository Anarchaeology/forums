Server Specific Name Databases
This has been annoying the crap out of me lately.

So I start a new character....and then I get stuck on the name screen because every possible interesting or witty handle I can think of is already taken.

Then I come to the main site and do name look ups on the names I want and this is what I find.

Lets say I want the name Ripley. Not that I do, just in theory here.

Well after searching I find there are two Ripleys. One on RK-1, and another on Test.

So this means that any name in the game can only be used possibly by 2 people. And there are 4 seperate servers now.

Why should it matter if I want to be Ripley on RK-2, if theres a Ripley on RK-1? Unless the naming databases are server specific pretty soon everyones going to be reduced to adding numbers or strange letters to names.

Its a name or a nickname. Something people can identify you with and I hardly think that having someone with a name on a server I don't play on should keep me from having the same name on a different server.

Just annoying getting stuck at the naming screen because every name I'd like to use is some level 3 character on RK-1 that probably hasn't been played in 6 months.

Sorry if this was ranty.

DOVVETECH 2.0 skin released!
Hi all,

Thanks for all of the comments and feedback on the last version. The new one keeps the same overall look but is a bit more polished overall and incudes some much needed fixes/improvements. This should be the last uptate to the skin unless funcom adds more graphics to the interface:

You can download this from:

http://peacefairchild.tripod.com/

2.0 Revisions

- Changed all increment marks on health, nano and exp to work in a 1/2, 1/4, 1/8 increment system changed the look of these indicators everywhere they appear.
- Reworked the stats window and NCU area
- Added accurate increment marks to the "easy/hard" slider in the mission terminal window. Its now easy to find the available quality levels.
- Changed the targeting cursor to red
- Fixed the "Back" clothing slot (it had been mistakenly labeled "Neck")
- Changed "team group" to the correct term "temp group" in the friends window.
- Modified the system fonts to fit better with the theme
- Made some other small aesthetic changes to polish things up a bit.

-Dovve

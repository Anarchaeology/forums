How to make an Agent an Agent
I have been reading alot of the agent forums, and one thing that they all have in common is that an agent is not what they are supposed to be. They all pretty much say that agents are Jacks of all trades , and that is not what we how many of us that play agents thought the profession would be, considering that is how the Adventurer is discribed.

There are many suggestions on how to make an agent a true agent and I believe that only two things need to be done so that we become true agents.

1) Make a new agent only rifle that has all the same stats as the x-3, but lower the speed of it to 1.0 to 1.5. Also remove the bonuses that it gives to the wearer. This will give an agent a fast weapon that deals good damage which is something we are lacking. And to make this an even more prized weapon either put it on one of the Unique Mobs, i.e. Tara, Mantis Queen,etc..., as was done with the EoT and the Queen blade, or make it a quest item as was done with the fixer grid.

2) Nerf the aimed shot so that if you have that skill over 900 you have a 10% chance of doing a 10k aimed shot in pvp, and for every 100 skill points below that the chance drops by 2%. That will make the agent titles (i.e. Assassin, Master Assassin, etc...) ring true.

I hope that Funcom and others read this post and consider the changes that I have suggested to the Agent class. For I believe that with these two simple changes the Agent will be what many of us that play agents thought it would be when we chose the profession.

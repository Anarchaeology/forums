The link for the RivaTuner mouse-speed fix is no longer valid, so I'll post the instructions here. Note that this only seems to work for GeForce-based cards.

Download and install "RivaTuner". You can download this from various locations. Try searching for it.

After you install RivaTuner, run it. Under the 'Main' tab click the 'Customize' button under the 'Driver settings'. Click on the DirectX icon. Go to the 'Blitting' tab and enable the 'DDBLT_WAIT' option. Enable the 'Limit maximum number...' option as well. Go to the 'Vsync' tab and set the value here to '1'. Click 'Ok' to save your changes.

Disabling anti-aliasing (or setting it to application-controlled) in your video card's control panel should also improve the mouse speed.

Works pretty well for me

Manual marking of a waypoint?
One of the better ways of tackling coordinate finding would be to allow a waypoint to be specified as a coordinate + zone pair, with the zone defaulting to current zone if omitted. In other words, syntactically something like:

/waypoint 1234,5678 Western Wastes

The code is already in place to allow part of this functionality, since missions are marked with a waypoint when you upload them to a map. In fact, while it would be nicer to keep the manually placed waypoint separate from the mission marker and displayed differently, it wouldn't be too bad just to reuse the existing mission marker manually as above. It sure would make the development effort for this almost none, ie. just parse the command and call existing mission upload code.

PS. Don't tie any facility in to helpbot, or to any other bot, as they're frequently congested or down altogether.

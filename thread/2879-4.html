Been a long time since I updated this thread (for various reasons).

Drivers for VIA chipset users are as follows are here. Heaven forbid this link should ever go down, but it may. In that case, goto VIA Arena and look for the latest release of their 4n1 drivers (now called Hyperion drivers...).

Also, some of you are reporting REALLY weird blue screens with some nVidia drivers. Remember, beta drivers can do that. Try getting new drivers from your card's manufacturer first, or go to NVidia's site to download the latest release (they claim they're WHQL certified, however, you will have to force Windows XP to take them anyway).

Finally, always check to make sure your RAM is OK (common problem, but can be hard to diagnose. Easy way is to reduce your swap disk space and running a memory intensive game such as AO... if you crash nearly immediatly, it's a physical memory issue), that the graphics card is situated properly in it's slot (always important, can cause problems that are hard to troubleshoot), and try taking out your soundcard if all else fails (don't know why, but some versions of SBLive and Audigy cards cause issues with GeForce cards).

Oh, before I forget, obviously Zixxaxx (sic?) has posted some great info on the 40.70 run of the nVidia drivers.

I have probably done more implant experimentation that the majority of other players at this point. I have experimented with utilizing several sets of implants for different uses (armor, then switching to normal usage sets, etc.) I have built implant sets heavy on AC. I have built sets with no nano skill clusters. The following is my latest iteration and attempt to make the best out of the feeble skills the Fixer is given.

The following Fixer implant schema is designed with a few fundamentals in mind. The fixer, at least it its current configuration, must capitalize on his evade ability. Regardless of the amount of AC a fixer may have, they dont have the HP to slug is out. Evades also help with mission blitzing. Also, given the extreme cost of the Fixers nano skills, using implants to raise these skills is invaluable in regards to saving valuable IP. Last but not least, SMG and Life are used in every available location which is a common rule in fixer implants.

Also, it is important to note that some slots have been intentionally left empty. This was done to allow the entire implant set to use either Agility or Stamina as the requirement. The empty slots only provided luxury type skills anyhow, so their omission does not adversely effect anything.

You will notice that Unloading has been placed in the Right Wrist rather than bursting. This has been done for the Suppressor route. If you intend to stay pure SMG, Bursting goes back in that slot. You will also notice that this implant schema lacks any matter creation clusters. I feel grid armor is a pipe dream. Effetive Fixer Implanting. Rules to Live By:

1. Never use "Ability" clusters in your normal everyday set of implants unless you have empty slots that you're not using. Abilities should be raised with a SECOND set of implants and used to equip armor...then replaced.

2. ALWAYS opt for clusters that raise dark blue skills that you use over any other skill except for two. First, SMG skill. Given that it sets your damage, never give up an SMG slot for anything else. The same goes for Life. Always use all three available slots for Life clusters.

3. Evades are better than AC. Never substitute AC clusters for Evade clusters. If you're using the best armor you can, you'll be catching mininum damage most likely anyways.

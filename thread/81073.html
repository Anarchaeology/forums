Best way to get to Rising Sun if you're Clan or Neutral is to exit Old Athen to the east (into Wartorn Valley). From there, you can see a large plateau directly south...The Rising Sun is on top of that plateau. You can reach it via yalm (but, you have to zone into Aegean before you can actually land on the plateau)...or, for the lower levels, on the far side of the plateau is a waterfall that you can swim UP. The area is relatively safe, but if you're very low-level...you might want to ask for an escort.

I'm not entirely sure what the best route would be for Omni, so if someone else can add that info, I'd appreciate it.

I really think this area is generally accessible to about anyone, but if someone has trouble getting there...give me a /tell that night (Braedon) and I'll try to make arrangements to get you beacon warped.

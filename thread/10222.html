I don't know if you already do this, but it helps ALOT.
When in Home/BS, I set visual distance to 10%. I still lag but never disconnect and the lag is completely manageable.

If I set visual to 0-5%, I eliminate lag all together but then I can't see any bldgs and navigation becomes a chore.

Also in the middle of town (near the bank/mission/insurance terms), if it's crowded I set char view distance to a minimum as well and this also helps a ton.

None of these settings have an effect on the missions, So I don't have to readjust until I am ready to leave.

Yes I wish FC would do something about the lag there, but until then, this is the workaround I have found most useful.

I don't put ClickSaver in the same directory as AO. At one time I didn't even have it on the same drive and it still worked. The first time you start ClickSaver it should ask you where you have AO installed. It will use that location to find the AO database and make a copy of the database into the CS directory.

Be sure you have exited AO before trying to start CS for the first time. I think the database is locked while AO is open which would explain the error message you're getting. Once the database copy starts it might take a little while so wait for it to finish.

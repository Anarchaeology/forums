I don't think there is anything wrong. I think that several of the patches are incremental, so that if you install from an older CD, you'll have to patch a few times. Each patch updates the previous.

The jumping from time left from "8 minutes to 17 minutes" simply means that your transfer speed has degraded. That happens sometimes; particularly on dialup lines.

I think your PC is fine. I also think the game is fine. Just patch when it tells you to, and after a few iterations you should be all set.

Or download the manual patches, which is what I always do. (though not for testlive obviously and I've never had patches corrupt there, virus software or not...)

But yes, the auto-patcher must restart after every patch, and if your using the original client disk (11.0) that could take quite a while. If doing this, then *do not* run the speed disk utility as it is no longer needed and will just waste time and disk space. If your using the newer special edition client, then you'll need less patches. Check the 'Local Version' number on the launcher title bar on startup.

To be honest, if patching from 11.0, you'll be far faster downloading the manual 'super-patch'...

Check these out
1) Have a pop up window for NoDrop items. This will keep people from looting an item they can't use and allow a team member that can use it to get it.

2) Set up a system where an item from a static spawn can only be looted once by a character. This will cut down on farming of the items. I don't mean Unique item where you can only have one on you at a time. Once your character has the item they can kill the mob as often as they like but never be able to get the item to drop from the mob again. This will lead to a little player interaction for those who want to dual weild an item since they will have to get a second item from another player/character.

3) If there is no target selected have the nano charger and treatment lab default to the user. It's annoying to have to target yourself to use an item this commonly used.

4) Change the mission interface to be more similiar to ClickSaver/AOMD. No, I'm not asking for it to auto generate missions. It'd be nice to get the basic information easily and have the backstory on a side panel or something.

5) Set lockpicks to work like trimmers. Allow chests/doors to be targetted and lockpicks to be right clicked from the inventory. The current system is clumsy and allows lag to have too much effect on game play.

Interface improvement suggestions
Hey everyone,

just returned from a 6 month break. It's good to be back. :)

Darn, 6 months and the interface is still the same. I'd like to share some thoughts on possible interface improvements.

a) Implement different "views" for inventory/buy/sell/shop item lists. This could work like Windows Explorer, where you can toggle between "Large Icons", "List", "Details" and so on. In AO, this would allow us to switch between "Icons" (the way it is now) and "List" -- small versions of the icons with the item name to their right side -- kinda like it is in *gasp* DAoC (which I don't like much as a game, but its interface *is* better, IMO).

b) Split up the text panel into different "pages" containing various "filters". The main page would display all messages (as it is now). You could switch to "Combat only", "Chat only", "Team" etc. pages to get only the text indicated by the page title. Ideally, the text panel could be split horizontally, like it is set up in *gasp^2* DAoC.

c) It'd be really nice to be able to drag around the interface panels on the right hand side. The right side could still work as a "dock" of sorts, but you could pick a panel and move it to any place on your screen you want. Once you close it, it goes back to the "dock".

Your thoughts?

- Hendrik

More interface suggestions
The chat system definitely needs to be improved. It would be nice to have visual confirmation on the chat window itself as to which channel I'm currently speaking in, so "w/t" isn't my most common phrase. Yes, I realize that the friends list shows it, but that too often clutters up my screen when I need my personal info, team info, and map up at the same time.

Another thing I've been thinking is that the info windows that pop up should be able to stay up while you grab the info for another item. It's so frustrating to try and memorize or scribble down a helmet's AC stats while I check a new mission item to see if it's worth going for to improve my AC. A manual "lock" button on the window would enable this, and the window could then be dismissed when I'm finished.

And my last, most frequent, complaint (in my thoughts if not in my words) is that there is no effective way of creating useful scripts in the game, as far as I know, apart from social moves. (And I would like to stress my ignorance on this matter... if there actually is already a way to do what I'm about to describe, please direct me to the proper tutorial or post instead of flaming--and yes, I've already done a search.)

For example, when I've finished killing a mob in a mission, I usually go through the same 13 keystrokes before I'm ready to go on:

1. Sit (C)
2. Treatment Kit (shift-2; 0)
3. Nano Recharger (9)
4. Stand (C)
5. Heal myself with a nanoprogram (shift-1; 7)
6. Sit (C)
7. Treatment Kit (shift-2; 0)
8. Nano Recharger (9)
9. Stand (C)
10. Switch back to fighting shortcut bar (shift-1)
*The parentheses show my configuration for each action...not a suggestion for the defaults or anything.

The addition of the ability to use key designations in scripts (such as "Key F2" or "Key C", like in Quake 2) would save me a lot of repetitive keystrokes. In a game like AO where you have to spend hours upon hours developing your character (most missions take me at least an hour to complete) it would be better for my hands, healthwise, if these unnecessary keystrokes could be eliminated by simply writing a customizable script.

The other cool thing is that by specifying keys as "Key 0" instead of, for example, "Treatment Kit" would effectively make the scripts dynamic. As my shortcut bar changes, so would the effect of the script. I could create a standard "buff up before hunting" script that would change as I replaced different shortcuts on my nano shortcut bar.

Thanks for your ear. I'd love to hear feedback and additions on what I've proposed.

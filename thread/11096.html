13.7 changes and bugs
In a couple of different threads I asked for undocumented changes and apparent bugs, and will be listing what I've found about them here.

Stationary surgery clinics
There is currently a bug with you not being able to use them after the 5 minutes usage timer has run out, but have to zone to use these again. It's reported, and the cause is known. No ETA.

Closing lockpicked chests
This would render the contents unavailable. A bug, which should be fixed now, and is sent to testing.

Looting bodies in PvP
I believe you're supposed to be able to loot anything the victim aquired after last scan (and a pinky, some say ). QA are looking into how this works now.

Switching weapons (and other equipment)
Equipping an item in a slot already containing an item now adds the equip/unequip timers of the two items, thus making weapon switching take longer time. Logical, though we should of course have informed you of the change. I apologize deeply for this, as I know how this affects certain tactics in combat.

First aid kit recharge
As far as I know it's been 40 seconds 'forever'. Please correct me if I'm wrong. (I don't use them on any of my characters. )

Only one unique item
You can now have only one single instance of a specific Unique item. It was always intended like this (hence the term 'Unique'), so it was a bugfix. Something we ought to have informed you of nonetheless.

For those concerned about this turning into a new 'pillow issue', I'll talk with Support and hear what they think of it.

Find item missions giving worthless pick up items
Some of the items you can get as targets in these missions have always been 'worthless' (i.e. selling for 0 credits). I have taken several such missions after 13.7 and always made sure to get items I knew sold for good cash. If these items are more common now, just make sure you check the mission description closer.

Ok, that's it for now. I'll hopefully be back with more later.

PS: This thread is closed, at least for now, simply because I want the thread to be info only, not lots of new posts and replies. I will link to this one when I add answers to issues I find in other threads.

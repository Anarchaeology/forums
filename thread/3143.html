game content (missions)
First off not sure this is the right forum for this post so if not cosmik please move

Ok heres my thoughts:

The problem right now with alot of the classes is the fact that the game is completely set up for nothing but combat. If you are a class that is not combat based you have a really tough time accomplishing anything without a group. What needs to be done along with the revamping of the classes is some content needs to be added to the game. IE missions. I thought there was going to be a totally unique mission system in this game with diverse missions and roles going to be available. This is simply not in the game. You have a choice of a few mission types which are all the same except for the final task: kill mobs and then find item/person, kill person, take item to something to be fixed and so on. There needs to be alot of things changed with this. My idea is something like for traders for example, go find a person in some other town and bring him an item. Now this would not require any fighting and might be fun to find the person in some house or other place. If you are a clanner and have to take an item to omni territory perhaps you might have to pass a checkpoint for smugglers and such, just to add some bit of difficulty to it. I know this isn't much but I just want to express some idea to build on for the real game designers. There is just simply not any veriety to missions. And this is one of the biggest reasons I started playing AO. Please anyone feel free to add your thoughts.

There is, unfortunitely, much war in the search for peace and my life is gladly paid in full for the price of freedom....

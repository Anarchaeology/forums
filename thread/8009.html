Calculate the cost of raising a skill with cost factor c from a1 to a2 (simple arithmetic series):

cost = c(a1 + a2) * (a2 - a1 + 1) / 2

The cost factor c is the number you find in the following table (it is the cost of increasing a skill first time basically):

http://anarchylore.com/AO_skillscomp.asp

No, it always cost the same amount to increase the skill 100 points whether you do it at 5points per level or 100 at a time. However if you do it slow, you might notice that your skill gets higher if you raise your abilities simultaneously.

The formula should reflect this unless I done a mistake.

Example: raise skill with c=2 from 1-20 in one go or from 1-10 then 11 to 20:

One go:
cost = 2*(1+20)*(20-1+1)/2 = 420

From 1-10 (including 10):
cost1 = 2*(1+10)*(10-1+1)/2 = 110
From 11-20 (already spent points for 10th increase)
cost2 = 2*(11+20)*(20-11+1)/2 = 310

110+310 = 420 so should be ok.

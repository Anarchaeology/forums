Guild Banking System (GBS) idea.
One of the most annyoing things in AO is that items are not easily shared between guild members.

My suggestion is that FC should add GBS to AO. Then guild members could easily drop items into guild's shared storage bank account, where items can be freely accessed by people with the rank of 'Members' and upwards. Applicants should not have access to the GBS.

There wouldn't even be a need for a new terminal. FC could make a selection menu like the 'Wear' menu, ie Normal/GBS selectable menu options.

This way trade within the guild is encouraged and more easily accessible.

A better developed idea for the GBS, would be that each guild member could have their own GBS account which would be accessible by other guild members.

Ie, when first selecting the GBS menu one would get a list of all members, and when clicking on a name, it would bring up that persons shared GBS account. Selecting the GBS menu again would return you to the name selection list. This would of course require three menu options: User account / User GBS shared account / GBS list.

There are of course security issues. Hacked AO accounts would jeopardize an entire guilds GBS. This is why a password system should be integrated into bank access. Entering the pwd would be a one timer per session. Logout, and when you relogin, the pwd must be typed again. This is logical (atleast to me) cause in realday life no-one can access ones own bank account without a key sequence.

I think this idea of mine would vastly improve an organizations trade habbits. Just think of this excellent idea I've given FC. What an outrage if they would not even consider, and encourage development of trade within guilds, and AO in general too.

So guild leaders, let FC know that guilds want and require better and easily accessible trade possibilities between guild members.

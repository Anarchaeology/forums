Ingame Notepad
Numerous times I wish I had the opportunity to write some stuff ingame. Would be cool if we had a logbook/diary, that you right-click to open and then you can write stuff inside. Things like :

Slurmi buffs +132 Wrangle
Psiraven has 930 NP
DAV Medusas coords 3190 1900
Save point in EFP is at 2800 2800

Further taking this idea would to implement an option to copy such a book so I can give a guildie, for instance, a copy of my book.

Also, if we could name this book to something we choose and have several books, it will enable us to have "Guild Rule Book", "Coordinates Book", "PVP book" and so on.

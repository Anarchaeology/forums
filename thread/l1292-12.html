Also, will all classes be able to do Tradeskills with a reasonable degree of success or just certain ones like Trader, Engineer, Doctor that can make their own components?
Making stuff is skill based. Some professions will be better at this than others simply because they can raise these skills more easily. If you wanna invest in the skills you should be able to make some stuff.

You can only raise each skill 4-5 points per level.
Skills seem to have a cap per title (each profession has 4 titles)
For instance, a Doctor is a Nurse til lev15. Nurses can only raise each skill to 50 or 60. At lev15, you can raise skills higher.
Skills cap around 1000.

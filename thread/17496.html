All breeds have special items, even Solitus.

The biggest difference in IP is Solitus / Atrox.

IP to Max Abilities
Solitus 1,371,732
Atrox 1,209,485 (-162,247 compared to Sol)
Nano 1,336,100 (-35,632 compared to Sol)
Opifex 1,253,075 (-118,657 compared to Sol)

The 'Spare IP' is due to Solitus costing slightly more to max all abilities and max nano pool and max body developement.

This 'Spare IP' though comes at a cost of inferior total Nano/Hip points as well as lower base skills in some areas.

Atroxs for example have on average -15 to -30 nano skills comparred to other breeds.

Solitus Base skills with Max Attributes Average 123-124
Atrox Base skills with Max Attributes Average 104-132
Nano Base skills with Max Attributes Average 118-132
Opifex Base skills with Max Attributes Average 118-137

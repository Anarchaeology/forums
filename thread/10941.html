Dimension transfer information
On copying characters from Rubi-Ka 1 or 2 to Test-Live
Yes, this is currently technically possible, but it has to be done manually in each case. This means it takes a lot of time, hence we do not offer it to players at all. If we did, only a tiny minority would get to have their characters copied (due to lack of time), which is unfair.

We choose to rather focus on completing a tool for players to be able to copy their character from the live dimensions to the test dimension. This is part of the process of allowing dimension travel.

On transfering characters between accounts
Yes, this is also technically possible, but due to several questionable possibilities we choose not to offer this to players. It could allow for selling characters, using several accounts for powerleveling and then collecting the characters and closing (or selling) the other accounts, and similar account / character transfers.

Some cases will always be of the kind where we might ought to allow for a transfer, but checking into all cases we would get if we opened for such transfers would take too much time.

On whether Illuvatar will be moved back
The character has already been moved back. At this moment the People of Rubi-Ka pages has not been updated, so you can probably still see him on both dimensions. I checked the character database myself to make sure I didn't give you wrong information. As soon as the page updates properly, you can check it yourselves.

Lack of update on the People of Rubi-Ka pages
The script doing this sometimes (quite often, I think ) reports errors when running (and thus does not complete), and has to be rerun manually later during the day. The guy handling this has been ill for a few days, and such we've had only one update of the pages for the last 3-4 days or so.

---

Got any more questions I ought to cover about this case? Let me know, and I'll see what I can do.

Cz

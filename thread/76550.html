better idea?
Loading all the textures at zone time wouldn't really be feasible. You don't really want it to load textures for some guy on the other side of the zone who you aren't even going to run into, do you? Memory usage is bad enough already.
What I think they do need to do, however, is have some kind of 'background' texture loading going on, with a default texture displayed until the real one is ready. This is a realtime game, so I would rather have someone/something displayed with a default texture for a few moments than have the constant texture-load stuttering we have now.

A use for adventuring skill.
What do you guys think of this. There are scopes in the game that tell us different info on mobs. Level, argo, health and nano.

As the outdoorsie type of people us adventurers should be, I think an item should be added like the scopes that uses the adventuring skill. In one item we can get the info that all those scopes give. The item QL and the adventuring skill would be checked to see if we get all the info, some of the info or none at all. That way it actually gives us the ability to find out more about the mobs we track and hunt.

The item could be as simple as an MA special attack. Instead of a scope to fit more with the adventurer image.

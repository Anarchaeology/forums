Yes, the problem is "a rounding error" (told by GM), so the system believes you dont have enough skills to equip the yalm. Its been like this for as long as I have played this game (about a year).

Add a few more points to vehicle air and the problem is no longer there. Annoying? Yes, definately. Cause I KNOW how eager you are to use it, and that you obviously dont want to spend more IPs on that skill than absolutely neccesary.

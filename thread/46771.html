Professionals Issue Update
This is the most current set of issues which were communicated to FC on the Professionals Board. We put forth an updated list of profession related topics every single week for review and answer by the Community Team. I am posting this here so that you are all aware of the current top list of issues we are working on and so that you can add items to this list by commenting in this thread.

Please remember to make your issues as detailed as possible so that Nettie and I can quickly add them without having to find you and get more details on your issue.

Thanks!
Argulace

quote:
Cosmik, here is a list of current fixer issues. We would like to see some input from someone as to whether or not these problems will be solved.

1. NCU Buff not refreshable.

2. NCU Buff canceled with epsilon purge. This buff takes entirely too long to cast to be effected by EP and it also causes a catastrophe in NCU, mostly disabling the fixer when EP is used because it not only removes the NCU buff but the HOT's which you cannot recast due to lack of NCU.

3. Manex Catastrophe line SMG's not dropping/questable. These guns were put in the game 5 patches ago as part of some fixer loving, to date not one fixer has one on live. Adding this weapon to the summon line would be acceptable as the summon line includes nothing to date which is useful in real application.

4. Fixer special attack weak and self defeating (see fixer thread in professionals forum)

5. Fixer debuff line as previously discussed in Fixer Q&A with DEV team has not been put in the game yet, ETA?

6. Certain items need to be equippable with Grid Armor; examples would include Viral Egg, Pads of Dedication, Globe of Sufferance, Globe of Clarity, Shoulder Pads (armors). Some argue that because grid armor gives hit points these items should not be available to fixers who use Grid Armor, however it is possible to buff hit points more than MKIV grid armor gives so this is an irrelevant argument. We would like the shoulder slot opened on not only Grid Armor but all social armors. Fixers with grid armor do not have the ability to wear armors that boost skills, such as MKII Corona armor, Servants of 8 armor and even our own love armor. Please release the shoulder slot on all social armors, including battle suits for soldiers and enforcers.

7. Summon line should include boss loot items. We believe this will help the eco system in the game because it will lessen the high prices of new items during the first 2-3 weeks of a patch. If fixers were able to summon these items for 12 hours, players would be less likely to pay hundreds of millions of credits for the items, instead waiting till they can find one for themselves or the prices come down. This will also finally give fixers something to use as a source of income besides blitzing missions, which is now obsolete with the introduction of boss loot only items.

8. Bracer of growing flesh/shrinking flesh should be equippable with grid armor as they are both technically also social armor.

Additionally I would like to say that fixers in general are very happy that we finally got some attention in the previous patch and we very much appreceate this attention. However, we would also like to mention that leaving something 1/2 done is nearly as bad as not ever doing anything.

Thanks for your attention to these very important issues.

Gurthang
Eleet
Dungeons as many of you have noticed are made of "rooms" that are randomly assembled to make each mission "unique". Add to each the dungeon modules a series of interconnected "nodes" (the fewer the better) And whenever a NPC or pet has to move to a destination they move to the nearest node and then move from node to node until they reach the one closest to their destination. To handle movement between rooms you make "doorway" nodes which become the destination anytime the objective is outside the current room. The simplest method of node navigation would be to assign direction information to each node connection, and have the npc compute the direction to the destination and then choose the node with the closest match. The other trick would be so long as the destination node does not change to never backtrack (aka use a node twice). Other details would be to make sure there is no nodes with only one link (except for the doorway nodes). This way you can get rid of collision logic and so long as your node designer does their job right you can assume that the path is clear.

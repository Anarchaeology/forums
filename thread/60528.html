Question on Range Extending Utils
Hi all,

I have heard various things about range extending utilities and was wondering if anyone out there knows for sure how they work.

The description on them (Yamaguci ? Range Extender ) notes an increase in range by meters (i.e. 2m, 4m, ..., 50m), but some have noted that this can not be true as when they use them, their range seems to increase by a percentage of the range of their current weapon.

I have done some testing with them and have noticed that my range is increased with them (even though it really should not be...seeing as how I use melee weapons), but with a 3m base do not seem to more than double my reach with the 4m tool. (though there is obviously a difference).

Anywise, any feedback on exactly how these work would be greatly appreciated.

We need more enhancements to IGNORE
I'd like to see some enhancements in the ignore commands:

The chat interface needs an /ignore <name> command. I don't see most of the people who are spamming at me so I can't ignore them. Unless its been changed recently, typing /ignore MrSpam would just ignore whoever my current target is.

It would be nice to be able to ignore people on a channel by channel basis too, perhaps with a /chignore (channel ignore) or /squelch command. There are some people I would not like to totally excommunicate that just spam entirely too much on certain channels. If I'm on the looking for group channel and some guy starts selling on there, then I would like to be able to type /squelch <name> and have it ignore him for that channel only. There are sellers that I know have very unreasonable prices that I don't need to see flooding my shopping channel since I will never be buying anything from them, but I can't ignore them completely because I may need to talk to them or group with them at some point.

I'd like to see the ignore.txt command easier to edit by hand. It doesn't hold names of people you have ignored, but only ID numbers so I can't look through it and delete old ignores that I don't need anymore. Best would be if I can add and delete lines from the ignore.txt by hand to ignore and unignore people, but at the very least I need the game to put some sort of comment after each ID number so I might know what character that represents.

I'd like to see some other ways to filter chat a bit like the ability to filter out certain types of messages with a channel-by-channel word filter. I could filter "selling", "buying", "WTS", "WTB", "wrangling", and "programming" on the seeking team channel, but still hear those on the shopping channel. I could filter "2ho", "clanners", "clan", "invading" from the shopping channel, but still hear them on the seeking team channels.

I'd like some way to filter out any message that doesn't contain an item reference in the shopping channel and any message that does (but not a person reference) in the seeking team channel.

Basically when you try to make a game with a server that holds more people than a single game world has ever held before we need a lot more tools to decrease the signal-to-noise ratio to help so we dont have to listen to every one of those 10000 people.

Area swapping in land control
We're aware of several organizations regularly terminating and rebuilding controllers to continously keep an area's suppression gas at 100%, and even some organizations swapping on who owns the area, to the same effect.

This is not intended at all. It is considered an exploit, and we're working on a code fix for it.

More about the code fix later, but for now, please note that this is considered an exploit, and you risk both suspension and disbanding of your organization upon doing this.

Add-on: This is still in effect and until a proper fix for the issue is implemented we will continue to enforce that rule.

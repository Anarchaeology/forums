Cz - how do keep track of the ideas ?
Information overload !

Reading through these forums is really hard work!

What I do see though is a lot of creativity every now and then hidden often between lots and lots of complaining.

I am concerned that lots of good ideas are wasted because they get buried in the day-to-day noise.

So the questions is Cz how do you keep track of all the input - can you ?

I guess this was in part the point of the professionals program to gather input from each class?

It would be wondereful indeed if there was a set of reference information that was maintained with all the ideas that people came up with - no doubt it would be very useful for the developers as well.

Perhaps a moderator or 10 (not sure how you would work this) from the more helpful side of the user community could help gather the information. These folks would have to be unbiased and would keep and eye out for new constructive ideas and would maintain a handful of sticky threads that only they could edit/reply to. Each thread would represent a particular area - one for each profession, one for GUI - like already exists etc. etc.

Just a thought. The game's not perfect we all know that but if there is a constructive way to make it better then I hope people would be willing to help.

I kinda flinch every time I see a useful idea quickly vanish off the top of the forum to be lost in the noise of constantly new threads

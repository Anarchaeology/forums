TOP 5 suggestions, by class, by breed, social, graphics etc.
An observation I have reading through the various forums is that there is a lot of "noise" and it can become quite difficult to build up a picture of what people want across the different aspects of the game.

My suggestion therefore is to develop with your input a wish list split into different categories - these can be wishes or fixes it doesn't really matter. Once I have some initial suggestions I will run poles where people can cast votes and then update the results regularly. As new patches are released we will obviously need to update the lists.

I know there is a lot of great stuff that others have already written I will try and incorporate this where I find it - any pointers would be greatfully received. If there are particularly good posts I will post the links next to the suggestion.

In the first instance I will suggest some categories and ask you to suggest a top 5 for any category that interests you and also to suggest any additional categories you think should be included.

If there is enough interest and feedback I think we will find the overall picture quite an interesting one

Friends List
OK here are a few things I would like to see for the friends list.
I would like to be able to either create my own sections or have them put in place for :- Guildmembers (got them all on my list), Other guild leaders, Friends, Enemies(you want to know when there are online so you can kick some butt right?), Reliable tradeskill peeps, and so on.

Right now my friends list is a jumble of names, which makes it very hard to sort through who is on and so on. Another thing I would like to see is for mouse wheel scrolling to work on the friends list. It really annoys me sometimes when I am trying to highlight a name or see if someone is online and you just cannot get the right part of the list to show up because you go past it due to the number of people on the list and the slider bar is so sensetive then.

I would prefer to be able to add my own groups to my friends list but will settle for just having new ones added that I can use

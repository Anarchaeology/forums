If you want a PvP group of all the same class ...
I would think that Crats would win hands down. Of course everything is subject to the conditions of the moment.

There is absolutely no way both PvM AND PvP can be balanced between the classes. The rules are just so very much different in each situation. Some classes are going to do well in one and poor in the other. Some classes will do well solo put not as well grouped. A few classes will probably do OK in all situations.

Don't get me wrong. I do believe there are some issues that definately need to be fixed. My vote for the most needed fix goes to the MAs. But even there an MA can be made uber. Just with a Hammer. Of course the same can be said for all the classes. Just go with a Hammer. The inequality between slow big damage weapons and quick low damage weapons is the main problem with game mechanics.

IF this were to be fixed then we can start to take a look at other individual class issues. The game would change dramatically and "balance" would have to be given a new fresh look.

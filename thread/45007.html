Cz, Ideas to enhance scripting(Randomize, and execute on idle)
Unless Ive missed somehow, I belive there is no randomize in the scripts, and im sure there are other things that would be sweet to have in the scripting language.

What I would want, would be a randomize argument in the script, so that if you for example write

%rand(1)
{1} "My master is so über"{/1}
{2} "Whohoo!"{/2}
{3} "Hey, who touched my bum?"{/3}
%endrand
/pet chat %r1

It would randomly choose from one of the 3 each time you execute the script.

It could also be like this.

%rand(1)
{1} /disco
/me throws a party
/delay 5000
/ymca
/say Whohoo! Lets rock!
{/1}
{2} /pointlef
/say This way!
/delay 1000
/say No, that way!
/pointrig
/delay 1000
/angry
/say Argh, Im so confused
{/2}
%endrand
%r1

If you use more than one randomize in a script, you'd simply add more and use different numbers (%rand(2) %r2, ect)

Now, the second thing I would like to see, that happens when you stand around for a long time, doing nothing, would be able to connect a script or something else to execute. For example
/setidle /backflip
or
/setidle /idlescript

Now, I belive that it should not be possible to link other scripts within scripts, to avoid looping. Like:

Script1
/say "Ultraloop"
/script2

Script2
/say "Megaloop"
/script1

If anyone can think of more things to enhance the scripting language(well, it might not be that advanced to be called a scripting language, but it might be in the future, i hope)
please post it here.

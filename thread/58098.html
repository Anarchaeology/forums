GUI Enhancing (Extra Chat Options) How-To
Many of you have been suggesting that we the ability to use the OOC chat by just typing /ooc. Well I'm here to tell you that this is quite possible (I have already done it). Its as simple as creating a few macros within the Anarchy Online\Scripts folder on your computer. Also, I am going to assume that you know how to use the scripts folder.

For the OOC chat channel, you're going to need to create a file for a macro in it called "ooc". Ensure that you don't have an extension on the end of it so the script will work.

Within the file you'll need to type:

/g "Clan OOC" %1
- or -
/g "Omni-Tek OOC" %1
- or -
/g "Neutral OOC" %1

Depending on which faction you are from. The %1 just uses whatever you've typed past the script name and places it within the script for usage.

The same basic principles apply when talking to your organization/guild. However, since the /org has already been reserved by the game, I've been using just /o. Same concept here, just create a file for the macro and call it "o".

Within the file you'll need to type:

/g "<insert your guild name here>" %1

Thats just how easy this is to do. Use these same principles to create macros to use the shopping channels also.. don't forget that you can always create one to post items on all 3 channels at once.

/g "Clan Shopping 1-50" %1
/delay 1000
/g "Clan Shopping 50-100" %1
/delay 1000
/g "Clan Shopping 100+" %1

So when you place the item in the chat text it is sent to all three instead of doing each of them individually.

Hope this helps with what you guys have been asking for quite some time now.

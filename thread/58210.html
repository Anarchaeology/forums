Bio's got it.

Hopefully, instead of Diablo's *very* limited set, they'll follow the Tribes 2 mold and include very detailed menus.

For example, in T2 you hit:

v (voice)

And are given the options

T (team)
S (self)
G (global, prolly wouldn't make it into AO )
B (base)
V (quick messages)
etc, etc...

Let's say you picked the V menu, the quickbinds.

You'd then get options like

H (Help!)
N (No.)
Y (Yes.)
Q (Quiet.)
A (Acknowledged.)
C (Got you covered.)
F (I've got the flag!)
etc, etc.

If you used the S menu, you'd find options like

A (I will attack.)
D (I will defend.)
R (I will repair.)
etc, etc.


So, to say "I will attack" you hit VSA. To reply "No." you hit VVN. Once you learn the binds, you can do this really quickly.

The system is pretty detailed, and very useful for communications amongst a team.

If FC implements a good system like this, detailed tree implementation, especially with replaceable binds (have a guild voicebind set for customized voices), then I'd definitely be happy with it.

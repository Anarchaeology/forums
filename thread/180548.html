Changing Agg/Def via Keyboard
I'm not sure what Funcom's view on this is, but I've always wished that there was a way to change your Agg/Def setting without having to use the mouse to drag the slider... especially in those really laggy situations where the mouse moves like i'm trying to drag a small horse with it.

Even a keyboard command of some sort to set it to full Agg or full Def would make all the difference in the world to me and others I'm sure.

Yes this would be great. Either keyboard shortcuts or commands we can macro, ie /aggdeff 50 for setting AggDef bar to 50% so /aggdeff 0 would be full def.

It would be of most use in PvP, especially tower battles where trying to use a mouse to do anything is a waste of time alot of times. But it is also useful for other situations, ie a Doc grabs aggro in a high level mission, no time to slide to Full Def and continue healing before those crits start adding up. Even as a soldier I find being able to go to full Def at single keystroke very useful in team missions, if I see the Doc is low on Nano and unlikely to keep up heals if I have aggro, I can the have a choice of using TMS or going to FullDef. I would prefer going to FullDef for a while then using TMS if its not totally needed.

It would provide an easier way for people making 3rd party tools to write an application that could automate combat.

But as applications like ClickSaver and AO Damage Dumper show, you don't need to have the keyboard commands to grab control of the mouse or get chat output, you just need more programing skill.

My opinion is, if someone really wants to automate it, they're going to find a way to do it. So in the end the point is moot...

It would be nice indeed, I suggest mapping it to the -/_ and =/+ keys to move it up and down by 25%.

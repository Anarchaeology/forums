From the Test Server Launcher:
quote:
Changes from 14.2.0.2-14.2.0.3

General changes:
-Fixed a problem where some items showed the wrong description.
-Tarasque now have more hitpoints, and should use all of his nanos. That means both DoTs, AOE and DDs.
-You will no longer log into windowed mode even when windowed is unchecked.
-Armor will now be effected by over-equipping as it should.
-Fixed a bug where Soldier could use the MK shield under the effects of the "Nano Inoperative shutdown" period.
-All three parts of the Trash King quests are now implemented.
-We have adjusted the new player rules. Death penalties are now:
1. No loss of items until lvl 10
2. No Resurrection Shock until lvl 15
3. No loss of XP from death until lvl 20
-The limit on pets NCUs will now have an actual effect.
-NCU components have had their equip time lowered from 30 seconds to 10 seconds. However, the Belt component equip time has been increased to 1 minute 10 seconds.
-Fixed a bug where NPC's wearing certain armor appear bugged.

Changes from 14.2.0.1-14.2.0.2

General changes.
-This patch contain a new launcher, and a new patcher.
-We have removed some templates that caused problems with certain items for a few players. The correct templates will be added in 14.2.0.3.

Changes from 14.20-14.2.0.1

General changes:
-You will now have the possibility to take a backup of the patch after downloading it.
-We have changed the version ID numbers.
On Live, the patch announced as 14.2 will be named 14.2.1.
On Test Live the patches will be named 14.2.0.1, then 14.2.0.2 and so on.
This will not make any difference for you, the players, it is only a change for internal use.
-The names have been changed on pf 565 and pf 567. Pf 565 is now "Newland Desert", and pf 567 is named "Newland".

IP reset:
-We have added feedback when you try to reset ACs, or other non resetable skills.
-You no longer have to target yourself to preform an IP reset.
-You will now get an IPR point at level 1.
-The full IP reset should now work as intended.

Org changes:
-The "Ready to accept votes" will no longer appear every time you zone.
-Org commands will now accept nordic letters. (ÆØÅ)
-You now pay tax when you logout/disconnect from server. When deducted, you will get a message saying: "You were deducted X credits organization tax." NOTE! The tax system is still being worked on, so this feature is still not complete!
You will note there are some changes that were made in the last patch revision that would have prevented the patch from going live (for example, armor OE not working till then)

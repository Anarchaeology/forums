Solution: I've been using dual (and now triple ) monitors for years now, so i've managed to experience all the joys and woes related. The problem you are having is related to DirectX. Basically an application chooses which "device" to use as its hardware. Once the device is chosen it then uses that hardware to do all the 3D graphics and display them. What is happening is that AO is using device Y but the window is appearing on the monitor plugged into device X. A graphics card like the FX 5600 has two outputs and tells windows that they are two seperate devices, which they kinda are. AO will always display on your PRIMARY monitor, which is set in the display properties settings. Now if you have the other device, which isn't primary, as AO's device you're gonna get a black screen.

The solution is to either change the device AO uses (which I don't think works???) or change which monitor is your primary monitor in the windows display settings. I say that changing the device in AO doesn't work because I can choose any of my devices from the device list and it still outputs on my primary monitor. Anyway just change ur primary monitor to a different one. Take heed though the GeForceFX 5600 (and very likely all cards using the NView application) can change which display is which in the nvidia settings as well. So goto the advanced tab for your FX and it has a picture of both ur screens, you can change the order of the screens here (they do it just to confuse you i'm sure). So in theory you will have 4 combinations to try out alternating between the windows and the nvidia settings, just change the setting and launch AO (no need to restart). And you have to shutdown AO each time you change the setting.

Also note that some applications use Overlay or DirectX to display video files so you may experience the same situation where by you can only watch videos on one of you monitors, however dragging the window to another screen usually works in this situation. I haven't had any problems with displaying video on all 3 screens for a while yet however, seems to be a thing of that past which rocks!! Shame about DX apps tho.

1 Other thing, this doesn't hold for ALL DX apps, so some may work on all ur monitors (confused yet?)

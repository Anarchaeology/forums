Oh well who cares. Here it is:

The uber HoT and NoT spam remover for AO (omg!)
Executable: http://cancel.org/nospam.exe
Source Code: http://cancel.org/nospam.c

Simply run nospam.exe and it will remove the following spam text:
You increased your nanopool with X points.
You got nano from X for X points.
You increased nano on X for X points.
You got healed by X for X points of health.
You healed X for X points of health.


The program does NOT modify any files, it only modifies the memory of AO.
This means that you will have to run it every time you start AO.

Whether or not AO is running when you start it does not matter.

I hope fixers and NTs will find this program useful.


Oh yeah, it only works under Windows NT/2000/XP...

Range Monitoring Changes Needed
Project Managers,
I have been experiencing the world that is Rubi-Ka for several months now and find only minor suggestions that would help mage-type classes out in playing the game... This feature revolves around the Range Monitoring. You know the one...the target selector with the red dots that highlight when melee/range weapons are within range... I currently have a doctor and an NT with out melee/range capablity and find that a "Blue dot" is needed to determine the range of nano programs for healing/nuckes etc.... I personally would love to see the right red dot turn into a "Blue Dot" that can range estimate the POD/Player distances for gameplay. This would help mage class characters out tremendously if this is possible to integrate into one of the future patches...Thanks for the time.

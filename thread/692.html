Measure Twice, cut once
There used to be a point where I would get frustrated with actions taken regarding the game, sadly I am no longer suprised by any action taken.

Case in point:

For a long time NT's begged to have the range extension line of NF's fixed. Time and time again patch's would be released without this change included. Finally in 13.00 the range extension line of NF's are fixed. What happens then? It's detemined that with range extension NF's and range extenders players are able to cast outside range of view. Ok, I think most would admit this would be an unfair and unbalancing advantage. So we have an issue which needs to be addressed. There are a few options to address this issue.

Option 1- Limit NF casting to viewable distance or 80M (allowing full benifits of *finally* fixed NF, used with hardware range extender.

Option 2- Leave range extending NF's broken, as at least all casting professions would sitll have some extended range but not outside viewable distance.

Option 3- Comprimise, set NF casting limit at 60M so somone using the *repaired* NF's which prompted the change would get the full benifit of the NF (not using a range extender)

Option 4- *The one chosen* Set NF range at 40M (1/2 view distance? ) which laughably, now reduces the range *below* the benifit of the NF's that were fixed to cause this change.

So let me get this right, you fix the range entending NF's find that they cause a game play issue, and the fix is to lower range *below* the range benifit of the NF you fixed *without a range extender* ?

As I hope you see, it's really not worth getting frustrated about, if the laughable nature of these actions are not obvious in retrospect then to continue to complain is pointless.

Do I think the funcom team intends to frustrate it's player base *NO*, they seem like decent folks trying to make a fun game.

Do I think the funcom team is at times there own worst enemy, *YES*, when *fixes* and *improvments* leave players in a worse condition then the original problem, it leads to major frustration (or used to).

If I can make one suggestion, as the son of a carpenter, "Measure twice, cut once"

Voices
The new voice ability are going to die quickly if we don't use them to better advantage. I'm referriing to making our own voices and then making them available to everyone.

With Custom voices you can have files that say hello and goodbye, wait, stop, oops, nevermind, save, thank you.

Imagine you are hunting with a team and you have sucky runspeed and you want to say Stop a Minute so you can catch up
or you need to buff and you say Please Wait.

All that is required is the voice file plswait_01.wav a text file plswait_01.txt and a script plswait that has the command /voice plswait.

I have created such a setup and it is available at http://www.bedtrick.com/download.htm

There are 2 zip files one with voices and one with scripts
the download description next to the link explains where to put files.

There are 66 voices in all. Check them out, please and give some feedback on this thread

How to Install
Download the customvoices zip directly into
For Live
c:\Program Files\Funcom\Anarchy Online\cd_image\sound\sfx\player\
For Test
c:\Program Files\Funcom\Anarchy Online\cd _image\sound\sfx\player\

Unzip the file and the voices are installed.

Download the voicescripts zip file directly into
For Live
c:\Program Files\Funcom\Anarchy Online\Scripts
Foir Test
c:\Program Files\Funcom\Anarchy Online Test\Scripts

Unzip it and the scripts are installed

sfreadme.txt contains a list of the scripts and what each sound says.

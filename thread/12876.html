Fixer Grid Quest

There are two different quests, for two different nanos. The first is just for the fixer and the 2nd is a team version.
Part one, from the Mockers [LINK BROKEN - sorry, will fix it when the mockers get their **** together. Meanwhile, anarchy arcanum also have a guide here]
Part two, from Greystar, AO-Stratics
Part I + II, from AO-fixer

******************************

NCU Hacker Interface

NCUHI (NCU hacker interface). You want this.

Combine a Nano Programming Interface with a Lock Pick (regular, not personalized).
Takes 25 Nanoprogramming skill and 60 Breaking and Entering to do.
Right-click it every level and it will level up with you all the way to QL 200.

Still don't get it? Go check out Anarchy Arcanum.

******************************

Implant Disassembly Clinic

Implant Disassembly Clinic. You want this too.

This clinic is used to disassemble normal implants. It removes all clusters by destroying them and returns only the Basic Implant. (You 'use' the Implant Disassembly Clinic on the implant.)
But that's not the best part.
You can also wear it in Utils slot 2, and by doing so it raises your treatment skill.
Hack a Portable Surgery Clinic using a Hacker Tool and then combine the Hacked Portable Surgery Clinic with a Implant Disassembly Unit (from the fixer shop).
As with most things that are built, it would be wise to get help from an engineer, or other trade skill specialist, because it takes quite a lot of skill to build one.

Still don't get it? Go check out Anarchy Arcanum.

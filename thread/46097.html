A solution to PVP and Mezzing
Posted this in the Next Patch forum, but Id like to hear discussion on this particular idea, as I think it may have potential if we talk about/refine it a little.

Anyway the discussion was over how to implement roots/mezzes/charms in PVP. Here is my suggestion and psot away.


How about this...

They make a new line of general Counter Buff's.

The counter buff QL would be checked against the mezz/charm/root QL. Suppose you were an 85 enforcer and got rooted by a QL 70 root. In your nano program pool you have 3 different counterbuffs. One at QL 60 one at QL70 and one at QL 80. Also assume that the root (or whatever but I got an agent so Ill use root) lasts for one minuete. The QL60 buff wouldn't remove it but It might reduce the duration by a certain percentage (I'll leave it to funcom to test this and decide how it should work) the QL 70 would remove the root outright. The QL 80 however would actually turn the buff back on the caster, rooting him for a certain percentage of the duration of the original buff ( the dame amount that the 60 debuffed it)

This would do several things. First it would stop some low level noob from rooting you for 5 minuets and running off. Second, it would provide functionality in PVP for the root/buffs. Third, if you set the nano init times right, it would still be an effective way of useing these buffs to get away. Finally it would add balance in that non rooting/mezzing/charming players would have a way to cast these spells but only if it were first cast upon them. THis would prevent an enforcer from mezzing a poor agent and then pumeling him/her like a 8 year old school girl (well that was jsut tasteless).

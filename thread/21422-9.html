I am deeply concerned about the repressor item. And how it can be used with other taunting nanos and devices. The device as implemented doesn't help the team and doesn't add anything to team play other than a way for agents to reduce aggro toward themselves. There also seems to be some confusion as to whether this is a device or a nano line...I'm fairly certain it is a device like the da taunter and aggro enhancers...especially since its in item changes and not nano changes.

Docs don't have green psychology skill which is why I'm assuming that they didn't get a similar item. It isn't available to everyone because such an item would be too powerful in solo play for pet professions. A deaggro device is needed in the game. However it needs to reduce the hate a mob has for the target it is attacking rather than reducing the mobs hate toward the user of the item. An item that reduces a mob's hate toward its target would be useful to the group as a whole. If the item was implemented this way an agent using such a device would be useful in aiding the tank in perform his job more efficiently. That way if a mob aggroes anyone and the tank is unable to taunt the mob off of him then an agent using a repressor could use the device on the mob attacking who was aggroed. The hate of the mob toward the player who gets aggroed could be reduced by agents using the repressor then the tank could then taunt the mob off of the aggroed player more easily. This implementation would not only help agents it would also help the team itself. It would also be a valid reason for a group to want an agent.

Agents are worried about the repressor. It does help us in regard to aggro as currently implemented but think of this scenario. An agent goes to pull a mob. He uses his aimed shot and amazingly it actually fires. The mob now has extreme hate toward the agent. The agent runs back toward his team while being attacked by the angry mob. The agent uses the repressor and the doc tries to heal the agent...because the mob is beating him senseless. The mob then switches aggro to the doc and the tank is having trouble taunting the mob off the doc. The doc then dies because an agent used a repressor and the agent is kicked from the team.

If the repressor reduced the hate a mob has toward its fighting target making it easier to be taunted off. If the repressor worked this way then we could help save the doc by using the repressor on the mob reducing the hate it feels toward the doc enough so that the tank could taunt the mob off of him. The agent stays alive, the doc stays alive, and the group continues to hunt the rest of the day. In this scenario teams would have a reason to want an agent on the team.

Boots for used items
Selling old items and loot can be a tedious affair in AO. It usually takes a lot of time to find buyers for the stuff you want to sell and if you are a buyer it is difficult to find things you are after if you don't have the money to buy new stuff from the shops.

Therefore I suggest putting up boots for used items. These boots function mainly like a normal shop boot, but with a few exceptions. For a buyer the difference would be that there are only one item in each slot, while in a shop boot there is no problem buying two of the same item if you find what you want. The difference for the seller is that instead of accepting the price the shop boot offers, he/she themself defines the price they want for the item.

Variants might be "Wanted" boots where players can tell their interest for a certain item and Auction boots where players can sell items to the highest bidder.

I can se that there are several gameplay issues one have to be avare of before creating these boots. The biggest one being that with a system this simple for trading with used goods, it could be difficult to control the balance of the game since FC have no direct control over prices on items and it would propably become a lot easier to get hq items at a low price.

Comments?

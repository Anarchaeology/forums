/gps set 812 2623
A simple but very useful tool would be a /gps command.

Something like this:

/gps set x y

- set your GPS target to x/y. You'd get an X on the map and the waypoint indicator on the compass, just like when doing a mission with uploaded coordinates.

/gps clear

- remove your current GPS target.

Of course, zoning would also perform a /gps clear, since coordinates input in a zone are totally meaningless in another.

What does everyone think? I know I would love it.

Faction ideas for Rubi-Ka
I read on the test server discussion about plans to add a faction to Clan and Omni for switching sides. However the plan seemed to be just to have two faction Clan and Omni with no differences between groups and no one else represented on Rubi-Ka.

RP wise I'm a little disgusted at having my Pilgrim character lumped in with Sentinels as "just Clan". Many neutrals want their own faction as well and don't want to be lumped into the same group as ICC.

Could we please get a few more factions for Rubi-Ka if you intend to implement this?

Some possibilities like:
Neutral
Jobe
ICC
Independents

Clan
Sentinels
Knights
Eco Warriors
(Council of Truth if FC wanted to reduce it down to Sentinels and that)

Omni-Tek
Omni-Prime
Omni Command
Omni HQ

The diversity would be more fun and would allow people to associate within their proper roleplay faction better. It would make the story come more alive in-game as the game mechanic would support the differences better. I hope something like this is considered for a later patch.

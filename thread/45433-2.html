A proposal for roots in PVP:

1. Make the roots unbreakable for a set duration (10-20 seconds?) by using current self-casting root breaking methods.

2. Root will break when attacked by another character, at end of duration of spell, when caster moves out of range (25 meters?), caster loses line of sight to rooted character, or when caster dies.

3. Once root breaks, character becomes un-rootable for set amount of time (10-30 seconds?)

This allows the rooter to move out of range from an attacker but doesnt overburden the root vulnerable person.

I can see possible strategies to defeat this method. Melee character has friend cast root on him/her prior to entering PVP, then has root broken by above method, meeler is invulnerable to new root for the 10-30 seconds.

But if invulnerable time was set low enough, this would be a very risky strategy to employ. If the invulnerability time is set too high, then the casters are at a sever disadvantage. So the invulnerability time is the critical part of this proposal.



Similar rules may work for the calm/mezz line

Possibly the end of AOMD
Here are some excerpts from a conversation on the Test server bugs forum.

FC programmer: 24th April
"We will be testing new network code on the Test Server later today. The goal is to reduce network traffic, which will help people on low bandwith connections when they get into areas with lots of traffic who encounter a lot of packet loss. You will not need a new client, since the code for this is already in the 14.1 (aka 14.07) client, we're simply turning it on now.
Naturally, if you are using some third-party tool, you might encounter problems after this change."

AO Player:
"AOMD not working is probably because of the new network code, above. Perhaps they're now compressing the packets or something."

FC programmer:
"Yes, the data is now compressed. It cuts down the traffic by a factor of 3 to 4, and the extra cost in CPU seems to be negligible - I did some testing under simulated high load here, can't tell a real difference. So that's good."

So unless the new AOMD cabal can work out the compression format (which will be pretty tough unless its RLE or something easy), then I suspect this will be the end of AOMD.

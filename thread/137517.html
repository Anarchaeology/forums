I had to work this out a while ago - there are three methods:

1) Install two copies - you use the Test Server tool for this. Never done it.

2) Run the same install twice, changing process priority - difficult and it didn't work for me.

3) The method I use atm; open AO - accept EULA, while it's checking integrety, open AO again, and you'll get another EULA - accept this. You then have two copies and can log both in. The first log in will go ok, but the second wil ask you if you wish to run the second copy - click yes and wait.

Notes - on my 700mhz, 512, GF2 GTS I find it a lot better to run in 800x600, 16-bit for both - this also allows me to see almost all of both windows at the same time. Also, zoning, logging in etc can take longer, be patient.

Good news and bad news here...

Good news is you do not have to have AO loaded twice in order to run 2 accounts. You merely load AO with Account 1 (in windows mode or the dreaded alt-tab crash will kill you), alt-tab back to windows, reload AO from the same icon and scroll to Account 2.

You will get an error message stating that there is already an instance of AO running, are you sure... Reply, yes that you are sure and you will have 2 instances of AO running. Remember, this must be 2 separate accounts, and not 2 characters from the same account.

Now for the bad news... You used to be able to run 2 instances with very little performance drop, however recently (last 4 or so months) when running 2 instances of AO I have noticed a SIGNIFICANT performance drop and if you run it too long, 1 will eventually crash.

So, I can confirm that it will work, it will work from only 1 installation of AO, but if you are doing it for levelling purposes, etc.... I would recommend a second PC.

The key to running two or more instances of AO at the same time lies in the processes' thread priorities... try this:

Start up your first instance of AO.
Log in like normal.
Start Windows Task Manager (shortcut: Ctrl + Shift + Escape)
Choose the processes-tab.
Find the AO-client process (Should be named clientr.exe, the one hogging all your memory )
Right-click it and set its priority to Below Normal.
Now start up your second instance. You'll be notified that AO is already running, and you can choose to start or not... click "Yes".
As soon as you log, you'll see another clientr.exe-process in Task Manager.
Set the priority of this to Below Normal as well.
The two instances will now share your CPU fairly well, and you can happily play both at the same time (missioning like this can be really fun! )

However, I too have noticed that the clients crash more often like this than they used to... started about 3-4 months ago, and it's starting to annoy me

started this two weeks back
GeForce4 Ti4200 (128Mb), AMD 2000, 512Mb Ram, WinXP (latest patches and updates)

I have two monitors attached to Ti4200. Use nVidia's driver to stretch desktop across both screens (not windows -- that one isn't very good, and will keep crashing Anarchy). Desktop resolution set to 2304 x 864 (which turns to be 1152x864 per screen). 16 bit colors.

Run Anarchy once (1024x768 windowed, 16 bit textures, medium quality, compressed textures). Once logged in, run 2nd anarchy. 2nd account (same as everyone else described).

Setting that you can play with is, in System Properties (right click "My Computer" choose properties), Advanced / Performance / Settings / Advanced -- Processor Scheduling switch between Programs and Background Services. Both windows run pretty well but jittering when on "Backgroud Services". When on 'Programs' active window runs pretty well, but inactive pretty bad.

I run this way and actually use alt-tab to switch between, because moving the mouse over very jittery AO is a bit painful.

This setup works a lot better for me than two computers, two keyboards, two mice...

I crash a little bit more often than when I run only one instance of AO, especially if I zone on both of them at the same time. :-)

Ohh, login server timeout has to be 90 seconds -- 2nd copy sometimes gets to wait way too long.

Sidenote: running one AO over 2304 x 864 two screens (must be windowed mode) can get a bit dizzy.... :-) but it's fun.

Another note: ClickSaver talks to whatever AO instance requested missions. :-) BUT while running the Buying Agent, you still have to leave focus on the instance pulling missions.. Gah.

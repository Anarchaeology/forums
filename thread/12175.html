Now that you have your test copy of Anarchy Online, you just need to launch the test version by executing the Anarchy.exe in the newly created test folder.

I don't recall the duplicator making a desktop shortcut for the test copy.

Once you launch the test copy of Anarchy.exe it should try to connect to the test server. So the launcher login message will indicate that you are connecting to the test server and not the RK1/RK2 servers.

Well, the test server is currently down and has been for a while.

I suspect that is why you are seeing it showing Rubi-Ka 1.

If the test server was up, then the launcher would have been able to fetch the test server dimension information. Since the server is down, it uses the live server dimension information that got copied over when the folder was duplicated.

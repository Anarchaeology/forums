Businesses
Sure missions are great for cash but wouldnt it be good to get money fast some other way for a change? People should be able to get jobs, set up businesses and recieve money from omni tek if they are a good citizen etc. etc.
You could work in security, entertainment, engineering, as a hired gun, assassin, anything!
You can do some of these things to a certain extent now, but funcom really should make jobs like this more official, like if you could buy property for offices or places of business.
There could be jobs provided by your alignment like Omni-Pol, or people could set up businesses in a similar way to an organsation.
All this can't be to hard to do, and would add a lot more to the game.

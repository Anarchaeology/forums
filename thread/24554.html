How about some contraband items
Ingame ones

For instance your wearing items specific to the other side so the guards kill you for it if they see you wearing them

Obviously this would have to be done delicately

Omni, neutrals and clan would have different ideas of what is contraband and what is not

For instance clan would consider omni armor contraband (i hate seeing clan wearing it)

Omni would consider clan armor (well steel ribbed obtru, nadir IS clan armor) contraband. As well as things like the clan shoulderpads for the su****ious (to prevent people from wearing items of the other side). And possible some illegal weapons and such (side note fixers would be able to bypass sensors to hide contraband)

Some people might think this would be a harm to teh game it would actually give some balance and allow for side specific benifits that would STAY with the side and not be allowed when sides are switched.

Effects of being caught with contraband would include being kos to all guards and npcs of the side in which the item is contraband to. As well as not being able to use save terminals/shops in the case of omni/clan contraband.

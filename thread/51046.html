IPR, Tokens, Level 190
With the current token board / IPR implementations, the end of the line brings about a question...what now? Am I stuck with the way this character is? How can I be stuck in this sense when AO is a quasi-skill based game??

When you reach the 1k board, there are no more boards after that and I don't think there ever will be. Likewise when you hit level 190, there are no more title levels for you to reach, effectively ending the chance to get any more IPR points.

So....

Why not make it so that once you've reached the 1k board, every physical token after that becomes redeemable for 1 IPR point?

Some have suggested that making IPR more accessible would create more exploits. Using the idea above, I don't think it would. With the OE and caps in effect, there wouldn't be a way for someone to use the above in a method which would allow them to equip something without having to sacrifice something else as IP is not being added, simply shifted.

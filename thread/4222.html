Skill Test
I want to suggest one major change that for me will correct somekind of injustice. This change oppose "weapons users" and "nano users".


When a weapon user want to use a weapon there is no skill check. The only test that will be done for is whole life happens when he want to equip the weapon for the first time. So he can be over buffed equip a mega weapon then use it every time he wants without any check.

When a nano user want to use a nano that are his weapons there is a check each time he wants to cast it. More for an engineer there a a check when he memorize the nano for the first time then a check when he cast the nano and a third one when he activate his pet. So those guys need to find a MP and a trader each time they want to cast great pet, nano.


This MUST change and for that there are 2 ways :

1) the hard way that will make cry many players. Put a check on weapon. You want to shot with it you dont have the wkill it wont fire. Make the weapon unequip each time the people LD, die or log out (engineer pet vanish each time that happens).

2) the soft way. Make a check when you memorize a nano then no more check you had the skill to memorize it ok you dont have it anymore but the nano is memorize well you can use it. And dont forget remove skill check on engineer robot shell.



Now some people will say that Nano do superior damage than weapon. Ok but check the casting time Big damage big delay up to 10 ven more 15 sec for a cast. Your nova flow QL 1 or QL 200 still has the same delay while nano delay increase with QL. So thats not an argument.

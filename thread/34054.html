Prior to the 14.2 patch, the patches had even revision numbers for tha actual patch, with odd revision numbers for 'fix' patches. With 14.2, a new numbering scheme was introduced, with 14.2.0.x being testserver patches, 14.2.1.x being live patches, with the x used for consecutive 'fix' patches etc.

However, I suspect they are still only doing even patches to avoid confusion since certain things had already been promised for specific patches using the old numbering scheme. Whether this will continue or they'll start using the odd numbers too, i've no idea.

1000 Token Board Change
Board Name: Double Sun
Token Reqs: 1000 Tokens

Wear Reqs: Title Level 4
Benefits: Max Health +700
Max Nano +700
+7% Experience
+7% Defense
+7% Offense
+4 to All Damage Types
+210 Run Speed
+210 Computer Literacy
+210 Nano Programming


This is a great enhancement to any character, but Docs, Engineers, MP's, NT's, and Traders get a little bit more out of that +210 Nano Programming than the rest of us, don't you think? Every class benefits from all of the other stats, but that +210 Nano Programming seems a little off-balance.

I think it would be fair to add a few other stats that would be useless to Docs, Engineers, MP's, NT's, and Traders, but beneficial to the other classes. Or, better yet, make that last stat variable, and when the character reached 1000 tokens or level 100 (whichever came last), they would be able to use a /command that would enable the last stat. For instance: /command 1ktoken np (where a character would be better suited with an extra +210 Nano Programming), or /command 1ktoken conceal (where a character would be better suited with an extra +210 Concealment). There could be a few different stats to choose from, and only one could be chosen. As an Agent working toward my 1k token board, I would really like to see +210 Concealment on my board instead of the useless +210 Nano Programming, and I am sure other classes can think of something that would be beneficial to their class that wouldn't be seen as unbalancing by the other classes.

Possible fix for dimension problem
This is a possible fix for people who are experiencing trouble reaching the dimension server.

This fix is only ment for client version 12.1 of Anarchy Online. If you have a lower version, please download the executables and patch it before applying this fix.

Please note that I do not take any responsibility for any problems that this may cause:

Just download the file located at http://home.no.net/westwon/dimensionfix.zip and unzip it to your Anarchy Online directory. Overwrite every file.

This package does not include the file Anarchy.prefs as this include the login information (I believe). If this fix doesn't solve this problem try deleting Anarchy.prefs before applying this fix again.

The fix was spotted at this forum, but it included getting the files from another computer. So thanks to the author of that post, I would not have thought of this otherwise.

Hope this helps!

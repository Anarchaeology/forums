Booster CD Key and existing accounts.
Within the booster pack you will find a CD key for the booster. This key is only good to update an existing account. Thus if you are a first time purchaser of the product you should install the accompanying base client and use the base client CD key, this will grant you access to the base functionality of AO and grant you the standard 30 free days of gameplay associated with the base game first time purchase. From there you can install the Booster Pack and use the Booster Pack CD key to upgrade your existing account to a Booster enabled account. If you already own the base client feel free to pass this base client and base CD key along to a friend. However, should this friend desire to gain access to the functionality within the Booster Pack they will need to purchase the Booster Pack to obtain a Booster Pack CD key to upgrade their account to a Booster enabled account. Hope this clarifies the situation regarding existing accounts and the Booster Pack CD keys.

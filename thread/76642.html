NVIDIA 40.72 Drivers causing problems
It seems the 40.72 drivers from the NVIDIA site (http://www.nvidia.com/) are causing some font distortions in Anarchy Online.

The fix right now is to just use the previous drivers, the 30.82:

Win98/SE/ME:
http://www.nvidia.com/view.asp?IO=win9x_30.82

Win2k/XP:
http://www.nvidia.com/view.asp?IO=winxp-2k_30.82

(Be sure to uninstall the 40.72 drivers using the add/remove programs function in the control panel before installing these drivers)

The issue has been reported to the developers, but I'd like some information from people who have experienced this, and possibly from people who use the 40.72 drivers and do not have any problems (I would have imagined we'd received more email/posts if it was happening to everyone using an NVIDIA card).

So if you are using these drivers, please reply with your video card, OS, and version of Direct X, and state whether or not you are having problems.

**edit: It may only be a problem with Win 98/SE/ME **

Thank you

Possible Fix for the Font block problem Nvidia V 41.09 (40.72)
Hello all.

I believe to have found a way out of the font block problem with the new driver from Nvidia V 41.09 and possible V 40.72.
Here is is:

Install the new Nvidia driver (V 41.09 or 40.72)
Put your desktop into 32bit
lauch AO
in the settings menu, put the Texture Quality to low and the Texture color quality to low.
Next Login and tick the game to run in Windows mode.
Start AO.
The game should now run without the blockes.
Next log off the game and restart it.
Now put the Texture Quality and Texture color quality to the level you want, and u should be fine as long as to play AO in windows mode.

Press report is this helps!

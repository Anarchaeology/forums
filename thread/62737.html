Pit Lizard workaround so they can fly again.
I was reading up on some old patch notes and noticed that the Adventurer polymorph had it's flying disabled - Which seems rather odd with those giant wings.

Anyways, I could certainly see the merit in the fact that you should not be able to fight and fly at the same time.
The inspiration came to me when I read the description of a Polymorph Nano - Must have normal shape.

It hit me that if you can check for normal shape, then you should be able to make a check for what other form you might be in. So I mulled it over for a time and came up with the ide of Polymorph Focus Nano's.

Thus I propose the following nano to be made :

-
--
---
Nano Crystal (Pit Lizard Focus: Fly)
Quality level: Special
Requirements:
Use:
Bio Metamor from 818
Matt.Metam from 743
Sensory Impr from 743

Charges: 1 (splitable)
Mass: 0.1kg

Description:
Nano Crystal - Due to some problems with the original shapeshifting nano's, the nano's was revised by independant scientists and was split into the basic shape shifting nano's and the Focus nano's, so an adventurer could focus on whatever he wanted to actually do.

This nano is focused on flying as a Pit Lizard.
Fighting while focusing on flying is not possible.

Item contains a formula:
Pit Lizard Focus: Fly
NaCost: 1
NCU Cost: 1
Dura: 11:11:11
Rang: 1m
Speed:
Attack 0.1s
Recharge 0.1s
Atkskills: Matt.Metam 32% Bio
Metamor 36% Sensory Impr 32%
Modifier:
Cannot fight
Can Fly
Removes all other Focus programs
Requirements:
Use:
Must have Pit Lizard shape.

Description:
This nano is focused on flying as a Pit Lizard.
Fighting while focusing on flying is not possible.

---
--
-

Uploading the Nano Crystal itself is aimed at the same skill requirements as the basic Polymorp requirements, in this case the Pit Lizard. However, the nano program itself should work even if the Adventurer gets debuffed, thus it's set to take a minimum of resources and checks for Shape and other Focus nanoprograms instead of Nano skills. This should make it useful in all situations without breaking the original nano's intention.

Once you don't want to use the Focus (flying in this case) you can just deactivate it by right clikicking it in the NCU list. The neat thing about it's long duration is that it will always put itself in the very ends of the NCU list, so it's easy to find.

Both advantages and restrictions can be build into it with ease and since it basically extends the already existing Polymorph nano.
Heck, you could even make high end upgrades to old forms, such as added hitpoints, attack rating or perhaps better concealment.

Simple as that.





Edit :
Figured out that making any Focus nano to just purge any other Focus Nano already running, would make it easier to use.

Scrolling trough a bunch of buffs while fighting to change Focus just isn't an elegant way to do it.

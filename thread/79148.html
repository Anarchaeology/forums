Seid
Phear Leet
Unless I'm totally out of touch Quaseem made the first one(s), but many picked up the idea and made their own.

You now have versions in everything from java via perl to VB and C++, on both linux and win32 platforms.

The basic idea is to log a bot on to the chat client using one of your char slots. There was some uncertainty as to FC's position on these, but as they now endorse helpbot in the subway I guess it's all good

So whoever hosts this needs one or more free alt slots and a server running.

I dont really think a shopbot is viable, as the chat system was never scaled for that amount of traffic to a single client.

Smaller special purpose bots with less traffic are doable however.

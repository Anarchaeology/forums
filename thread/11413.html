The new False Profession changes
First of all, to avoid confusion, when I say MP I mean Mimic Profession, FP is False Profession and AP is Assume Profession.

Then I'll continue by posting the stats in these nanos for later reference:

False Profession Martial Artist:

Duration 30 min

Set Nano Cost to 150 % On Self
Set Range to -50 m On Self
Set Interrupt Modifier to 75 % On Self
Modify Nano Init by -2000 On Self
Modify Psychological Modification by -25 On Self
Modify Sensory Improvements by -25 On Self
Modify Matter Metamorphosis by -25 On Self
Modify Matter Creation by -25 On Self
Modify Time & Space by -25 On Self
Modify Bio Metamorphosis by -25 On Self

Assume Profession Martial Artist:

Duration 45 min

Set Nano Cost to 70 % On Self
Set Range to -25 m On Self
Set Interrupt Modifier to 50 % On Self
Modify Nano Init by -1500 On Self
Modify Psychological Modification by -80 On Self
Modify Sensory Improvements by -80 On Self
Modify Matter Metamorphosis by -80 On Self
Modify Matter Creation by -80 On Self
Modify Time & Space by -80 On Self
Modify Bio Metamorphosis by -80 On Self

Mimic Profession Martial Artist:

Duration 60 min

Set Nano Cost to 15 % On Self
Set Range to -10 m On Self
Set Interrupt Modifier to 15 % On Self
Modify Nano Init by -750 On Self
Modify Psychological Modification by -140 On Self
Modify Sensory Improvements by -140 On Self
Modify Matter Metamorphosis by -140 On Self
Modify Matter Creation by -140 On Self
Modify Time & Space by -140 On Self
Modify Bio Metamorphosis by -140 On Self

Okey. As you can see, the main differences between these nanos are that the higher quality level ones have bigger nano penalty, lower nano init penalty and lower nano cost penalty.

To analyze each of the nanos as they are now, the False Profession line is the good buffing-line. It has high nano init penalty, high nano cost, but low nano skill penalties. The only thing this line is lacking is a short duration. 30 minutes is not good for buffing.

Assume Profession is just the nano in the middle. I see no current use for it. Mimic Profession is the closest you get to a combat casting line, but the nano init penalty is still too high.

So, to summarize the current state of these nanos I really can only see a good use for the False Profession-line. It is the best line for buffing, and as none of the lines really can be used for combat casting, they are practically useless.


But. Looking at the patch notes for 13.8 I see that the duration for Assume Profession and Mimic Profession is going to be changed to 25 minutes and 20 minutes. Okey. FunCom shows us that they are willing to change things, and are trying out stuff to improve these lines, but is this what we need?

The AP- and MP-lines are the lines closest to be combat casting lines. So why make the duration shorter on them? When casting in combat you would want a long duration so you don't have to rebuff all the time. FP is the line needing short duration, because it is the best line for buffing.

I want to give FunCom credit for trying out new stuff, but I think they are doing the wrong things, and it is not what we need. Therefor I will try to make a suggestion for how I'd like to see these three lines changed.

False Profession (buffing line):

This line is already almost good. The only thing needed to be changed is the duration. A duration of 15 minutes would make it much better. To compensate for short duration and low nano skill penalties, it should continue to have high nano init penalty and nano cost penalty, as it has right now. So this is how I'd like it to be:

Duration 15 min

Set Nano Cost to 150 % On Self
Set Range to -50 m On Self
Set Interrupt Modifier to 75 % On Self
Modify Nano Init by -2000 On Self
Modify Psychological Modification by -25 On Self
Modify Sensory Improvements by -25 On Self
Modify Matter Metamorphosis by -25 On Self
Modify Matter Creation by -25 On Self
Modify Time & Space by -25 On Self
Modify Bio Metamorphosis by -25 On Self

Mimic Profession (combat casting line)

For combat casting we need low nano init penalty, low nano cost, long duration and a long duration. At the same time we cannot have to good combat casting lines, as it will unbalance the game when we can compete with the combat casters in combat casting. To compensate there can be high nano skill penalties. With the nano skill penalties and nano cost penalty plus nano init penalty still there, this wont be a serious competitor to other classes as combat casters, and therefor wont unbalance the game, making agents too über. This is how I would like to see the MP-line:

Duration 45(?) min

Set Nano Cost to 15 % On Self
Set Range to -10 m On Self
Set Interrupt Modifier to 15 % On Self
Modify Nano Init by -150 On Self
Modify Psychological Modification by -100 On Self
Modify Sensory Improvements by -100 On Self
Modify Matter Metamorphosis by -100 On Self
Modify Matter Creation by -100 On Self
Modify Time & Space by -100 On Self
Modify Bio Metamorphosis by -100 On Self

Assume Profession (combat casting line for lower level agents)

Assume Profession could be the combat casting line for the lower level agents that cannot use MP yet. It could have lower nano skill penalties because lower level agents dont have that high nano skills usually anyway. To compensate it could have higher nano init penalty than Mimic Profession and higher nano cost penalty. I'd like to see it like this:

Duration 30(?) min

Set Nano Cost to 30 % On Self
Set Range to -20 m On Self
Set Interrupt Modifier to 30 % On Self
Modify Nano Init by -300 On Self
Modify Psychological Modification by -75 On Self
Modify Sensory Improvements by -75 On Self
Modify Matter Metamorphosis by -75 On Self
Modify Matter Creation by -75 On Self
Modify Time & Space by -75 On Self
Modify Bio Metamorphosis by -75 On Self


These are just suggestions from me. I am sure there are lots of people disagreeing with me, and people with other ideas, but I am just trying to get a discussion about this, and hopefully FunCom will look at it. My point is that we need to be able to combat cast too. But not to good so we compete with the combat casters themselves, because that would make us to über and them useless.

My main point is that the changes in 13.8 are not the ones we need and I hope they can change this before putting it on test server.

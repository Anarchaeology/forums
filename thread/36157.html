Hacker tools are quite useful provided you are either a fixer or find certain items.

Shift left click the tool to find out what it can do

But to summarize, it can :

- Hack pills, blister packs, boosted grafts to remove profession requirement and reduce skill requirements, basically giving you access to other professions nanos if you are lucky enough to find useful charged items.

- Hack open sealed weapon receptacles that can be found in team missions now and then, containing unfinished weapons you will not find in any store.

- Hack (mobile versions of) surgery clinics to allow fixers to build their hacker interfaces

Overall not an item you will use all the time, but it can be handy now and then

Hacking uses the Breaking & Entering skill, so if you are unable to hack an item, look for a Fixer or an Engineer.

Division 3 Academy open for Class Charlie
Division 3: Omni Reclamation, a member of Project Revenant, is announcing the opening of recruitiment for Class Charlie of our Academy.

We are accepting applications for all professions level 5 and above.

We are a role-playing guild, that also focuses on PvP and having fun. As part of Project Revenant, we help to organize and participate in player-run events on RK2.

For more info on Project Revenant, go to www.projectrevenant.com.

If you would like to join Division 3, register for the forums at the Project Revenant website. Then go to the Academy forum, fill out an application in the sticky post "Application for Academy [CET]."
All the other info you will need to be accepted into Division 3, and the steps to take to accomplish that, are found under the same post.

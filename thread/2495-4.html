Some things I would like to see added and changed (sorry if any is a repeat);

 The ability to create, rename, edit text color and remove categories in friends list with user defined category names. For instance user could create a category for faction members by using command /category add First-Order which would add a new category name in friends menu with First-Order shown. Text color for categories could be edited by selecting the desired category in friends menu and using /color lime. This would make all incoming messages from names within the category, Lime colored text (or whatever color you like).

 Add function to move or remove friends from categories in friends list. Friends could be categorized by using /add playername categoryname command. Also you should be able to drag and drop names between categories. Deleting names should be as easy as ctrl-pick or shift-drag multiple names and using delete key.

 Add small button in friends menu to toggle on/off online or offline friends for each category or all categories at once.

 Users should be able to manage their own text color display for each channel, vicinity, faction, shout, item links etc.. using similar command as the suggested category color edit by selecting channel and using /color colorname.

 Add a /retell command. This should solve the problems with mistells by sending your message to the last person you sent a "/tell" to instead of the interrupted replies that we all grow tired of.

 The ability to add custom chat buttons at bottom of chat text field. Similar to quickbar macros, user could create macro shortcut for channel, category, trade channel, faction/clan, tell, reply, retell, etc and drop in slots below text field (small buttons of course). The button could be used after text field is filled to send message, or before text field entry executed by enter key.

 /squelch players from channels as an alternative to permanently ignoring user. (great idea Nalissa! )

 Access player bio by right clicking name in friends menu.

Of course the commands might not be exactly as written here but the mechanics of these features is something I envision as being feasible and very user friendly. It also gives some customizing options to those who really want to get the most out of their chat.

Chat interface
Oh, the chat interface. Or the horrible abortion that passes for a chat interface. My question is, why is there no MMORPG that features a decent chat module? Why is it that a piece of multimillion-dollar, corporate-run entertainment software cannot do what a 4-bit MUSH or MUD, usually run by collage students, can do for free? You want a good example of how chat should work, take a look at virtually any text-based MU* out there. There's hundreds of em. And perhaps, you'll get a clue.

I dont mean for this post to sound like a flame, but the abyssmal state of every single MMORPG chat interface to date really has me steamed. Its almost as if it was tacked on as an afterthought. If the grafix engine is the heart of a game, then the chat module is it's soul. Without it, the players cannot communicate with eachother, nor can the game communicate with the players. It boggles the mind to see what kind of shoddy lash-ups are currently avalable. AO is the cream of the crop in MMORPGs, it deserves the best chat interface as well.

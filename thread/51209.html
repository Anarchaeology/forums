Scripts tied to nanos.
A feature I would like, is to be able to tie scripts to nanos...
While nanos in scripts would easily become to powerfull, a little something like
"/me is calming %t
/s don't mess with my mezz please"
going when I execute a certain nano, in this case a calm of sorts.

This way one would not make a über script like
"/while %t alive
/nuke
/wait 500
/loop"
but one could still explain what one does.
Maybe an option like
"/say executing %nano !" where %nano is the name of the nano you are currently executing.

Catalogue of Suggestions
Below is a compiled list of many of the suggestions from this forum. These are collected in order to provide Funcom a quick index of many of the player idea expressed within this forum and for players to be able to more easily find whats already been suggested and to hopefully reduce multiple posts on the same subject. This list is updated routinely.

Only one thread from a multiple posted suggestion is listed. Also, any threads that were spam or flames were neglected. Sadly compilation threads did not make this list unless all the suggestions were on the same topic in order to categorize these. Additionally, no bug report threads are included: these should be sent to bugs@anarchy-online.com. Please keep this thread clean so that it remains purely a catalogue.

Notice: Starting February 2004 newer additions will be flagged with a "NEW" following the link. Flags will remain present for a period of at least 2 weeks. Items implemented into the game are removed from the list and tallied below.

Remember, please no replies to this thread. Replies requesting additions will be ignored. Profession-specific issues should be directed to the appropriate Professional. Also feel free to E-mail ideas to feedback@anarchy-online.com.

Thanks!

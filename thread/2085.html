Tutoring devices
Does the tutoring devices work properly?
Today, I and a stranger tried it out for some time, and we both came to the conclusion that they don't work as they should.

This is what we both thought should happen:

1 If all requirements is met, it will work. otherwise you get an errormesage.
2. The target get points in a skill and the user (the tutorer) loses those points temporarely
3. after a while, the effect wears off.

This is what actually happened:
1 If all requirements is met, it will work. otherwise you get an errormesage.
2. The target see NO increase (or decrease) in skills whatsoever, but the tutoter looses points in the skill until he/she zones. (not for the 30-30 second duration it claims)
3. the negative effect seem to last several minutes (until zoning) The positive effect doesn't seem to last at all.

Anyone else has experiences with tutoring devices? Is there a lvl restrictment on them (as the xp-gaining restrictions)
(the target was very red to me (he was the only one around when I wanted to try them out)

Could be a bug .. feedback plz
Hey guys ... whilst playing around with some scripting concepts I decided to write a setup script for my pets (MP). So I did, /setup renames combat and mez pets. It also orders combat to guard, and mez / healing to follow.

After realizing that I didn't have the healing pet set to watch me I wrote another script /AReset which sets combat to guard, mez to follow, does a /selectself, then orders healing pet to heal.

So I came up with the bright idea that anytime I had to re-summon a pet, instead of typing /setup then /AReset, or instead of creating 2 different macros, I'd just place a call to /AReset at the very end of the /setup script.

I executed it from the command entry box guy and blammo, worked great! So I created a macro to the /setup script. You would expect the macro that is executing a script to act the same as a script, but it doesn't .......

It appears that the /AReset call at the bottom of the /setup script is begin ignored if executed from a macro, whereas execution from the command line works fine.

Can anyone else confirm this behavior?

Precedent
FC sets a precedent by devoting specific patches in the past to enhance/modify classes. So the classes that have yet to see thier respective enhancements assume from the precedent that FC set that thier respective class will get modified in the same method. None of the previous class fix patches were called "advent patch", "Fixxer patch", etc by FC but they were called such by the playing community simply because that specific patch dealt with fixes/enhancements to "balance" that class. Those patches didnt just add a simple nano or a single weapon they added major changes to those classes which drastically changed that class in one day.

The three remaining classes (NT's, soldiers, and Engineers) are now told that precedent doesnt exist for them and will be modified over time instead of using the method we used to modify the other classes. All of these classes have been waiting thier turn and now are told thier turn will be spread out over patches. I see this as simply stating that balancing the remaining 3 classes is no longer a priority as adding a nano or a weapon in a patch, which is what i assume is meant by over time, isnt going to have the same effect as the other classes got by a single patch that dramitcially affected thier class. If FC thinks the remaining 3 classes are balanced and doing just fine, then simply state that and we can all stop posting and decide what we want to do from there. If we in fact do need changes to be better balanced we would like them in the same fashion the others received. We are not asking for more or something that has never been done. We are asking for the same.

I do not wish to and will not wait for another year or 2 years to get the changes needed to make the solider class better and i would be willing to bet neither does anyone from the NT or Engineer profession. Without a timeline associated with "changes over time" there is no way to tell when or if it will ever happen.

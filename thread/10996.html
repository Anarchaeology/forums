I'd like to see Palm type hand held computers which provide information. Upgrades would give more thorough info.

Basic Model: Tells you general information for getting from point A to point B.

1st Upgrade: Combines with the map so a line is drawn from point A to the various sub-points leading to point B (Waypoints).

2nd Upgrade: Tells you information about the area, like important landmarks and wildlife.

Their use could depend on Comp Lit. This way, those without a map to an area can still find their way to point B.

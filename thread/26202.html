From what I've seen, this is an artifact of lag causing syncing issues between the client and server. In most cases I experience it after any noticable lag from the servers (such as a few seconds of fighting with hitting or being hit or being able to cast nano's). I'm guessing that both the client and the server have timers for each action and the lag is causing the client timer to get out of sync with the server so that you might get a message as stated above or, in the case of first aid, MA specials, etc., get a message that the action is available but when you try to use it, you get a message that you have to wait X seconds before the action will be available. Once again, a long standing problem that Funcom seems unwilling to acknowledge, much less correct.

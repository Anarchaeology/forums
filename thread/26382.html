Terminal GUI v1.2 is out...
Well it's finally done, this is a completely new made from scratch Graphical User Interface for Anarchy On-line, it replaces ALL of the graphics for the original in-game GUI.

You can get the file from us by Clicking Here, it's 1.05mb.

Also you can check out the Read Me file which is also included in the zip by Clicking Here.

ADDITIONS & UPDATES IN VERSION 1.2
  • Updated to all of the GUI graphics.
  • New Map based on actual geography (not where the game tells you
    where you are) for those of you who actually look around
  • Help button (AO v13.6) added.
  • RP Button and panel (AO v14.2) added.
  • All the Windows have rounded corners.
  • New More visible Targeting Indicators.
  • New Target Pointer Cursor.
  • New Icons for Unknown Items and Nano-Programs (the question mark)
  • There's much more changes - you will see them


Please feel free to mirror the file in your websites and such, we'll need to spread it around for the community (and Insomniax's bandwidth!)

Enjoy.

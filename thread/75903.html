Newly updated In-Game Map available for download.
Greetings!

Rubi-Ka Playfields' newly updated in-game map is now available for download. This map is current for the 14.7 patch.

The new in-game map will provide two files to replace the current in-game map files with maps of Rubi-Ka which provide:

- Playfield borders with zone lines
- Playfield names
- Whom-Pah System routes
- Grid Access Terminal locations
- Public Grid Access Requirements
- Fixer Grid Exits
- Outposts
- Carbonrich Rock Fields and Qualities
- Labeled Points of Interest
- Dungeons

**UPDATE** Added:
- Locations (floor/position) of Playfields in the Fixer Grid
- Ferry Routes

These maps function just as the original maps do, allowing for zooming in and out, and centering the map to your current location.

Many thanks to Dovve for permission to use map enhancements from Dovve's Map.

To see this in-game map in it's full size, click HERE.

Click HERE to download the in-game map files (ZIP format). (You can also go to http://travel.to/rubi-ka and click on the 'In Game Map Files' link.)

After downloading and unzipping the file, place:
"PlanetMapGfxNormal.bin" and "PlanetMapIndexNormal.txt"

...in the following directory:
Funcom\Anarchy Online\cd_image\textures\PlanetMap\normal
(Make sure to make a back-up the two original AO map files already located in that directory, first.)

Also available on http://travel.to/rubi-ka, are viewable and printable maps in both full color and black and white of:
- The Complete In-Game Map
- Playfield Border Zones and Names
- Whom-Pah System routes
- Grid Access Terminal Locations and Fixer Grid Exits


Enjoy!

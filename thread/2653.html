Just a little carelessness by Funcom. AO stores a base item-NCU chips, say-with several "milestone" items. So, a 64 NCU Memory (item name) is the Q200 NCU Memory. The 32 NCU Memory is about QL 120. Items from Q160 and up have the name "64 NCU Memory." The actual NCU they have is determined by how far from Q200 they are-it's a linear progression from 120 to 200. So a Q160 may say "64 NCU Memory," but it really has 48. The proper names would be

1-2 NCU memory
3-5 NCU memory
6-11 NCU memory
12-23 NCU memory
24-47 NCU memory
48-64 NCU memory

I hope that clears it up.

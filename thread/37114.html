Community answers - part 3
A few things for you. We have several issues waiting for confirmation, and a little bit more info coming up hopefully later this week.

Pet pathing
A superb report was submitted through the Professionals program (special thanks to XtremTech) and has been fed to the development team. Community has pet pathing as #2 on the important issues list right now (reimbursement tool is #1), and will continue to push for improvements in patch meetings and other channels.

We will post updates when we have 'em.

Self only skill buffs (Pistol buffs)
Previous answer (in part 2) stands. The issue with the Pistol buffs is an exception. If you have other similar buff examples where a buff usable on everybody is better than a self only buff (and the two don't stack), let us know.

The Adventurer and Engineer buffs are not scheduled for any changes, so while the Engineer can buff better, the Adventurer does not need to have the Engineer around at all times.

Trash King
We currently have a temporary solution making sure the Trash king spawns more often. We actually heard people are not killing him fast enough at times, so there might be more than one of him.

The intented system is a more random spawn time, with shorter average spawn than the current work-around (but a limit on only one Trash King at a time, I hope). This one will have to wait for a suitable patch to come around before we can implement it.

In-game maps
Map of Wailing Wastes is still missing, but hopefully not for long. Also, we're pushing a bit on getting the in-game maps updated (the ones shown in the Map window; Ctrl + 6).

Weapons with wrong initiative skills
We have two reports in the bug system about this; One with a list of bows and one with a list of other weapons. Both are scheduled for 14.6, but I can't promise they will all be fixed by then, as we haven't gone through the list for 14.6 fixes yet.

Broken trade skills
The bug report on this had a nice list of fixes, and it is scheduled for 14.6 (already committed, so the changes are made, I guess). Not sure everything is listed there, as I don't have a complete list of broken processes, but hopefully we will get an auto-detect tool on the trade skills and find every single broken process soon.

XP for trade skills
Basically, the reward for the trade skills is the items created. The XP is an additional bonus. We will add a suggestion on increasing the XP a bit, but don't expect too much.

---

That's it for now. As said, we're working on several other issues, but don't want to add them in the threads until we have had a talk with specific people on the development team, and can bring out some more facts about it.

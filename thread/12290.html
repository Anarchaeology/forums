A way to help out agent soloing
With an eventual patch that will take away MP pets from agents arsennal of survival skills, i have an idea thatll help agents solo same level mobs and increase total survivablity; allow us to use agent only nanos while in FP (false proffesion).

I think by being able to use several of the combat nano's while in FP (or any of that line) survival will surely increase. Currently the entire line of agent combat nanos is being ignored because, quite frankly, we are always another proffesion. If the ability to use these useful nanos (run debuffs, roots, weak DoTs, among other more unique nanos) were allowed to be cast while in FP, we would be able to survive many instances where: Sneak breaks in a mission, in the middle of the wilderness and being chased by a choo choo, or just more useful in a group (seeing as how roots work REALLY well now).

Because the focus of this fix on the combat nanos, the nano penalties (nano init, decrease of nano skills, and the handicapping nano cost penalty) cant apply to the agent only nanos. Because if they did, the combat nanos would be worthless - cost too much, too hard to cast, too long to cast.

Would this infringe on other proffs? No, agent combat nanos - roots, run debuffs, DoTs - are the weakest of all the proffesions. Crats roots are waaay better, Someones debuffs are better, doc DoTs are hands down better. Its just a minor improvement to agents.

And if this proves too powerful, only allow combat nanos to be cast while in FP, not our buffs. Although IMHO this would only be a nuasance to agents.

Any constructive thoughts on this?

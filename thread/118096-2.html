An even better solution (but one that would require far more effort) would be to give every running nano a special numerical value and a single flag to indicate if it was self-cast or an outside buff. Then, all outside buffs whose numerical value exceded an equivalent value for the LCA could be cancelled on first becoming PvP flagged in a LCA, or re-entering a LCA whilst PvP flagged (All nanos should not be castable outwith PvP level range whilst either caster or target are PvP flagged).

This allows fine tuning on a per nano basis seperately from NCU usage, and allows twinks to be able to still use their own nanos. The purpose here is to restrict outside buffs, particularly the more disruptive ones (HoTs, damage and reflect shields etc) whilst not overly interfering with other less disruptive nanos.

Maybe Shadowlands will add features to enable this to be done more easily.

Linta posted this in that other thread but I'll post it here so you can see what people can do at just lvl 25 with the right equipment and buffs on.

Let's see... Level 25 Enforcer :

- Max Comp Lit = 118 +3 +20 = 141 should be able to get to 225 with implants (and there are a few comp lit buffing items)
- Max Treatment = 118 +3 +20 = 141

Base NCU : 8
+ 7 Ring of Nucleus Basalis QL26 (subway) = 15
+ 15 Guardian Circuit Board (GoT in ToTW) = 30
+ 26x5 = 130 Dark Memories (Lien in ToTW) = 160
+ 11 Notum+Platinium Ring = 171
+ 40 Retool NCU (req level >=25) = 211

That's with using only reasonnable stuff btw... It could have been pushed even farther with rare loots, or using NCU gear. Memory Loop gives +33 NCU, with the same req as Dark Memories, but they're a lot rarer.
All you need to get these is to kill the first boss in the subway (I can do that 100% reliably with a level 18 nanomage enforcer) and survive in ToTW while someone else is doing the killing. GoT is soloable. Lien is harder to solo, but a duo could handle him easily.

Now, with 211 NCU, there is a lot you can do, including having ... Not exploiting or anything... Like :
+ Omni-Med Incursion (24 NCU) : 122-276 HP/5s for 180s
+ Hacked Diagnosis (6 NCU) : 58-64 HP/10s for 15 min (level req)
+ Run buff (I would go team version, max is 44 NCU, but not sure if it has a level req or not)
+ Reduce Inertia (MA buff, +120 evades - 42 NCU). On top of maxed and implanted evades, that's pretty close to god mode at level 25
+ Reactive Reflective Field (Extended) (30% reflect, 44 NCU)
+ Essence of Behemoth (+996 HP, 47 NCU) or the max doc buff for an extra 1344 HP (56 NCU) or what about the max humidity extractor (52 NCU, 235 nano point every 15s)? I would actually go for HE, that means unlimited mongo/challenger...

At worst, that's a total of 177 NCU. You still have room for you own buffs... The only untwinked thing is AR, and this is the one you will have the most troubles to buff to godlike levels (maybe +87 from Brutal Thug, which is still not that much). But you're pretty much unkillable, between the high evades, the HoT and unlimited nano... Actually, the HoT is the weak spot there : the long version is level limited, and the short version is *short*...

So, nothing "magic" there... Just some twinking and high level friends with nothing better to do... I agree it is game disrupting and borderline on exploiting (you cannot do this kind of direct healing anymore, but loopholes still allow HoT to do that). The problem is that there are no easy solutions to that. You could :

- put level limits on *every* nanos. But that tends to piss off people, and it would be very harsh... Just think about not getting stuff like SFA, IC or Essense until you're in your 100s...
- Automatic debuff of non personnal buffs when going into tower pvp. But then, it destroys any team play...

Neither of these are satisfying...

Crash Report Poll
Since there is no way to reply to the question posed in the poll, I will have to reply here.

I have experienced 100-150 client crashes in the last 6 months. This is on various versions of windows, with different hardware and software configurations. I have never reported with the report tool as it ALWAYS fails. I tried to send a bug report in to the address listed and it was returned user unknown. Sure I could have done a little extra work and dug around for the info and probably would have found a way to get the report to you, but you know what?

I'd rather play the game that I'm paying for than spend 20-30 minutes looking where to send a report. I mentioned the BugRep tool issue to a GM, not an ARK, awhile back and was told to mail it in.

Isn't this what I'm paying you do to. Hey, having a bugrep tool is a great idea, but don't expect much if it doesn't work.

Here's a novel idea. Do what real tech support departments do and have your GMs put issues into a database that don't require detailed information. That way you can see the issues that people are having who don't want to do your work for you.

Oh and I did notice that you changed the layout of the tool since I started, so it's not an issue of having given up. Everytime I get the BugRep tool I try to send. The problem is it still doesn't work.

Nerfing shotguns dont make another mistake...
Like you did wqhen you nerfed Aimed shot and Rifles altogethor and lost all the agents back in 12.xx.

The problem herein lies in the fact that people werent raising evades. Back then people didnt raise dodge-ranegd and Agents were able to take advantage of this using scopes and crit buffs to do insane damage. This lead to Funcom nerfing aimed shot and rifles balancing them to render agents damge more reasonable against a person with no dodge range skill. Now that folks have learned and raise their dodge range any agent using a rifle that does proj damage is pathetic.

So Agents have started switching to Lovemakers using shotgun! Traders and everyother profession are using Shotguns...is it the gun that does this insane damage and needs to be nerfed? No its the same exact situation people have raised dodge range and neglected Duck Exp which is the defense check for the shotgun skill and the same thign is happening all over again.

I suggest before nerfing the guns themselves that some extensive testing is done with toons with reasonable levels of Duck Exp skill in place. Another knee jerk reaction like was done to the agents back in 12.xx and youll have yet another mass exodus form the game...something which you cannot afford at this point funcom.

I would like to suggest some rebalancing being done with regards to conventional weapons so that agents will want to use normal RIFLES instead of shotguns...agents arent using shotguns because they want to...trust me they are only using them because they have to. Once people start raising their duck exp all these agents carrying Lovemakers are going to be rather disappointed in all the ip they wasted on the shotgun skill. In the end its not really their fault either..if you want to be effective you had to do this because of the knee jerk balancing that took place the first time this occured with reagrds to rifles...dont do the same thing again Funcom please fix this the proper way by rebalncing Rifles and other Weapons that have been "balanced" previously so that everyone is no longer forced to use shotguns.

If you continue nerfing all the viable weapons people are switching to when you nerfed the last one eventually there will be no viable weapons and eventually the game will be unplayable...is this what you want?

Please think about what im saying before you flame me...Wouldn't you folks rather have a viable alternative to use instead of a shotgun rather than having shotguns nerfed to the current damage of the weapon your using? Doesnt this seem like the proper way to handle the situation? It seems elemntary to me but unfortunately it does not to alot of folks I see here crying for nerfs.

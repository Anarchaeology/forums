Long Nano Recharge/Nano Inoperative
Long nano recharge on nanos like Last Word/Little Nuke, stuns/CoC, A&O etc makes them ineffective/little used. CoC and stun are "escape" nanos. No one uses ILW for dmg. Alpha&Omega is upload for fun.

Nano Inoperative effect of TMS, Challenger, MA temp fist is very annoying and limit the effectiveness of the nano.

If the purpose of long recharge/nano inoperative is to stop people from spamming the same nano over and over again, isn't locking the type of nano being used (ie. trader team heal w/o the DoT) more effective?

Take A&O for example: If A&O is lock for 12secs instead not being able to heal for 12secs, A&O would be used alot more w/o making it extremely powerful.

The same thing can be said for TMS/Challenger type nanos. It would be fun to cast reflect after TMS is down or not worrying about not being able to cast Mongo and/or Absorb after a challenger.

The speed of the trader heal nerf/enchancment was done so fast by FC -> A change like that should not be too difficult for FC or takes forever.

Even if this idea is bad, something needs to be done to those nanos to make them more user-friendly/useful.

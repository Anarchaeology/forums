New features for guild page!
One feature the guild page is sorely lacking is a way to tell which characters are on what account. Please add this functionality. I'm not asking you for a login name or anything, a unique number would do nicely. As it is, about the only thing we can do to find this out is to parse the XML (thanks for that BTW!) into a database, then have our members go in and tell us which ones belong to which account.

Heck, I'd even be happy if each user had to go in and manualy tag their chars to let everyone know they're on the same account. As it stands in order to truly keep tabs on the guild, we'll have to write a new webpage from the provided XML, which is a pain in the butt.

Please add this functionality Funcom!

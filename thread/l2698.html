If the NDA was lifted now, the current beta 3 testers would spill their guts about the state of the game in beta 3. Since AO has changed a good bit between beta 3 and beta 4, Funcom most likely doesn't want the impressions about beta 3 out before people see beta 4. These beta 3 impressions would probably end up starting endless threads on the board about things which could have changed already by beta 4. You would have posters begging to know if X has changed, or if Y is still like it was in beta 3. People would start arguing, spam posting, polling for changes, etc. Look at the "random naming" fiasco. It's crap like that Funcom wants to avoid.

It would be messy.

Guild halls? how about this FC
Apartment blocks being changed into guild halls

Well thats the idea, I would like to see them be something more than a one time newbie curiosity or play thing for the rich and bored. also I think the guild comunity would like to have meetings in a permanent place that isn't a cleared out mission. There is allot of item space and other things already in game to make this a worthwhile kind of thing to look at. As players we are not really loosing anything we need or use, and a dead horse could be taken off the list as it were this way, and fix a few much needed things.

We have a working Key system in game, and all the objects in game to make it work already, we just need a few changes to labeling to make it work.

put a few guild items in a shop machine, guild hall key duper, lock boxes ( similar to the chests in missions, but for halls, so we can store the hand-me-downs in a place other than someones mule bank ), trophey cases ( maybe a few rewards based on meeting requirements or tasks for thier faction could be displayed )

Make the guild hall key dupping device require a given rank to use the item to make a key for a member. ( This could even be a layered type system at some point allowing leadership to extend acess to diffent areas of the guild hall itself.)

make all the duped keys a item similar to the un-opened agent mask requiring a given rank and membership to "use" it. This would make it trade capable, but become no-drop once activated on your character.

Now, after bit of lable swapping on the apartment blocks, all you need is a new interior for it to link to, nothing fancy, just a large open room with a few smaller ones on one end perhaps even a message board or MTOD when you enter the hall.

If your not thrilled about the first idea of swaping the apartments then how about a new row of doors in some of the cities next to them or replacing a few.

This would lead into a comunity area with amenities just like the apartment area, maybe a merchant who sells the org items could be located here. heck throw in a mini-bar too, lol so we can socialize with the nieghbors.

Really you could piece most if not all of this together from bits already in the game, were not that picky honest, if it works its good.

It would be nice I think for guilds to also have reward tokens of a sort that would be displayed in a trophey case in the hall. Like say if you achieved X number members above level X, or sponsored a player to player event that was outstanding, heck maybe a few special items from some of the hardest to kill creatures of rubi-Ka that would give members above a certian level a bonus of some sort, not allot but something to collect.

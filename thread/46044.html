Another approach to in-game notes
I've submited alot of ideas on this subject. This one however is alot easier to implement than making chips or other data storage devices.

Give us the ability to /reference and have a window pop-up that we can type in and make notes or linked pages. I see linked pages in the /help command window. That would be good enough for us to make notes, data bases and write books. Being able to edit the reference is also a must.

Another addition that is needed is the ability to trade a reference from one person to another in a trade window. As an example we could write the coordinants and description of a place and have it as notes for later reference. During a trade of references the references always goes to the knoledge window and not the inventory.

Copy /reference is a needed option. Example: Type /reference to start a reference window then close it making a blank window. Pick up the reference you want copied drop with a right click on the blank and the copy is made.

This is definatly an option I think because those files we edit reside on our computers and not the servers except for the the chat server for a short while. This has nothing to do with objects in a virtual.We have already seen a few examples of text editing and creating with third party apps. Take the third party app out of the picture by letting us do this in-game.

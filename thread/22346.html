An idea to help grouping
Don't know if this has been recommended before, but here it goes.

A very common thing for groups to do (mostly the pullers/tanks) is to create a macro such as "Attacking %t", which as many of you know, replaces %t with the target's name.

Also, we've recently received that /assist command. Very useful, but it has a problem. The problem is it doesn't necessary target your teammate's target. Sometimes pulls go bad or adds come into play. /Assist simply targets a mob (the nearest?) attacking the person you've targeted. This can cause some problems for the team, especially if the /assist target has the same name as the one orginally pulled.

1.) It potentially splits up the damage dealers among targets.

2.) Crowd control is not as effective.

In the end, people can die. This is bad.

My idea is to change the %t/%f, so that instead of just putting the name of the target, place a link to the target (much like item info links) that selects that target (not pulls up they're POD display ).

The team now has 2 new macros:

Attacking %f : All damage dealers/pet owners use this to select the combat target.

Add/Calm/etc %t : The tank notices an add/bad pull, doc gets aggroed by the add, etc. Crowd Controllers can use this link to find there proper targets for calms/roots.

Just a thought.

quote:
Originally posted by Jica
Had one bag turn into a lousy bracer already and I decided to shut down my main(s) untill all this with items/uniques disappearing, has been fixed for sure.
Check it isn't actually still in the bank elsewhere, I had this happen too, but it turned out the bag was now right at the end of my bank items. It looks like when the bracer drops out, it takes up the same space as the bag but the client isnt informed so you see an empty space. When you put the bag back, the client puts it in the empty space quite happily, but the server knows there is a bracer there so puts it in the first available space. When you next open the bank, its now back in sync, so it looks like the bag has become a bracer, when in reality, it has just been put elsewhere.

Now, I'm not saying the same thing has happened to everyone, quite possible people have actually lost stuff, but I'd check just to be sure, you may get a pleasant surprise.

Clothes Patch Needed!
Nice clothing isn't cheap.

When I finally could start affording some nice threads, imagine my surprise when I put different, expensive sleeveless tops and shirts on my Solitus female only to find that instead of seeing the skin of the arms, I saw the sleeves of the Solitus uniform (that you start the game with)! Talk about stupid looking! I looked so impressive with my new clothes... not!

Now I know what some of you are going to say, I have to buy matching sleeves also. This isn't my case, halter tops (as well as some of the other sexy outfits I bought for my character) don't have sleeves. This affects all the races except for the Opiflex (they don't have sleeves on their base uniforms).

The solution is a simple. Create a patch that negates the base uniform when an article of clothing is worn in a specific area. For example, if my character puts a tank top on, no part of the base uniform on the torso/arms should show except the tank top and skin. And so on for pants, shoes, gloves, etc.

C'mon Funcom! Isn't it enough that it takes forever to get a matching set of clothes/armor from random vending machines?

Can any of my AO brothers & sisters give me an Amen out there!?

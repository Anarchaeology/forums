Tiitii, MORB did already a fix for 14.2, Clicksaver 2.2.1

And I found a way around the problem with it on first start where it does nothing after asking for the directory. Somehow the copy routine does not work on every PC.

Save your old CS config files from 2.2 and put them into the clicksaver 2.2.1 directory, then copy manually the resource database and index from the \anarchy online\cd_image\data\db into the clicksaver directory and rename them.


c:\anarchy online\cd_image\data\db\ResourceDatabase.dat -> c:\CS221\Resource.dat

c:\anarchy online\cd_image\data\db\ResourceDatabase.idx -> c:\CS221\Resource.idx

Works fine on both PCs now

*** Addition: You do not need the old CS 2.2 config files, copying the resource db files is enough.

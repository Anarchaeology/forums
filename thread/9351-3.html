Different AOMD Version
I have made my version available. The version has been labeled 1.5.0.0 because of the number fo changes done. Here is the list of new features

1) Addition of 2 list for item watch with multiple colour display on find. Allows for indication of special and general items.
2)System remembers network card configuration.
3) All files as stored in same directory as executable. No registry settings. This allows all settings to be remember if you require to format.
4) Slightly smaller front end.
5) Disable option which stop network monitoring until reactived. This also reduces the size of the program.
6) The minial view can be position differently to the full view and restores to correct position when reactived.

The watch item has been tested under Window ME and NT 2K.

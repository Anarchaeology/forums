How does one change clans? Is there a way to if one is dissatisfied with one's current affiliation?

If you don't like the current guild you're in, I believe the command is /org leave. If that's not it, you can try /org help for a list of commands.

If you want to change sides (like clan -> omni), then you need to find an application form for the other side. These can be bought in stores up to a certain QL, after that they show up as loot items or mission rewards. Note that you cannot change to Neutral and there is a penalty for changing sides - you have to wait a certain amount of time before changing back and I believe you lose any tokens you have accumulated.

Suggestions for small features to improve game play
-Let us erase nanoprograms that have been uploaded but no longer needed. For example, there is no reason Ill ever use a proficiency nano again because I uploaded the Expertise nanos 90 levels ago. Over the course of many re-installs to help crashing problems Ive had to rebuild my hotbars many times and these old unneeded nanos get In the way.

-Give us a keyboard button for unlock. Of course we still need to have a lock pick and point at the item to unlock. The necessity of using the lock pick from the backpack is the only reason my inventory menu is always open.

-Add a line of text in the chatbox that says You parried the MOBs attack and You evaded the MOBs attack, just like we get when we counter a nano. Currently there is no way to know if we are evading blows and can only see parries in 3rd person. If I dont get hit for a few seconds I dont know if I dodged a blow or if Im going to get hit by a barrage that was delayed by lag.

-Add some shading behind the text in the upper left-hand corner where the name of your target is displayed. Its currently unreadable against many ceiling/sky textures.

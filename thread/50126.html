2 easy pet command i would like to see
I've read several post about that and i don't see why it could be difficult to add them to the game.

1- /pet warp : This command automaticly "warp" the bot to your position. Very useful when the bot is stuck or lost in a dungeon. This command can only be used in non-combat mode.

2- /pet stay : Just like the wait command BUT it will attack any target within is reach.

If you cannnot improve pathing at least give us the possibility to get our bot back when he's stuck or lost.

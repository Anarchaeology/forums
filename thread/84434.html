How do I get a link to show in my sig.
Ive read all the user instructions etc and cant figure out how to make a link to my pictures on the anarchy online site. Can someone explain how to do this in dummy terms 8 )

For some reason it does not change the address into a link.

Use the following code:

[ url=http://www.someurl.com ]Text you want linked[ /url ]

Remove the spaces inside the brackets (had to add them, or it would have displayed a link ) and you're good to go.

So, for instance, typing:

[ url=http://www.anarchy-online.com/character/bio/d/1/name/celeztial ]Celeztial[ /url ]

(again, without the spaces) would result in:

Celeztial

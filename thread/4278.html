Shotgun is a dark, dark blue skill for docs to raise. Docs can also only raise it 4 points per level, as opposed to a trader who can raise it 5. Therefore at level 100 a doc would have maybe 50 less base skill than a trader of the same level after dead levels, and would have spent maybe twice as much IP to get there. I don't believe that this is unfair; it is simply the doc's IP spending choice. Now, if you are talking about the Vektor by itself... I personally agree that it is easily the best weapon that uses only one weapons skill in the game. But that's why you see backup classes using it. If they nerfed the Vektor, I personally think all the Vektor users would just jump to Home Defenders.

Also, there are two problems here: one pvp, one pvm. Many people think powerful gun + powerful heals = assured win. Not having pvped much, I'm not going to comment on this. But the second problem is that of doc soloability. I have seen many complaints that docs are unable to solo, for one reason or another. Shotguns help alleviate that cheaply. By no means am I saying that for a doc to solo he/she MUST use a shotgun. But you don't win fights from defense alone.

Lastly, 487 duck vs. a doc's shotgun skill should still produce less crits than negligible dodge versus a fixer's SMG skill, in my opinion.

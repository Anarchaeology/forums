So let me comment a few things about the lag issue,

0. When in crowded area all your eq is loaded for all within vis
range. So less different stuff you are wearing less download.
This is a tragic thing with FC it would be MUCH better if there
was "suits" solution giving less load. This is a problem with
many other online games. Take for example AC, if u couldnt
get thru a door since u didnt have picklock u could lag thru
door. Lag was easily created when many ppl is around by
swap clothes and everything gets laggy and u can lag thru
the doors.

1. MAKE sure to distinguish the lag terms.
a. Net lag, then download for internet diagnostic tools to
check wether its at your end or server end that is the trouble
Run the tool meanwhile u play and disconnect.
b. Graphic lag. Lower graphic affect a. so its easy to blame
your graphic card when its actually a. that cause it. What i
mean is that radar distance change.
c. I/O lag. Check if when u lag while not loading stuff or zone
wether the I/O lamp flash and for how long. Take a clock and
measure over time the delay with 1 hour interval. The reason
for this is what ppl love to call memory "leakage" but it isnt
true entirely.
d. CPU lag. If u lag during sound effects or when alot of things
is happening which doesnt involve other player for example
when u are in solo mission. What i implied here that MANY
times the soundcard is the cause of the problem, ie its
software accelerated. Run DirectX own diagnostic tool
to check this.
e. Server lag. If u can move around and u think wow no lag
then try to sit/cast nano/watch damage report if they cease
etc etc , if u cant sit the server is truly lagged down. In this
case nothing can be done, go and take a cup of coffe and
relax.

2. Try to optimize your computers performance.

a. Lower visual radius especially when u move into crowded
areas.
b. Toggle of fog effects under enviroment option. Experiment
but turning of and using the fps check running, dont
remember it but i think u can read about how to turn it of/on
in guides/manual.
c. Choose right resolution to your screen size. 14":640x480,
15":800x600,17-19":1024x768;
d. Be sure that u set Fastest rendering under Direct X settings
for your graphic card settings.
e. Have game in different partition from swap file. This to avoid
get the disk totally defragged.


Comment. 1 common misstake with ppl using 256 MB memory
+ XP operative system is that the swap file goes haywire and
is around 300 MB. Increase the meory to 512 and everything
goes smoothly. Dont forget to install memory booster program
that when memory is nearly full it cleanse memory. This work
superb with DDR memory. This has in other word NOTHING with
AO in primary, rather the nature of XP, after a so called
thresshold memory XP 'revives' goes extrmely fast. From my
experience i would say 512 MB.

If u guys finds something that is missing, plz feel free to add.

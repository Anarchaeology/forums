While my first reaction to this practice would be that it is an obvious exploit...

The fact remains that you get a token for accomplishing a mission. If you die, that mission stays accomplished...

Meaning that technically you have earned that token.

That does not change the fact that killing yourself to lose exp so you can keep suiciding for tokens is too lame to express in words legal on this board :P

I am sure it is obvious to everyone here that this is not how tokens are meant to be gained. That you are able to do something does not make it right to do so.

It is a pity that the game mechanics reward lamers and punish players...

It also instantly brands anyone with a 300+ token board as either an ex token trader or a token farming lamer...

Which, believe it or not, some of them aren't.

One possible solution to this is to add an exp bonus to the token. A bonus that is not lost by /terminate or death by other means.

If that bonus is calculated according to your level, it should be possible to prevent an excessive number of tokens without levelling.

I think that is a better solution than the alternative...which might be total loss of everything gained since last save if you die.

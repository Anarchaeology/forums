Webinterface for AO
More and more people request the possibility for retrieving information from the MMORPG currently available.

This is usually requested to make dynamic website for the many Guild websites on the Internet.

The wish from these Guild websites is to provide members of the Guild with realtime, up-to-date information about the Guild status, number of members, server uptimes etc.

None of the MMORPG currently available provide possibility of doing this, but as far as I can can tell, most are planning to implement this possibility in the near future.

Can anyone here tell if FunCom/AO has plan to do this, or will at least be interested in joining a project to write a common standard?

An initial (very) draft is on our temporary website on:
http://jesper.angelo.dk/mwi/

In hope that FunCom will join in,

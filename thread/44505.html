Ya know what's really kinda silly...
is that when you create a character, you go to the race BEFORE the profession! It is silly because, newbies, or otherwise less-witted folks, create Opifex enforcers, or Atrox NT's.

The character creation should be changed and the profession should be chosen first, then based on the profession, only certain breeds be available. Now, you might say, "well then isn't that kinda dumb??!" "What if I wanna make an Atrox MP?" Well, I donno why you would want to, it would be pointless and stupid....

Which opens up a whole other bag of worms really, *mindless babble*what is the point in the first place? What is the ultimate goal? There are no high level raid worthy zones or targets really to speak of (shadowlands not taken into consideration), but still, there isnt anything to concour.*end of mindless babble*

So anyway, back to character creation, there should be more description of the profession available during the character creation stage, so that players can read about Typical weapons, strategies and so forth that the profession might use. Heck, wouldn't it be kinda neat to have a"First weapon of choice" Interface or stage of the character creation? Where you have chosen your profession, then race, and then you go to an additional stage, where you could pick from like 4 different startup weapons? Doctors, and adventurers would especially love this, as you always see adventurers using 1he instead of pistols, or a doc using a bow, or an enforcer using 2hb or 2he instead of the startup 1hb.

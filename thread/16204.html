Profession changes would rock and make the game unique
Profession changes were originally going to be in the game for solitus only, but never made it to completion.

I think profession changes for all breeds would be great for the game. You could level up as one, and then get more play time and a longer subscription rate if people could change. Just make it so that the profession change process removes all nano programs that aren't general and it would be balanced. So, you'd have to buy everything to start over in the new profession, quite a challenge, especially if you changed from enforcer to soldier at level 150, you'd need to get all the mission/loot only nanos.

It's not a carebear thing. It is a role-playing thing, classes changes have been in rpg's for decades, but in those you get to keep the old skills. I think that would be overpowering/unbalancing in AO.

I think breed changes should also be allowed, since they can reconstruct your body from a dna scan, why not be able to pay for a service that reconstructs you as a different breed? This might of course involve the loss of all nano programs, but it would keep people playing 1 character instead of repeated re-roles, and it isn't manatory.

We live in a world now where people get all kinds of elective operations/surgery, in the year 30k, why not have some wilder stuff?

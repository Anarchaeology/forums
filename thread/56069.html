CLuster QL rules are as follows:
  • Shining clusters need to be at least 86% of the QL of the implant, rounding up.
  • Bright clusters need to be 84% the QL.
  • Faded clusters need only be 82% the QL.
Accordingly, you should be able to use a QL68 bright cluster in a QL80 implant. If you want to be sure, buy a really low QL cluster (something like a QL4) and try to combine it. The System will tell you the minimum QL needed.

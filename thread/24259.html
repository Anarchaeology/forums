2 suggestions for implementing Dueling
Sjoko has suggested we post this over here so here it is. Tell us what you think.

Suggestion 1: by Ripple of Soul
----------------------------------------
Just a suggestion for what a /duel command should look like (when Funcom implement it at patch 29.8)

Condition for using /duel:

-cannot be in a fight
-cannot be in a vehicle
-cannot be in fly mod
-have to be able to target each other (in range)

How to us it:

Target the guy you want to duel, type /duel and wait for the opponent to target you and type /duel.

After that both players will enter a 10 seconds count down before they can start bashing each other.

Special conditions for /duel:

-You can duel in any outdoor environment regardless of gas level

-NPC guards will not interfere with dueling

-Monsters will still aggro (if they aggro normally)

-First one who zones or dies lose, and his/her PvP rank is reduced accordingly (duel will end automatically and both sides cannot attack each other again)

-No outsider can cast nanos or use any object (such as first aid kit) on a person in a duel.

-Only the person you duel will be able to attack you in 75% and 100% zone (25% and 0% still follow normal PvP rules, ie others can gank you)

-Normal level restriction still apply, ie you cannot /duel a person whose level is too low or too high relative to yours.

wildcards:

-f: friendly duel, the winner will not gain PvP rank and the loser will not lose PvP rank.

-s: self buffs only, all outside buffs will be terminated when both sides initiate a duel.

-n: no buffs, all buffs will be terminated when both sides initiate a duel.
----------------------------------

Suggestion 2 by Meligant (aka..me)
---------------------------------------------
Ah. I like the idea but I think the following would be better supported by current tech.

1. 2 players that want to duel enter a "team" together.

2. Either one of them uses the "Duel Terminal" and they will get a key each (that can not be copied).

3. Duelers enter arena zone and it sends them to "THEIR" arena for the length of the battle. If either one of them dies the keys kill delete (mission complete).

4. The keys only last 5 minutes so you don't get much time to mess around before you need to get in the arena.

**I see the need to add new coding to prevent the coping of arena keys and to code the new arena zones.

**If FC was really interested they could make it one big zone with an observation deck. They keys would send the combatants to one of the "pits" to fight (least 40 by 40 in size).

I like the /duel idea but it sounded like a lot of coding compared to leveraging the current "key code" that is in the game. I guess we could also add that "remove buffs" code to the zone requirements of the arena.

Does this "work" better?

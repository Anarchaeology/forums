Do a cut and paste of this into wordpad.

Save it anything you like, IE emote.txt

Make sure the file is saved inside the script directory of where you AO game in installed: Should look something like:

C:/Program File
...........FunCom
................Anarchy Online
..........................Scripts

If you do not see a Script directory, you can make one.

Once the file is inside the scripts directory when you are in-game, simply type /emote.txt and this begins the script.

It's about 2 and half minutes long.

You can edit it to say anything you like in wordpad and simply save again.

Enjoy.

I had performed it at the Gathering of Souls festival today in West Athens at the picnic table and I got several /tells asking for it, so thought I'd share with everyone.

Hmmm, alright if too large for notepad / wordpad - cut and paste into your word processing program and ensure you save it as a .txt file uhder the Save As option.

If a line gets hung up .. you said after /shrug .. just make sure there are no spaces after the word shrug. If a space appears after any word at the end of the line, this will cause it to hang up.

So backspace to bring up the next time - once this is done - then hit your enter key to move the next line back to its proper place.

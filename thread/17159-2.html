If our punching is really based on Melee init (and we all know it is now), it seems to me that with the the free IP reset coming up it would be less work all around to just leave punching on melee, and remove phys init completely.

I could never understand why there are so many inits anyway. It just makes everything more complexe then it needs to be. It should be simplier.

Melee init = ALL melee close combat speed. Swords, beams, blunts, fists, etc

Ranged init = ALL distance weapons. Guns, bows, etc

Nano init = ALL programs. DD's, DOT's, HoT's, buffs, debuffs, etc.

If they fix our punches to work on phys init, then we have to build up both phys and melee init if we want to be able to use MA weapons (assuming they ever fix them). It just makes more sense to only have to built up one init for fists and swords.

And, best of all, it would be WAY less work for FC. The only thing they'd have to change is the verbal description of melee init to include fists, and change the phys init description to read 'does nothing, our bad, am sorry'.

Since there's no way we'd get a fix for init's before the ip patch, it just makes more sense to do it this way.

Oh, and change MA's melee init to green.

Just my thoughts

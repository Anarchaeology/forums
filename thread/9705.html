(IDEA) Nano cluster change Tool & some other things
Hi guys!

I dont know if this is the place for ideas so i just hope it is.
And i dont know if these things allready r in the game (havent seen them)

Lets say u buy an ear implant(A) and a bright cluster, u add the cluster to the implant and then wear it.
After a few levels u find an ear implant(B) with one faded or/and shining, And then u want to remove the cluster u added to Impland A and add it to implant B with this tool.

And for Implant B, u should not be able to remove those clusters that was allready there when u found it only the one u added, if removing those that allready where on the implant they should be destroyed of failure or something just so people dont use the tool to remove all clusters from the implants and gain more credits when selling them.

When removing a added cluster from a implant, it should lover the QL or something and if u remove it a second time, it should be broken but repairable.


Cluster parts & cluster repair tool
When a added cluster is broken u just need to buy cluster parts and the cluster repair tool and repair the tool and the add it one more time. IF u decide to remove it one time again it should be totaly destroyed.

Prices
Nano cluster change tool - around 50 000-100 000cr
Cluster repair tool - around 30 000-100 000Cr
Cluster parts - depending on cluster QL

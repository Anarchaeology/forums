Multiple Item Detail Windows
I am really pretty new to the game and I found something that's a little frustrating to me and I hope there is a good solution to it. When I run a mission I might come across say a pair of boots that might be better then what I am currently wearing so I check the stats. The problem that I have is that I would love to be able to have both of the item stat windows open at the same time so I can check the stats line for line rather then have to continually open each window. Also what makes this more frustrating is that the stats are not always in the same order for what ever reason so it makes it all the more difficult to check the stats line by line. It would be nice to either be able to open up two stat windows or put all the stats in the same order. I am not 100% sure why the stats would not be in the same order anyways.

If anyone has a better way too do this then please lets have it. It just seems to me that its very difficult for the player to examine each piece of gear and judge if it is truly better then his current piece.

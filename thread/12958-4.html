LOL. Ok, to see if a NPC has a quest, do this :

target NPC

/say Hi

If NPC has a quest he will open up a dialog box. Choose your repsonse from those listed.

If NPC does not have a quest, the NPC might be part of a quest but not one that gives out the quest, like nuts n bolts.

A static dungeon is one like smugglers den.

A static mission is a quest.

Here are a few quests :
Fixer quest for grid
Alvin quest for shoulderpads
Quest for living armor
Quest for sentinel armor
Quest for prof specific ring

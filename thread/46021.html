Preliminary Build Notes v14.6
This are not final notes more features are coming.

General Changes
All heals will heal for 50% of their regular power. This new rule will work in both pvm and pvp.
Removed all restriction on pvp now level 200 characters can freely attack level 1 character in any pvp zone.
All ranged weapons will be now soldier only. Exception was done for stigma riffle which is now agent only and some mg/smg like Kaliankov Good Day that now for fixers and adventurer only pistols.
All melee weapons will now be enforcer only exception is adventurer swords.
All nano programs will have level equipments this include heals and damage nanos. Your target must meet level requements to be affected by those nanos.

Playfields Changes
City backyards will now be 25%.

Profession Changes
Soldier Changes
Reflective Shields line of nano will now be only cast on self.
Added new line of nano that increase reflect of team
Added new guns
Total Mirror Shield was fixed it will now absorb and reflect 75% of damage
We extended duration of TMS it will now last three times longer
Removed nano shutdown affect on TMS line.
Added weapon skill buffs.
Added new line of critical chance buff. This line will be self only and increase critical chance up to 60%
Made special token boards for soldiers, it has same modifiers as regular board, but has an affect of flashing sign on top of soldier head PVP GOD

Fixer Changes
Defense modifier on all grid armors was reduced. It will now have maximum of 500 defenses on Grid Armor MKIV
Removed evade boost and speed boost on Grid Armor.
A small note You just wasted three hundred millions was added to description of grid armor.

Trader Changes
Plunders and Divests will now be easier to resist. Ransack line have defense skill nano resistance 690%. And deprive line has defense skill nano resistance 500%
Traders just like engineers will use wrench (look below for description of this tool)

Doctor Changes
Doctor heals have been increased in nano cost and execution time. Complete Heal nano was removed from mission reward and now has drop rate of Nullity MKII
Lesser Muscle Atrophy lines of nano will now work same way as Tired Limbs
Doctors no longer able to wear any armor except med clothes and medical cloak.
Added new weapon called the scalpel

Martial Artist Changes
We drastically increased cast time and nano cost on Fist lines of nanos.
Martial Artist will no longer be able to cast their old critical buff nanos instead they will use new line of nanos.

Agent Changes
Agents cannot use other profession nano programs that higher then ql 100.
Agents no longer able to execute concentration line of nanos while being FP.

Engineers changes
Cocoon line of nanos will now be self only.
Engineers get new weapon called Wrench here is a description of this new weapon
This is heavy metal wrench with rubber handle, examine closely handle you can see some writings which say there is no place in pvp for gimps like you

Nano-Technician changes
Nano regeneration and reduction lines will now be self only.
Introduced new cap on range for NTs, it will now be 50 meters
All nukes in pvp will now do full damage like in good old days.

Pet Changes
Pet patching has been improved!
MP pets will have limited nano pool and explode when they run out of nano.

Launcher Changes
Nerfed login button for those who havent posted at least 10 posts of whine and begs for nerfs, at pvp forum.

Character Created Missions (New Mission Booth Feature)
I think that Funcom should re-think the possibility of having the option of letting players create missions for other players to complete! I remember the concept of this when Anarchy Online finally was released. It was a cery good idea! It apparently was very buggy and was abandoned.

Also, some missions have descriptions which allude to the ability to hack into the mission terminals to create one's own missions... since there is no ability to do this, it leaves one wanting something that does not exist!

The most feesable way for this to work would be the mission creator would access a mission terminal and either have to hack the term using a tool (which would be MUCH cooler) or simply click on the "Create Mission" button. They would then give a brief description of the mission and deposit the items/credits which would be given as a mission reward.

If the mission entails retrieving an object, they would have to return it to the same mission terminal, just like current automatically generated missions. Then the mission creator would be notified that mission has been completed and if an item was involved, the mission creator would be able to access that same mission terminal and withdrawl the newly aquired item!

Now, if the mission creator wanted to change something about the mission, there would be a "Modify Mission" button in addition to the "Create Mission" button.

To make these new missions distinct from the automatically generated missions, there would be a seperate button or something like that to access these missions which might be classified automatically by the server according to what items and areas are involved.

Please feel free to add to this or take from it!! I'm curious to know if I'm the only one who thinks that this would be the coolest thing since Multi-Manned Vehicles! (hehe)

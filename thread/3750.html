Some 'good' clans
this is a partial list, but all of these seem basicly set to help everyone and be 'good'

{Eternal Warriors}, led by Caid.
http://community.anarchy-online.com/...nal%20Warriors
A strong clan with fairly good community, and a definite
postive outlook for Rubi Ka.

{Wasteprowlers}, led by me (I couldn't put it first you know)
http://community.anarchy-online.com/.../Wasteprowlers
Very idealistic, but mostly community minded, and not that
much storyminded (as far as most members go)

{Knights of Sacrifice}, led by Rederon
http://community.anarchy-online.com/...ice%20%7bAA%7d
My personal distaste for the Athens Accords aside, a good
clan, and active. Rederons a good guy

{Tribe of Judah}, led by Whitedread
http://community.anarchy-online.com/...10%17da%10%08h
Strongly suggested, ~IF~ you're willing to be (or play) a
rastafarian. (if so this is the only place)

{The Journeymen}, led by Lorekeep
http://community.anarchy-online.com/...urneymen%10%08
Very story oriented, the only problem I see is that some
people totally cannot get along with Lorekeep, so not for
all.

{Rising Phoenix}, led by Unitsi
http://community.anarchy-online.com/...sing%20Phoenix
Another Great org, Uni has a great mind for clan community
and it one of the hardest workers to get us all talking
together.

{RLA}, led by Tylo
http://community.anarchy-online.com/...s/d/1/name/RLA
Good intentions, if a bit militaristic... one of the main guilds
remaining in Red Freedom

{Mercury Dragons}, led by Windguard
http://community.anarchy-online.com/...lus%20Alliance
Again, very militaristic, but a fairly good place to go if you
want to be a soldier.

added one I forgot...
{Knights of Avalon}, led by Hayjyin
http://www.anarchyonline.com/org/sta...%20of%20Avalon
Good RPing clan, with the goal to eventually merge with the 'galahad' knights. Good people, strong roleplay

These are the people whom I think from talking to them seem the most interested in being 'good' and in Helping Rubi-ka. If I've forgotten anyone, please forgive me, I meant no insult... I can only speak for people I both know and remember.

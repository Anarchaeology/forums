RPBot brainstorming session.
Okay, guys... hypothetically speaking...

If there was a Helpbot type of chat bot available solely for the purpose of RPing. what features you would like to see in it?

Technically, it would be able to:

1. Use text windows to display custom information. Just drop a "knowledge info" to see what I mean.

2. Could have a database support with browsing using some console/chat syntax.

3. Might be interfaced with a web interface (or something that might be easier to edit text windows with).

4. Limitations might be response speed. If there's too many people using it, it'll slow down its responses to avoid being kicked by the chat server.



Okay, so that's the description of what it might be able to do technically. Now, what about content? Just brainstorm. There are no stupid ideas in this thread so post whatever comes to mind.

What would you need it for? As you yourself do the roleplaying I fail to understand the need for an RPBot.

The things I could imagine is a database for your background, such as /tell RPBot History (insert short background here), but then again, that has it's drawbacks too. What's the purpose of telling your story when everyone has read it through RPBot? For IC-reasons, I'd like to tell my history myself, to the ones I choose needs to hear it. Also, with the current limit of /tells those stories would be real short. I can also imagine using it to organize events, kind of like OmniBot, AuctionBot etc. sends out items to the shoppingchannels with regular intervals, RPBot sends out "RPguy invites everyone to a Metalfest at Rompa Bar on 24/5, please don't wear wepons or armor" to some appropriate channel.

What I also would want to see is an OT/Clan IC Channel (opposite of OT/Clan OOC), for roleplaying only - as that would work perfectly in my example

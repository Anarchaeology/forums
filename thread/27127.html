Sick of seeing "Skill available" followed by "wait for attack to finish".
Anybody else sick of seeing this? I'm really tired of constantly getting "such and such a skill is available" and of course when I go to use it I get this message for the next six or so seconds: "wait for your previous attack to finish".

Is it too hard to have the client do a simple check with the server as to whether a skill is actually available since it checks the server anways? Heck, just don't have the client actually display that a skill is ready for use until it actually is. The server already has its own timer, why bother with the client having one too just for it to be constantly out of synch?

It's just really annoying to be constantly lied to by the client about the availability of skills, especially during combat when it's essential to know when we can actually use the skills, be told it is available and actually have the skill be usable at the same time.

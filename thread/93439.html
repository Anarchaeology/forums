OOC: Prefix on threads?
Hi everybody,

This forums contains - and should, imo, continue to contain - both in-character (IC) and out-of-character (OOC) threads. Do you feel we need to be able to tell them apart from each other more easily?

One way this could be done is adding a prefix to the subject of the thread - OOC or IC. How do you feel about that? And should both types of threads have the prefix, or is it enough with one of them having it? If the latter, which one - OOC or IC?

And note that the use of OOC in front of a thread is no excuse for going off the topic of the forum. OOC discussions should still be about role-playing. (This thread being an exception, I guess. I'll look into opening Community Corner for discussions like this again.)

Please let me know what you think.

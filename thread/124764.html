Specialist tradeskills
Well enough about implanting, it seems like a lost cause to argue about losing the main tradeskill that was left as pure NP. Got put in stealthily under the radar.

So my suggestion is a replacement tradeskill, maybe this time one of even more value than implant construction anyways. It looks like with SL all implants are going to go the route of Ptech anyways.

So other than spending a lot of IP to be second-rate engineers and traders it would be nice if NTs and MPs could make use of that green NP. I hope there will be further items for those professions to boost their nano programming skill and something to use it with.

How about the ability to use Nano Programming to enhance nano armor? Doing so would give it a boost maybe to ACs, Nano Resist, Nano Init, and/or NCU.

Maybe a shortcut method for combining pre-programmed crystals with PPPEs using only complit and NP? or another means of making accelerated NCUs or the like.

Anyways, something to return us to being the specialist tradeskillers that we're supposed to be.

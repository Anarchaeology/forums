quote:
Originally posted by wrecklass
Unfortunately, any computer system has to be taken down for maintenance or updates.
Not actually true. The telephone network is a good example. When was the last time your phone was down for a switch upgrade? Basically never.

One way to do this is with redundant systems. Say you have two identical systems. You upgrade the software on one system, and new calls use that. When all the calls on the old system are finished, the old system gets upgraded too.

A virtual persistent multiplayer world is different problem however, because the world is shared. So you can't switch over piecemeal as you can with telephone calls. I think redundancy would still work, but here the problem becomes switching everyone over to the upgraded system at the same time.

This would involve getting everyone's status and position and loading them into the upgraded system, as well as switching everyone's connection to the new system at once.

One way to get everyone's position simultaneously without freezing the system is to use mirroring. You have two systems. You upgrade one, and let it run in parellel with the old system for a while. All information going into the old system goes into the new one as well. In a relatively short period of time, the two system would have a common representation of player positions.

To switch over to the new system, the connections would have to be run though an intermediary machine with a software layer that could easily toggle connections between machines. Under normal operation, each player has a single connection established, and runs through that. Under upgrade condtions, each player has a primary and a secondary connection. The primary is a connection to the old system, and the secondary to the new. To switch between systems, all that is required is to change the stream that is giving feedback to the player's client from the old to the new system. As the new system is in sync with the old because of the mirroring, players shouldn't notice any interruption.

Of courxe, problems would arise of the two worlds were significantly different, as then the mirroring could not be consistent. But for most bug fixes, this is not going to be the case.

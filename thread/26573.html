Hacked Accounts - Technical
OK - just skimmed the 380+ comments and accusations on the Hacked accounts thread. Just to pull out any useful technical info I thought I'd start this thread.

THIS THREAD IS NOT INTENDED FOR COMPLAINTS ABOUT CUSTOMER SERVICE OR REFUND POLICY.

I'm more interested in how the accounts were hacked and how people can defend themselves against it happening to them.

From what I've gleaned the most likely MO's are (in order from most to least):

1. 'Trojan' 3rd party tools - something like AOMD or clicksaver forwarding account details to a dropbox. Likely, since AOMD at least is open source and available for revision, since the victims were in te same guild it's probable that they sourced the their tools from the same site. The only defence against this is not to use 3rd party tools (write them yourself or get the source code, check it and compile it yourself).

2. Physical invasion - someone physically using the victims PC. Unlikely unless the victims are in the same city. If this is the case the hacker is almost ceratinly someone known to them both. Only defence is not to check the remember password option and limit access to the PC.

3. Packet sniffing - possible if the computers were on a public network (academic?). Only defence is load monitoring by the network administrator (and it's not easy.......).

4. PC remote monitoring - if the affected computers have been infected with something like 'Back Orifice'. Best defence is to get some decent antivirus software.

5. Funcom login server hacked - we're all up poo creek..... and if this happened then a lot more than 2 accounts are likely to have been hacked.

Overall the hack looks like it was done by a typical sad git hacker (the use of a cutout dummy account supports this - the account details are almost certainly ficticious).

It's worth stressing, the perpetrator of the the hack(s) is a criminal having commited at least one and possibly more crimes in the course of 'stealing' the accounts (identity theft, misuse of a computer at least - extending possibly to housebreaking and credit card fraud! In the UK this could lead to a jail tem of up to 5 years). This is NOT just a civil case.

Banning from AO should be the least of the perp's concerns if detected........

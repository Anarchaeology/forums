How about a /resync command!
I'm asking for a /resync command (again - first was shortly after the first forum wipe), so we don't have to alt-f4-f4 and reload AO to just get back into sync. And a resync command would be really simple. It would just warp you to where the server says you are, as well as warping any critters in view-distance. Simple as 3.14159265359....

I don't see any exploit-ability in this, since all it does is make sure your computer and the server agree (with server taking precidence, of course).

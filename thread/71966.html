Solution to Pet Pathing - The Phase Grid Device :

-An upgrade to a pet that will make it Grid instead of walk if given an Attack order on a Monster (not players that would be PvP exploitable)
-Also grid back to it's owner if he calls it back (summons it back).

That way it would not run in all sorts of directions when attacking a NPC but go directly from point A to point B where the NPC is. And vice versa when it's called back. It's basically a very short range Teleportation device implanted directly into the Pet.

That way if it gets stuck, the Engineer goes to where he wands it and "summons" it to him ... voilá ... pet is unstuck and ready to fight.

Heck, it could even be a device that was made with Mechanical Engineering tradeskill, I'm sure both Beurocrats and MP's would like to buy a few from the Engineers. Which in turn would make Engineers more .. erhh .. engineer like.

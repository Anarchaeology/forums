RUBI-KA PLAYFIELDS: New Map Website
Greetings!

I just finished making a website which focuses on providing maps of:

- the playfields of Rubi-Ka
- overlay maps for the Whom-Pah System routes (current for 14.4)
- Grid Access Terminal locations
- playfield outlines and names
- links to additional playfield maps available on other websites

A new in-game map file is available on the site for download. Just click on the "In-Game Map Files" link in the website.


The URL is: http://travel.to/rubi-ka


Be well.

UPDATE
Greetings!

UPDATE: A new in-game map is available for download!

The download will provide two files to replace the current in-game map files with maps of Rubi-Ka which has:

  • playfield borders with zone lines
  • playfield names
  • Whom-Pah System routes
  • Grid Access Terminal locations

These maps function just as the original maps do, allowing for zooming in and out, and centering the map to your current location.

To download the new in-game map with border outlines and playfield names, go to http://travel.to/rubi-ka and click on the "IN-GAME MAP FILES" link.

Enjoy! :-)

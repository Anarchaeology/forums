Reusing npc-player characters
To run a story based adventures in AO you will often need to create one or more characters to be used as NPCs. This is time consuming as you may need to level up this NPC character so that he can get to right location for the adventure. The trouble is , once the adventure is over, it is often impossible to reuse the same NPC for your next adventure. Players who met "Peppermint" the sassy waitress in one adventure might be understandably confused (and amused) to meet "Peppermint" the underworld boss in next.

Ideally we should be able to rename our characters, but failing that this is what I am thinking. Maybe we could establish an informal naming convention for NPCs, something neutral like "Genericman01" "Genericatrox04". That way the same "toon" can be used between adventures without the players assuming it was meant to represent the same character each time. I am also thinking if enough people are interested, maybe we could come to some sort to of arrangement whereby we create a pool of generic NPCs for each other's adventures on a "I'll run an NPC in your adventure and you run one in mine basis". Just a thought.

I like to think small, and if it works, build up from there.

This is how I see it. We start off creating generic toons, a set of NPCs that can be used to play any kind of role in any type of scenario. We build a guild for our generic toons. Call it something like "The Extras" or the "NPCs" or even the "Actors' Guild". By setting this up as a guild we can then use the FunCom database as the player registry with all the information regarding professions, level, character portraits available and use the /org info to store a list of contact names. And all this for no extra work. No extra work is a good thing. Never underestimate the power of no extra work.

This generic NPC service would only be available to other guild members. This means that in order to have one of our generic NPC appear in someone's adventure, that someone must provide the guild a generic NPC of his own. No free lunches.

If by some miracle this initiative proved successful then, and only then, I'd risk investing time into a few proper NPCs with individual personalities traits and backgrounds. By then, based on our experience with generic toons, we should have a pretty good idea of which sort of roles were in demand and a bit more experience organising this sort of thing.

And yes, I agree this is just the sort of thing to talk about at the next rp conference, but I think it would look better if by then something where already in place.

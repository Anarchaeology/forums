You never need to accept an identify mission - ever. If you're looking for a token that is an especially bad mission type to select. It is not Funcom's fault that you had this problem, you just need a little more familiarity with the game to avoid this sort of situation.

If you want a token, you want a short mission (and hour and a half??) so make sure the mission ends up somewhere like the Perp Wastes. Set all the missions sliders to the right (tends to give short missions in my experience) and don't take on any Identification missions.

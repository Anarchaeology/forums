Ideas from the RP Conference
I've listed here a few ideas from the Roleplayer's Conference so that we continue the disscusion off-line.

Please note I do not take credit for these ideas nor do necessarily agree with all of them, and I am sure I've missed something out. So please feel free to add or amend.

1. In game object (note pad) to write on so that players can pass notes,
business cards, love letters.
This is covered in full on the following thread in FC Envisioned section:
http://forums.anarchy-online.com/sho...threadid=10676

2. A class of objects that when dropped can be picked up by other players and which does not vanish within 2 minutes (as in the old days). Essential for any "find hidden item"
or "treasure hunt" style mission. The note pad object described above should have this property.

3. The ability to "book" existing locations for a limited period of time. For instance a guild could book in advance the "Omni-Ent Arena" or the "Steps of Madness" for an of hour on a specific date. These sites would remain public for the vast majority of the time, with perhaps one bookable slot per week.

4. The ability to create simple missions so that for instance finding a player character in the mission area can actually be the objective. Obviously this should subject to Xp or loot exploits.

5. A roleplaying flag of sorts, like for instance, a different color in the name displayed overhead with the show-all option.
The aim is to help rolepayers find each other.

6. A roleplayers channel (similar to the OOC channel) or some sort of in game bulletin board where one can leave messages.

7. Roleplayers should perhaps use /whispers more than /tells as a way of getting bystanders involved in our roleplaying.

This could be used for player-created missions, declarations of war, contracts, or even for stuff like an in-game copy of the Tir Accord, etc.

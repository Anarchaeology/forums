The only way you can use two specials when dual wielding is if the specials are different. For Example...

Pistol (RHand) Fling
Pistol (Lhand) Burst

You will be able to use both specials but...

Pistol (Rhand) Fling
Pistol (LHand) Fling

You only get one Fling not two. So if you are dual wielding try to choose an offhand waepon with different specials than the main hand in order to take full advantage. It would be nice if you could use both.

Textures!
With the NW booster pack AO made some improvments to the grafix. But i'd like to see some additional/better textures on buildings. In cities that is. If you have been to Rome, you know how nice it looks. Especially by night. Now, take a peek in Omni-1 Ent. or Trade district you'll see buildings that seem to have no windows at all. Blah blah blah videocard memory blablah you might say. Well, the textures dosen't have to be as pretty as in Rome, but atleast add some textures to make the buildings look more like actual buildings rather than huge concrete towers that has no funtion. Maybe add a 'improved building textures on/off' setting in the options?

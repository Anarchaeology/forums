auto pointing character to enemy
I have a problem with the way the auto-point feature works. If I'm running away and trying to face doors and around objects it is a big pain when my character keeps turning around to face the enemy. I know this is helpful when being attacked and you're trying to find the enemy. So maybe there's some solution to accomplish both. How about a function key that toggles auto-point? When I'm in a big hurry to run away I can hit that while running to keep from getting switched around all the time. In team missions I often find myself unable to use the lift because of this. Lag really complicates this problem so adding a button to toggle it would be fantastic.

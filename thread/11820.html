chain casting observations
The problem is still extant in 13.7, although 13.7 did show an improvement over 13.6.

I spend my time in missions instead of hunting outdoors, so I don't know what the outdoor behavior is, but in missions I find the following to be true:

If anyone is chain casting in a mission everyone is, it is as if there is a set chaincasting on attribute for the mission area.

Chaincasting can occur in any type of mission level and any location.

The chaincasting on attribute is not an integral part of the mission generation, as say the treasure in the chests is. I was in a mission where the server for the mission zone crashed twice, giving me three partial to complete runs through the same area. In the first run no chaincasting, in the second run chaincasting, then in the third run no chaincasting again. In each case the treasure in the chests and the type and level of the mobs was exactly the same. The treasure on the mobs when they were killed did vary.

The bug is not a huge problem for me in most cases. No matter how many roots or run debuffs or such they cast the effect is basically the same, the only big issue is when they use direct damage nanos, mostly traders and NTs.

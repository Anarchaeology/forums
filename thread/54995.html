Use of chat colors in text entry area
How about using chat colors in the text entry area. Use the color the text will be shown with in your own chat window. This way you will avoid most mistells. And it should not be difficult to decode the first couple of chars to change color while typing. So as soon you eg. have typed "/v" it changes the color to yellow. Very simple and fool proof.

A novel idea
Just a suggestion but maybe people wouldn't complain so much if you actually updated the online manual every once and a while. I mean there are functions in the game explained quite clearly in the game and any other documentation we have that simply doesn't work "as intended" at all.

Shotgun skill for example describes the skill as being an area effect attack which we all know is not correct. Both the written and the online manual shows a lot of inconsistencies such as Aimed shot relying on 100% on agility instead of 100% on sense. The description of the sneak attack skill describes it as being the hidden attack able to be used while hidden or invisible...yet no one caninitiate an attack while a cloaking device is active. I mean any new players to the game will be downright confused if they actually read the manual...which is the opposite effect that one is usually trying to go for when you write a manual in the first place. The written manual most can understand that being out of date...but the online manual? I've always thought that was the primary reason that it was there in the first place...to update us on changes to skills abilities and other basic changes to game mechanics that have occured since retail release. Instead the manual and even many of the descriptions of classes, skills and abilities haven't been updated since early beta let alone since release. Is it no wonder the player base has many misconceptions of what each class is supposed to be capable of doing. The formulas for attacks and certain skills don't necessarily have to be written out...but there should at the very least be a general explanation of what each stat is supposed to do or effect. I remember a time when perception skill was actually used by players in hopes of it helping to reduce the effects of an aimed shot. Why did many think that? Because that was how it appeared to work for mobs.

At the present time there are a lot of functions of the game that we are currently attempting to use simply because that is how it appears to work. Another example would be the proper usage of the aggression defensive slider...everything we know about this tool is all based on guesswork. With all of the misinformation we have been given it really ticks me off when I hear that something that was at least functional becomes buggy and practically useless at times was "fixed" because it wasn't working "as intended". Also if we had a better idea on what our skills are supposed to do and effect we would be better at spotting things that are bugged...of course that could be why they don't update the manual with the way skills are supposed to work because they don't want us to know how badly they messed up the implementation of a skill.

If everything was working as intended in the first place we wouldn't have half of the complaints that we do now currently. Fixers would have sole access to the grid and agents would actually have green martial arts skill as was in beta but they still haven't corrected the in game description of agents to reflect that.

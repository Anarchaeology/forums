Hypothesis: PvP balance cannot be achieved in an RPG
Lots of good whining here, I enjoy it. However, I have a proposition for ya'll:

Can you come up with a better system?

My hypothesis

It can't be done

Here's why:

[list=1][*]It is a RPG. Therefore there are different classes with different abilities[*]Some of those classes will be better at healing, some better at dealing damage[*]Some classes will be better at defending, some will be far better at attacking[*]Over time, the damage dealers will be better at melee than the healers.[*]If you give the healers more damage dealing abilities, the damage dealers would need more healing abilities.[/list=1]

I'm talking about 1v1 mostly here. If you have balanced teams it is different. But most of the folks are complaining about how they get owned by someone in 1v1.

BTW, there is a solution, and it has been stated before. Make one class for everyone. Give them the ability to use the exact same weapons, and the exact same shield/health kits. Also, make them all have the exact same stats on offense/defence skills. Lastly, make them all the same level with the same hitpoints.

There ya go, perfect balance. This has been achieved, and the clever folks out there know the names of the games that have this perfect balance already designed into them.

But how would you build such balance into a RPG, with different classes, levels, and skills on the characters so that they all have an equal chance against each other?

Funcom has hypothosized, as I did, that it isn't possible. So tell them how to do it. I'd like to know myself.

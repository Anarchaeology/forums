PvP and PvM
Indeed, PvP is an entirely different beast to PvM, and should infact be treated as such. It IS possible to have one set of rules cover both, but generally that only works for pen and paper based games, not computer games. There, the rules should be similar, but definitely not the same.

Nonos and Nano Resistance is a good example. All nanos have a nano resistance multiplier so some nanos are easier to resist than others. In reality there should be two, one used versus players, and one used versus MOBs. In many cases there might be no actual difference in value, however, skewing things in the player's favour a bit, giving players more chance to resist nanos in general, and certain nanos specificaly.

FC should balance for PvM in the basic rules, and create exceptions as needed to then balance PvP without breaking PvM. The 40% damage cap is an example of this already in the game.

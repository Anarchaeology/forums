Hybred Professions

Wouldnt it make the game more interesting if we could take other professions like in other games like D@D. You know like fighter mages or fighter thiefs. But with us it would be Enforcer MPs or Agent Docs in Trader mode.

Now hear me out first before you thump on my idea. This is how FC could do it. Say you pick a profession and you get all the bonuses and negitives of that profession. And any armor or profession only stuff still requires you to be that profession. But we get a new page on our skills and call it Hybred Professions and have a tab for every profession on it. On this page it makes it so that we could use our IP on the use of other Professions nanos. So if your an Eng and you would love to use some low level MA buffs you could put points in MA and use some of there nanos.

Of course there would have to be have restrictions on how high of other professions nanos you could use. Like if you was level 10 then the highest of any other professions nano you could use is level 5QL. Say cut it in half just to keep all professions different from each other. It would really be dumb if one Profession could do all anothers nanos. But at level 200 a char doing level 100 nanos in another profession would be kinda cool. Muti nanos skill would make all kinds of new game play.

Ok now say your a NT and you put points into the NT tab in your Hybred Profession page. Well funcom could add NT nanos that required you to put IP points in NT and the same for all other Professions. This would allow nanos that no other profession to use at any time just NTs.

Ok now this also would be a drain on IP making it impossable to to all other proffesions nanos. Forcing you to really think about where to put IP. Example...Do I really need a gun with full auto or do I want a lower IP weapon so I can use that low fixer run buff. In that way the game would even itself out. People would have to really think hard if it would be worth the IP to use other nanos.

OK all I know this is just a pipe dream and it will never ever happen but its still fun to think of all the posabillitys and combinations something like this would add to the game.

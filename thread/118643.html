Personal Robot Brains (revisited)
The description seems to indicate they are in an unfinished state.

http://www.aodb.info/showitem.asp?AOID=156027

So with a little more tinkering a Skilled Robot Brain could be obtained

take a tutoring device of suitable QL, open its circuitry with the Hacking Tool (or similar device)

construct an interface for the opened tutoring device
(there are a large number of items existing in the database that can be used for this, ie "Highly plastic mother-circuit array", "Main Frame Human Interface" etc. that rarely get used very much at all)

combine the interface with the tutoring device, and then with the Robot brain.

such an item would then give its wearer at QL 200
+15 Sense
+15 Int
+30 x Skill (as defined by tutoring device used)


a second possibilty is to use the Weapon Component tradeskill items in a similar fashion
eg http://www.aodb.info/showitem.asp?AOID=137190
these when constructed in a similar way above could add a small
buff to a Single weapon/special attack skill or attack rating/damage output


I know this idea is a little vague, but constructive critisisms and refining comments are welcome.

That sounds like a good idea, and a good tradeskill use. As you mentioned, a lot of the icons and pieces are already in-game.

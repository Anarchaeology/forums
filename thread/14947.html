Grow/Shrink bracers appear to have no visible effect to others
I'm not sure how new this bug is, but it's certainly there now, and I'm sure it wasn't there before. It seems that Bracers (and presumably backpacks too) scale modifiers aren't taken into account when you first see somebody elses character come into view. I've tested this, and people see me as being normal height, despite having two Growth bracers on. Taking them off makes me appear SMALLER than normal (so it's removing the modifier), until I run out of visual range again, after which I'm back to normal.

Only way they show up is if you run up to somebody, put them on, and then never leave their visual range

This doesn't seem to apply to nanos though... Ruse, Enlarge and Essence show up fine... it's just the bracers.

Sure hope this is fixed soon. Hardly an urgent problem, but... damnit... I wanna be tall

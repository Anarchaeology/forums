Izgimmer CCD 4000 (New Item!!)
NCU = nano containment unit. Defines the number of friendly nano programs (buffs) you can have at any one time.

Belt Component Platform 6K-X - Equip this Component Platform in your belt slot, and install upgrades to your NCU-unit. This can contain 6 upgrades! This is the hottest on the line right now, costs a bucket, and is hard to use!

Okay, I supplied the AO definition/description of each item so that you have an understanding along my line of thinking. A component belt is designed to hold a number of NCUs that allow for containment of friendly nano programs (buffs). It is not a cyberdeck that executes programs. So with that said, here is what I have thought about for some time now.

An NT executes a number of hostile programs and the animation effects show him executing these programs by using his hands as if hes typing on some type of deck. I am fairly certain that Funcom always felt the execution of programs was done through some type of computer deck or cyberdeck. Most NTs dont want weapons. We want increased damage and we want some type of nano crits with our existing nanos. So we want more damage and added crit damage with faster recycling nano attacks.

So how about a new item that fits our profession much better than previously suggested items. This item fits in the (RIGHT hand). I present to you the Izgimmer CCD 4000 (Commercial Cyber Deck). The Izgimmer CCD models were first created by Mehar Izgimmer to help outfit his RRC (Recharge Recompiler Chips) which would diminish the recharge rates on executed nano programs. Mehar eventually created newer models to accommodate third party vendors that redesigned custom chips to fit into his vastly popular cyber deck. Each of the 4 CCD models allows upgrades to other chips but the amount of chips each model holds separates them from the rest. The 1000 holds 1 chip, the 2000 holds 2 chips, the 3000 holds 3 chips, and the 4000 holds 4 chips with a special customizable feature for a Fastjack O-Ring Railblaster.

Izgimmer CCD 1000 (Commercial Cyber Deck)
--Can contain 1 chip (UCAC type 1 / DAC X / or RRC-1 only)
Izgimmer CCD 2000
--Can contain 2 chips (UCAC type 1 or 2 / DAC X or XI / or RRC-1 or 2 only)
Izgimmer CCD 3000
--Can contain 3 chips (UCAC type 1,2, or 3 / DAC X, XI, or XII / RRC-1,2, or 3 only)
Izgimmer CCD 4000
--Can contain 4 chips and 1 customization (UCAC types 1-4 / DAC X-XIIa / RRC 1-3 and a Fastjack)
Description  Izgimmer CCD decks are designed as small portable computers which help to execute programs in a variety of ways. Each model has its own specialty chip and a variety of containment slots for third party hardware upgrades.


Praetorian UCAC Type 1 (Universal Critical Analysis Compiler)
Praetorian UCAC Type 2
Praetorian UCAC Type 3
Praetorian UCAC Type 4
Description  Praetorian UCAC chips analyze codes within nanos that are executed and compile them in such a way so that they are boosted to greater than the maximum potential the code dictates. This results in very damaging nano programs that critically hit based off a set percentage determined by the type of compiler chip. The drawback of using this type of chip is that it has a potential flaw which may shut down the CCD deck for up to 30 seconds due to a power fluctuation as it compiles. The drawback occurs very rarely though.


Phoenix DAC X (Damage Allocator Chip)
Phoenix DAC XI
Phoenix DAC XII
Phoenix DAC XIIa
Description  Phoenix is an up and coming hardware vendor that prides itself on a very clean product that helps nano-technicians increase damage potential with existing nano programs. The DAC chip is a state of the art nano-circuitry cpu that redefines how programs are executed through the deck. When a nano program is executed, the chip monitors the process and diverts memory to the cyber deck storage containment slot which helps the programs execute more smoothly and efficiently. It has an added effect of increasing the base min/max damage assessment of each executed program by a set percentage determined by the type of chip used.


Izgimmer RRC-1 (Recharge Recompiler Chip)
Izgimmer RRC-2
Izgimmer RRC-3
Izgimmer RRC-4
Description  the Izgimmer RRC chip was designed with the help of several expert Engineers who modified its design to work with the CCDs. The RRC chips recompile the execution frames for each nano as it is set into motion, effectively reducing the recharge rate per nano program. The amount of recharge rate reduction is determined by the type of chip used.


Fastjack O-Ring Railblaster (Custom fitted only for the Izgimmer CCD 4000 model)
Description  this small barrel is custom fitted for the CCD-4000 and fits along the width of the deck in a specially created containment unit. The barrel uses rail technology which is a magnetic propulsion system designed in the O-rings which allow an object to be pushed to the next ring and so forth, creating an extremely fast object by the time it reaches the last ring. This railblaster fires notum particles that are built up around the cyber decks power supply, drawing the particles from the very air itself and condensing them into matter missiles. This weapon effectively acts as a special attack, useable once every 25 seconds. The type of damage is projectile based and is considered a burst.


What is the end result 

A Nano-Technician wielding an Izgimmer CCD 4000 with an Praetorian UCAC Type 4 chip, a Phoenix DAC XIIa chip, an RRC-4 chip, with a customizable Fastjack O-ring railblaster. This technology would allow more base min/max damage for nanos executed, the chance for a critical hit also, while lowering the recycle rates of all nanos executed. Oh, and you get a burst special attack as well. What this would do is bypass more buffs that we would have to outfit to create the same desired effects like critical hits and recharge rates, and still effectively giving us a burst attack. The skills used to wield the deck would be probably based off of computer literacy, nano ability skills, and for the last implementation, burst skill.

You may or may not like this but its not a staff and its not an IP costly weapon. Yes, funcom could fix the nanos so that base damage is increased but until they say yes we will, this is another solution. As for the critical hits and recharge reductions those they would only implement via another buff. We know they would do that and this would crunch our NCU even more. I like the idea of a customizable cyber deck and it doesnt even have to have these things  but it could have a number of different types of chips and you could pop them in and out for whatever type of fighting you were going to do.

Let me know what you think.

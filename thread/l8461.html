I remember reading a few posts from people who couldn't download the patch, so I've compressed the files (with full directory structure) and put it on my webspace for you to download. You'll need winace to unpack it (sorry wouldn't let me zip it up for some reason). Get the file here:

http://homepage.ntlworld.com/hushbl...ane/Aopatch.ace

Once you have it simply unace into your Anarchy Online folder, overwriting all files.

BTW I'm not guaranteeing this will work, but its worth a shot. If it doesn't work, I'd imagine you'll need to reinstall AO. If this helps you please bump the thread for others to use . Please also post if this doesn't help, so other don't needlessly try it. Thanks!!

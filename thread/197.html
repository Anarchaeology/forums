List of changes that were not mentioned
Feel Free to add your own. Since Funcom wont list them, perhaps we can help other players out instead.

- Tank armor nano requirements fixed, you now have to have double the stated nano to run any nano programs while wearing tank armor. Previously you could run programs if you had enough in your nano pool to cover the stated nano cost in the description and they would still run just reducing your nano pool to 0 if you didn't have double the nano (hope that makes sense)

- Chat text colours changed.

- Mission blitzing disabled, you now can not collect mission rewards while a mob is aggro'd on you.

- 40m Range cap on nano programs, this was mentioned in the forums but not the patch notes.

- Vehicle will now stay on while unequipping and if you zone while its counting down it will still be on when you have zoned forcing you to unequip it again.

I'll add to this as I think of more

1. i think alot of improvements have been made. one of the changes i liked the most was the option to change the graphic format AO uses to another that loads much quicker. it really helped a lot for me. tradeskills are also improved, though not perfect, they have gotten alot better. new content has been added, some static dungeons. the latest patch says there will be static missions as well, plus if you have seen any of the screenshots that funcom has released of pictures of the new static dungeons, they look real sweat. some things still need improving like class balancing, pvp and some other things, the game isnt perfect, but it sure improves with every patch and i think that being a citizen of Rubi-Ka is much more pleasant now than it was in the beginning.

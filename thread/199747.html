quest program
so i got bored the other night decided to do some quests my internet was being lame webpages were comin up slow/timing out so i decided to screw around with an internet independent program side from updates and came up with AO Quest

its simply a program that reads html files with quest info in them ie pictures/coords/how to etc and displays them the whole point is to load the pages off your harddrive instead of goin out to the net and loading em up

to install simply extract the program to any directory
to update extract the update files to same directory as the ao_quest.exe

not much to it tried to keep the interface clean and simple hope this is useful ;o and if you find any bugs or have a problem /tell bettyross or leave me a pm here on the forums

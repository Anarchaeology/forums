Some small changes
I've done some minor changes on the bulletin board. Some were done when we turned the search option on again after rebuilding the search index, while others were added right now.

The changes are...
- You now need to wait 10 seconds between each search. This is to prevent flooding the database with requests during high activity periods.
- The default search period for a search is now "a month ago" - as opposed to "any date". This is to reduce the search sizes, for the same reason as above.
- Time limit between posts is reduced from 60 seconds to 30 seconds.
- All threads will now have numbers linking to ever page of the thread on the top and bottom of the page. This used to be only 5 pages. Threads will also link to the first 5 pages on the thread listing (forum view).
- You now have 10 minuted to correct / edit the title of your thread. This is done by editing the initial post's topic. After 10 minutes, only the post will be edited, not the thread. This used to be 5 minutes.

That's it for now.

SUBSET HOTKEYS (NOT INCLUDING NUMLOCK)- ACTIONS (LAYERED FUNCTIONS)

Subsets add additional functionality to the hotkeys. Example: TAB will
auto-target to the next hostile target (within range, without another
target, it will maintain targetting of the hostile already selected-
or nothing at all). If you click CTRL+TAB you will, instead, target
the next friendly. SHIFT+TAB will target the next hostiles in reverse
order. SHIFT+CTRL+TAB will target the next friendly in reverse order.

These are the subsets for the common hotkeys:
CTRL+TAB - target next friendly
SHIFT+CTRL+TAB - target next friendly (reverse order)
TAB - target next hostile
SHIFT+TAB - target next hostile (reverse order)

CTRL+V - past text from clipboard (works in all Windows programs)
CTRL # (# from 1-9) - Pull up Side bar options including Stats, Missions,
etc. (moving from left to right through the 9 options menus)

ALT+F4 - quit program (function in all Windows programs)

CTRL+F8 - next camera forward

SHIFT+F8 - next camera backward

up_arrow(hold)+ALT(release) - Forever walk forward
left_arrow(hold)+ALT(release) - Forever turn left
right_arrow(hold)+ALT(release) - Forever turn right
down_arrow(hold)+ALT(release) - Forever walk backward
up_arrow(hold), ENTER, (release up_arrow), ENTER - Forever run forward
down_arrow(hold), ENTER, (release down_arrow), ENTER - Forever run forward
left_arrow(hold), ENTER, (release left_arrow), ENTER - Forever run forward
right_arrow(hold), ENTER, (release right_arrow), ENTER - Forever run forward
w(hold), ENTER, (release w), ENTER - Forever run forward
s(hold), ENTER, (release s), ENTER - Forever walk backward
a(hold), ENTER, (release a), ENTER - Forever turn in circles
d(hold), ENTER, (release d), ENTER - Forever turn in circles
z(hold), ENTER, (release z), ENTER - Forever strafe left
c(hold), ENTER, (release c), ENTER - Forever strafe right
(hold)CTRL+SHIFT, LEFT-click on stacked items to display amount. While
holding keys, move mouse left or right to unstack amounts. SHIFT+# (where
# means 1-9) - cycles to the group of your hotkeys function according to
what number you use

CHAT CONSOLE - COMMANDS & FUNCTIONS

ENTER - enter input/chat/msg mode
BACKSPACE - delete previous character (common in all windows programs)
CTRL+BACKSPACE - delete previous word
INSERT - toggle insert/overwrite (common in all Windows programs)
DELETE - delete character
CTRL+DELETE - delete word
HOME - home
END - end
SHIFT+Right - moves cursor right 1 space (without deleting)
SHIFT+Left - moves cursor left 1 space (without deleting)
CTRL+Right - next word (forward, without deleting)
CTRL+Left - next word (reverse, without deleting)
SHIFT+up - repeats last statment. SHIFT+up repeatedly will scroll through
last few messages posted. SHIFT+up will remove the hotlink from items
listed in the chat window (ie. cannot click to view).


To cycle through multiple incoming tells, first, SHIFT+r to bring up the
auto-response (/tell [name] displays automatically for last incoming
whisper). Next, SHIFT+up to cycle the responses until you find the person
you want to send the tell.



/r [message] - Reply to last incoming message
/reply [message] - Reply to last incoming message
/tell [name] [message] - send a tell to another player
/text [text] Will not be shown to anyone else but you
/s [message] - Shout message
/shout [message] - Shout message
/whisper [message] - Whisper message (smaller vicinity chat)
/w [message] - Whisper message (smaller vicinity chat)
/me [message] - Character action (sometimes called "emote")
/say [message] - Normal vicinty message
/ignore (while player is selected) - Toggle ignoring of the selected
character.
/group /g [group_name] [message] - Talk to group
/invite [nick] - Invite a user to private chat group
/kick [nick] - Kick a user from private chat group
/help - Help for chatcommands
/log - Toggle logging of the chat to the file "LogFile.txt"
/n - Answer "No" to a game-play related question shown in chat
/y - Answer "Yes" to a game-play related question shown in chat
/chathelp - Chat commands
/pet help - Pet commands
/script [name] - Executes a script located in the
c:\program files\funcom\anarchy online\scripts directory *For more
information regarding scripts and how to write them, click here
/[script_name] - also calls scripts
/macro [name] [text to chat] - Creates a macro and icon
/selectself - Select Self
/played - Time played
/funcom - "This game was made by Funcom"
/afk - AFK mode
/terminate - Terminate self, kill character.
/quit - Automatically quit the game (no delay on client-side)
/camp - Begin the logout timer
/viewdist # - Set your viewdistance to # percent (if no #, sets to 0%)
/chardist # - Set your chardistance to # percent (if no #, sets to 0%)
/char&viewdist #1 #2 - Sets both values with single command.
Viewdist (0-100 meters)
Chardist (5-80 meters)
*An approximate 50% settings would be /char&viewdist 40 50

/follow Follows targetted character or NPC
/ch [channel name] or /channel [channelname] -- Channelname may be
multiple words now, at least on test, so you can '/ch v' for vicinity,
or '/ch ot sh' for OT Shopping (will pick first group name in list that
matches the string), or '/ch OT Seeking' for the seeking team channel.
(would need to specify whole thing to get anything but the first seeking
channel, as in 'ot seeking team 10-50' or the like.)


**To chat to an NPC, make sure you have them selected. You can chat to
an NPC through the vicinity, whisper, & tell channels.

NUMLOCK KEYS

The numlock keys control your camera views/movement (in the default mode).

- - zoom out
+ - zoom in
8 - camera down
2 - camera up
4 - camera left
6 - camera right
5 - reset camera to default
0 - auto-run (forever run forward- reverse movement key to stop)
These controls are functional in all camera views, including first-person.

Note: Pressing F8 (FPV), then F8 again will automatically return you to
your previous camera selection. Camera is preserved when not in movement.
To lock camera movement, change the settings in the main options menu
(F10). Also, ALT+SHIFT+F9 currently brings up the in-game bug reporting
form. CTRL+ALT+F will bring up the "FPS" or Frames Per Second.

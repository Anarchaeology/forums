Agent nano...
I had an idea for an new Agent nano I wanted to run by you guys.

Many a times I have been in a team mission in which some one wants MP buffs or Crat's Baton, or whatever. I am happy to buff these folks, but it leaves me stuck in that profession, and I would rather have access to my crit nanos, roots and "tickle dots", as an Agent I do more over all damage, than in FP/MP/AP.

So, in the past it has been suggested that AP/MP/AP be non hostile so we could cancel it, but that would create problems with over self buffing (so they say..not like I can't just ask other profs for thier best buffs). My suggestion is to create a nano for each of the FP/MP/AP lines that removes the Agent from the profesion, thus allowing us to help others with a buff they need while still being able to return to Agent or the other FP we were in.

What would make this nano different from just allowing us to cancel FP you ask? make it whipe not only the FP, but all nanos running in our deck, thus removing any "over buffing" concerns.

This nano would have to be fast, and use very little nano, I could put the usual mock description up, but feel rather lazy today, so I wont.

What do you guys think? Be nice.

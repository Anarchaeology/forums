thats a rough indicator of how much of your CPU is currently active, yes. The CPU (central processing unit) is capable of performing many simultaneous calculations/operations. Generally, the home PC is capable of doing many more than they are usually used for... they only really get fully utilized when doing graphics and/or sound manipulation that requires a lot of memory addressing and mathematical calculations or running current games.

The idea of the 'spare cycle' comes from the fact that computers operate on a clock (the 1.5 GHz part of the stats of the computer). With each pulse of the clock, every single register (memory location), mathematical unit, and so on... cycles... or advances. Some of these occur in parallel to each other, some in series. But they're there, whether assigned a task for every single pulse or not. There are also plenty of times when one set of calculations is delayed, waiting for information to be loaded into the proper registered before calculations can be continued and so on... not all of these times can be 'exploited' by another program (because if you're waiting for something to be loaded into memory already, trying to load more info for some other program isn't really going to do anything but slow you down), but there are plenty of times when there are available resources that can be used.

Additionally, many people (wisely) leave their computer running when it isn't in use because they use it often enough that starting it up and shutting it down frequently puts more stress on it than leaving it on 24/7.

When you aren't using the full capacity of your computer, you're often not only not coming close to 100%... you're probably much closer to using no more than 10%. Sort of an all or nothing world...

NOTE: I am quite aware that this is a simplification of computer architecture / engineering... but it should serve for this purpose

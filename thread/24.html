Describe item missions:

If you pick item up -> Mission REMOVED since target item no longer exists in mission. Dropping it back has no effect, since the mission is already removed. Meaning, don't pick it up until you complete mission.

How to complete -> Target item when closeby, wait about 5secs.

How to target -> single left click.

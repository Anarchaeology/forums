Been realizing there is another chat thing in AO that drives me nuts..

"/" should automatically invoke the chat line.

Having to press enter, and then "/" for each command is unneeded. "/" should be enough. The game should know you are about to issue a chat command. In addition, most of games work this way which causes me all sorts of confusion. Its pretty standard for me to use start type /somecommand then have the chat bar come up when I push enter at the end.

I think games should innovate and be different, but some areas some degree of commonality can really help.. chat is one of those areas.

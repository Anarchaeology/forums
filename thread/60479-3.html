WARNING Solution to path problems enclosed, Might take some experience in development to read... (cz, dont even bother trying )

its called A* (pronounced "A-star").

This heuristic search ranks each node by an estimate of the best route that goes through that node. The typical formula is expressed as:

code:
(n) = g(n) + h(n)

where:

f(n)    is the score assigned to node n 

g(n)    is the actual cheapest cost of 

        arriving at n from the start 

h(n)    is the heuristic estimate of the 

         cost to the goal from n

ok, over to some code..

code:
	s.g = 0		// s is the start node
	s.h = GoalDistEstimate( s )
	s.f = s.g + s.h
	s.parent = null
	push s on Open
	while Open is not empty
		pop node n from Open  // n has the lowest f
		if n is a goal node 
			construct path 
			return success
		for each successor n' of n
			newg = n.g + cost(n,n')
			if n' is in Open or Closed,
			 and n'.g <= newg
				skip
			n'.parent = n
			n'.g = newg
			n'.h = GoalDistEstimate( n' )
			n'.f = n'.g + n'.h
			if n' is in Closed
				remove it from Closed
			if n' is not yet in Open
				push n' on Open
		push n onto Closed
	return failure  // if no path found
-------------

EDIT: A small image to show the logic in action
Might help to clear things up
the black areas is walls, and the Grayish are different levels of obstacles.. the darker they are ,the higher the movement cost.
-------------


A* has a couple interesting properties. It is guaranteed to find the shortest , or the fastest if the map has movement cost, as long as the heuristic estimate, h(n), is admissible-that is, it is never greater than the true remaining distance to the goal. It makes the most efficient use of the heuristic function: no search that uses the same heuristic function h(n) and finds optimal paths will expand fewer nodes than A*, not counting tie-breaking among nodes of equal cost.

Using A* would solve most (all?) of the INDOOR pathing problems

for outdoor, other systems might work better, like one called 'Dijkstra's algorithm' (also public availible)

Also, for those MPs who don't bother casting their pets, here is the best workaround we currently have.

Cast pets. Rename them. Put attack pet on guard. Put heal pet on heal.

Never give them a command again except when going up an elevator. Then repeat commands.

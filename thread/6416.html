How to fix PvP
There is a very simple solution to the current PvP problem where doctors are almost invincible. Remove or change Vektors. The problem isn't that healing is too powerful, the problem is that Doctors can overequip these nasty vektors and other shotguns so far due to skill wrangles. I played with a level 70 doc last night that was using a QL131 Vektor, there is no way that a doc could overequip this weapon without a skill wrangle, but in doing so he gets access to one of the most powerful PvP weapons in the game. Vektors check against Duck skill which most dont raise, hits for energy damage, and has an very high critical damage. The doctor was able to crit for close to 1700 damage. My QL184 Nova Flow only crits for about 1900 damage. THIS is where the imbalance is, sure the Vektor doesnt have fling or burst, but fling and burst are hard capped but the vektor's CRITS ARE NOT. Now I know that in PvM the Nova Flow is a superior weapon, but we're talking strictly PvP here and in which case the vektor is a very strong competitor for the Nova Flow with the current special attacks nerf.

This is in no way meant to nerf Docs in PvM, I think everyone should be able to hold their own in PvM, but Im just trying to point out one aspect of the problem with PvP. When you carry about the same caliber gun as me AND heal, its not balanced at all.

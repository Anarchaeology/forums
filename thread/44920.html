What about a "notepad"?
What about making a text editor that you can write down things to remeber? This would be an extended text editor that supports the hyperlinking used in the chat today.

If it was possible to drop a reference to a player into the editor (creates a link) and any other item it would be great.

For exploreres, make a shortcut that will paste in the current zone and coordinates, also as a link. When you click that link your map will open and show the location.

An easy way to drop this info to the chatbar whould also be cool :-)

This idea will not give content to gameplay, so i guess this is something that can wait. It was an idea anyway.

In-Game notes
I've had plenty of ideas I have submitted to the boards about this idea alone. Lately a boost in reference generators has started. I use one to make references for advertisement and I'm sure you've all seen the same. If not, you can generate a refrerence that will appear under your knoledge tab that you can drop on your chatline. Bad thing is is you can't use it while the game is running.

If we had a reference creator in-game we could do alot with it. Down-side is we can't trade references. I think. Never actually tried though. The use of references is already there. If we cant now, it shouldn't be hard to make it so we can trade references in game.

This seems to be a more simple aproach than my previous ideas on the subject. Less work for FC.

Here's a link to the file download for the Reference maker
http://webpages.charter.net/aofun/do...RefMaker20.zip

This is a 3rd party app but I have checked with FC and they said that they won't stop it as long as no exploiting can be done with it. So as long as people don't abuse it we have another roleplay tool too use.

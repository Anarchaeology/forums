Five little things to change to make the game play so much better...
There are just a few things that would sure make it an even better game:

1. If you are sitting, make it so when you move forward or back, you automatically rise. I hate having to hit the "X" to rise first.

2. Do I really need to have all that info whe using F9 key for location? Personally, I would like just the Position, Area name and Suppression. The rest of that stuff looks like debugging info that was never turned off.

3. Why won't the sliders on the Mission Terminals stay where I put them? Once I set them, leave them that way until I choose to move them again...even if it a hundred misison requests or two months later.

4. Make the Chat Box resizeable. Is there any real reason why it shouldn't be? I would like something only half the size it is now. Even better would be to have the box split for chat and combat status.

5. I am a MP pet user. Could we have a key that will cycle though the pets? It is very hard to find them sometimes, they get hidden in walls, other rooms, ceilings, invisible...who knows where, this would make it much nice to get them healed.

Just five little things that would improve the game. Any chance that Funcom would act on these?

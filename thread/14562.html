Doors in the missions
My guild mate and I were trying to blizz a QL200 mission yesterday . It didn't work out too well as we are both about 50-60 levels short, but I got an idea which I belive might be worth looking into.

There were a lot of locked doors, like in most missions, and I thought that if the doors can be unlocked, wouldn't it be nice if they could also be locked by players? This would add an interesting strategy for doing missions that would involve smart teamplay as it would be possible to "disable" really tough mobs that you just can't handle (Veteran Enforcers come to mind ) by locking them in rooms... For example a fixer could run to him, piss him off and start running back while someone else would stand ready with the lockpick near the door. Once the mob is in the room, root him and lock the door!

Code wise this should be really easy to implement as I am almost sure that there is a simple flag that is set if the door is locked and is not set if the door is unlocked (or something like that)... so if you click lockpick on the open door and you have enough points in b&e skill the door becomes locked.

just something to think about..

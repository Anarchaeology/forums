Question about Fixer's Summon Grid Armor
Recently, 2 professions were "enhanced" by Funcom, the Engineers and the Fixers. Engineers received 2 new lines of nanos, Sympathetic/Distruptive Auras and the Beacon teleport series. Fixers received new summon lines for ammo/armor/weapon and *grid armor*.

-- Engineers:
The Auras and the Beacon series are incredibly useful to a group and greatly enhance the utility of an Engineer in a group. I am happy for them. Additionally, the new nanos all have 3 requirements, which are MatterCreation, MatterMetamorphosis, and TimeSpace. All three happen to be green skills to Engineers and already used by other Engineer nanos. This is great! It means that current Engineers won't need to spend ungodly amount of IP to use these new nanos!

Last, all these new nanos are fairly easy to get either as mission pick up item or mission rewards.

-- Fixers:
Ammo/Armor/Weapon summon nanos: I think we've heard enough complaints on these nanos, Funcom please reconsider these and see if they can be made less useless... The only "good" thing is that these are at least available as mission rewards.

Now... the point of this post:

*Grid Armor* summon nano: I have finally heard that 2 fixers were able to find the components and have someone build the Summon Grid Armor Mk I(QL60). Ahh... so Summon Grid Armor is *trade skill only*, and the instruction disk is extremely rare it seems. Now, once the Nano Crystal is created after huge amounts of cred and effort, here are the requirement:

TimeSpace 261
MatterCreation 333
MatterMetamorphoses 365

For a QL60 nano that's EXTREMEMLY hard to get already?!

For comparison, look at the following fixer nanos:
QL57 - Team Grid Phreak (PsyModi 278/SenseImp 278/MattMeta 278) - this can be considerred one of fixer's defining nanos
QL60 - Venom Modification (MattMeta 289/SenseImp 289)
QL73 - Invasive Micro Entanglement (TimeSpace 261/Sense Imp 365) - this only takes 2 skills at QL73

Not only that... As anyone who has played a fixer knows, up until this "enhancement", there has not been any fixer nanos that use MatterCreation as a required skill. (There was a bugged summon ammo nano that required 901 MC and something else, but I don't think that counts) As a result of that, NO fixer has ever increased his/her MatterCreation for nano skills, which was a blessing, since we have *all* dark blue nano skills, all six of them, just like enforcers.

So now, unlike the enforcers, who has at least one unused dark blue nano skill (TimeSpace) and one very rarely used one (SenseImp, used in only 5 nanos), fixer nanos now require us to put IP into *all 6* dark blue nano skills!

This *may* have been fine IF this is the situation since the very beginning, but it is NOT. And this means that for all the fixers that are currently already at a high enough level, we can't even choose to improve MatterCreation since we have spent all IP on all the other nano skills. Add that to the fact that the QL60 Summon Grid Armor nano has exceptionally high requirement and is VERY difficult to acquire, is this really an enhancement to the existing fixers?

I do NOT understand why an "enhancement" to an existing profession has to make that profession use a completely unused skill when another profession that's being enhanced, and I mean *really* enhanced, uses nicely colored skills that's shared by nanos that's ALREADY being in use by that profession...

Thanks for reading this long post, and please keep the discussion civil. No need for "I hate Funcom!" or "Funcom hates Fixers!" type post.

We need apartment improvements
Lets face it: recent game improvements since the addition of more Miir lingerie lines (thank you Funcom!) have all been focused towards improving the technical / gameplay aspects of the game.

Anarchy Online does have a very active roleplaying community. Granted, we are small, and not as vocal as the power levelers, but we do exist. Today, I am asking that Funcom acknowledge the fact that the AO social / roleplaying community needs apartment improvements. Apartments were a wonderfull concept, but still need work.

I'd like to suggest the following improvements.
- Increase the number of objects that can be placed in the apartment. Many voices have been screaming for this, and it should be a trivial change.
- Allow apartment keys to be duplicated, so they can be shared. This would offer a good temporary solution until proper guild housing features are implemented. Also provide a command for changing the locks that would also work for someone who lost their key (this would reduce petitions).
- Provide a command or object for dimming the light in an apartment. This would be better for mood lighting. You have given us lots of great lamps to put in our apartments, but it is hard to take advantage of them because it is so bright.

Those improvements should not be very difficult to implement. One major problem we are facing that would be more difficult is that of missing chairs, couches, and beds in apartments. It doesn't seem as though the code supports moving around solid objects, and this could cause a lot of problems if used improperly. An easier solution would be to allow someone to pick from a set of furnished apartments. So you could go to the store and buy an apartment deed for a furnished apartment. Of course, the furniture could not be changed or moved around. This would be a positive step towards implementing guild housing.

I hope someone is listening!

If you support these ideas, please add your comments to this thread!

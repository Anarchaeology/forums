Adventurer Website
Greetings fellow Adventurers!

As some of you may know, I've been putting together a website for the Adventurer profession As I care a lot about the Adventurer as a profession, I want to make this site as comprehensive as possible. Jayde and I will be writing articles about each item/skill/armor/equipment that effects the Adventurer. Realize that this site is still in it's infancy and has quite a ways to go That said, I am announcing it now because even though only a few of the articles have been written, this site already helps answer a few questions about the class that i've seen posted.

What would be of great help to me is if you could look over the site, offer suggestions about what to add and what you like/don't like.

Things that would help: Suggestions about items to add to the "Special Armor", "Equipment", "Armor", "Weapons" section. (remember that this is an advent site, so the point isn't necessarily to list every armor/item in the game ) Suggestions for more articles. Ideas for future topics (would be added to the nav bar)

Things that won't help: Criticisms about the layout. It's designed, that part is done. If you don't like it, make your own Advent website

If you disagree with the article that i've written: Great! Send me a personal message (pm) about it via the AO forums. We'll discuss it. Please do not post them in this thread

The site is http://aomainframe.info/advents I hope you all enjoy it and that it can be a web site that helps every one of us

(another note: I realize that this site was designed with those of us with larger monitor resolutions in mind)

15.2.0.2 patch notes on Test
-Numerous gems found in the Shadowlands can now be cut and polished and set into filigree gems. These will not only
sell for a nice amount of cash, but also give minor stat bonuses if worn.

-Some of the lower level boss mobs in the Shadowlands have found a stash of a very sought after superimplants.

-We have fixed mouse syrup!
No more jerky and laggy movement.
No more jerky sound effects and music.
No more need to use the Riva-Tuner workaround.

-Minor changes made to first sub-quest in Drake's Psychic test.

-Fixed a bug with Control Unit Sleeves.

-If you try to increase a skill that has been modified(negative) temporarily you will be given the following
message:
"You can't increase a skill that is temporarily changed!"

-A server-side bug has been fixed; it caused non-developer characters to receive teleport debugging information on
playshifting.

-A lot of monsters in the Shadowlands are no longer completely pulverized but some salvagable remnants of their
bodies may be left on the corpses.

-Added a reload button, it will reload the currently wielded weapon(s).

-We have made a new chat channel called "Tower Battle Outcome". Here we will put results of battles, who the winner
and loser was etc.

-Added a Yes/no box when dropping stuff on ground.

-The Pads of Dedication should be having the correct requirement again.

- Fixed a black line in the horizon in a garden.

-The engineer startup crystal Feeble Automaton will now be uploadable without raising any skills.

-The Heal special ability in the First Aid perk line has been doubled in power.

-When using Brawl or Dimach you will no longer get a message that says "you need long range weapons equipped" if you
use it.

-You will now be able to use the Aban garden key on Shining Redeemed Statue of Transit to get transported to the
Garden of Aban.

-Panicing npcs will no longer run through walls and vanish.

-Fixed a bug that sometimes made indoor npcs slow to react when they were attacked.

-Self only perks can now be used without the need to target yourself!

-Fixed a spelling error on the Composite Melee Expertise line.

-A wear requirement bug has been fixed on all garden keys. YOu can now not equip the key without meeting all the
requirements.

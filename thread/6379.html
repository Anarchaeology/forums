There is an interesting little vehicle available from superior/special stores called the Carrier, which doesn't actually add speed, but strength. So if you have an investment in vehicle ground, you can transfer that skill into strength to equip something as long as you have the Carrier. I have a complete set of Flower's Tech and Secondus coat on my own fixer using this method. Envisioned changes might eventually make this set-up a bad idea and I have a backup suit of armor already assembled for that possibility. But for now, it's the cheapest way to actually equip a coat.

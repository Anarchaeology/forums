the percentage-chance of getting a token is defined by a number of factors:

1) You get a percentage based on how many percent of the mobs you have killed (50% mobs killed = 50% token chance)

2) This percentage can be modified by how many GRAY mobs are in the mission (lowers chance, not sure how much tho) and raised by the number of REDS (i can't confirm this but i seem to recall a GM posting it once)

3) There must be a minimum number of mobs in the mission for you to get a token, the number is different everytime you ask () but it seems to be 6-10ish

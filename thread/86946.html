Galahads are great pistols. I used to use them on my adventurer to do stuff like self cast pit lizard when I was 150.
For docs though, I don't like them.
Docs only really need Biomet boost in the 100-150 level range, after that you have more biomet than you ever need.

If you put IP into a skill, hopefully you will get use out of it.
So....if you are a doc, and know you are going to be using pistol, burst and full auto, and are going to dual wield, maybe this makes sense. How many dual wielding docs do you see these days?

So....pepper pistol, requires pistol skill, and as we know, a QL 51 pepper pistol can be equipped with NO ip expenditure, given QL 200 implants. Shining pistol QL 200 implant is very easy to get on level 115ish. With base pistol skill 100ish, plus 105 from shining pistol cluster, plus 20 expertise, 120 extreme prejudice, 40 pistol mastery, plus 132 wrangle, you are in business.

In that 80-100 range and 125-150 range you aren't gonna have much IP for full auto, burst, multirange. Unless you know you are gonna be using a flashpoint or some other FA assault rifle, I'd suggest not putting IP into those skills at a low level.

Multirange is a broken ranged skill, and I don't think docs will ever get additional damage returned that is worth the IP invested.

New Player Resources
/delurking

Hi to all newbs and assorted veterans that pass thru this board to help us out. I've been playing AO for about 3 weeks and, well.. I'm hooked. While I love the exploration involved in getting to know this game, I hate floundering so I've spent some time on the web getting some resources together and I'd like to pass them on in one post, in hopes of decreasing anyone's frustration level and help them enjoy the game more.

general info guides... which I found VERY helpful!
http://aoidiots.users.btopenworld.com/walkthrough.htm
http://oldwatchtower.homestead.com/index.html


printable maps... getting lost in Tir and Athens stinks =)
http://www.nepentheim.com/rkplayfields/

Assorted in game maps, user interface... WAY more functional than the default
http://www.kuren.org/ao/gui.php

Clicksaver .... a great way to mission for that item you just gotta have
http://a.chavasse.free.fr/ClickSaver/

Nano Nanny... plan you implants, know what can go where and know if you've got the skills to make your own
http://www.timezulu.com.au/NanoNanny/

because I'm an Adventurer by class:
http://www.advy.org/

tradeskills, which I haven't even come near touching yet..
http://www.anarchyarcanum.com/

items database:
http://64.106.154.149/index.asp

because I like the name:
http://www.ao-basher.com/

So far it's what I've found most useful after wading through webpages. I hope others will add onto this post to share what they have found with others. =)

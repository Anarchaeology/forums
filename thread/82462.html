0% is attack anyone, no matter the side.

5% is a special gas used in land control areas, designed to make it possible to attack same-sided folks, but also to make it possible for certain same-sided folks to be protected from an area's towers by teaming with the tower's owners.

50% was never used. Not sure what it'd be useful for: what's intermediate between monsters only and sided combat? The only I thing I could think of is a neutral-safe area, but omni and clan would complain a lot if that happened.

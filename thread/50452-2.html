Apartment Ideas

Upgrades:

*For a set cost, the ability to add save terminals, grid access points, bank terminals, reclaim terminals. All upgrades would cost an initial hefty fee, and a weekly tax.

*Variation in the standard apartment. More basic models.

Items:

I can only imagine that the 10 item limit was set for...memory reasons? Did someone think allowing more would clog up some server's hd? 10 items is a farce, and current apartments still look very very sparse with 10 items in it. Up it.

Visitors:

Allow us to dupe keys to give to others. Also, if they haven't choosen an apartment yet, they should not be given one when trying to zone into someone else's apartment.

Location:

Add housing complexes all over Rubi Ka. This, integrated with the upgrades idea will allow higher level people with their resources to have a whole new intricate way of transportation from here to there. Plus, how boring is it that we're all in the same backyards?

Anything really to spruce up apartments would be nice. This seems awefully like some module of code that was modified to fit a sci fi theme and then left untouched ever since.

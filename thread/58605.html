New content - Server stability
With the new content in the game of which most is great
the servers have had their workload raised.

Excample: Eastern Fouls Plains

Ace camp ( new mobs , Iann Warr quest )
The Trainee's

Mobs that everyone want to kill are in this zone therefore making it a more populated server.

Two times in the last two days this server went down when my guild and I was killing mobs there.

first time: We were killing mobs in Ace camp. not a big problem since killing even the Primus mobs isnt a long haul. just irritating to get disconnected.

second time: We were after the Diamond Trainee, because we wanted to diamond matrix mesh. We got the guild together had tactical meetings and finally started killing.
All went fine all tho its mind bogling boring. if u get the tactics right its not hard but it takes SOOO LONG. we had it to 60% HP when the server crashed. half the people didnt wanna experience this again so we gave up killing it.

When the Booster arrives ( not sure if it will be possible to make towers in EFP ) this server will be even more roughed up. SO killing the new bosses not only takes long but you might have to restart the whole affair because the server drops



Please look at the server stability when making mobs that take 1hour+ to kill. !

and make items like "diamond matrix mesh" always drop.. its not game altering to have that sword/scissor BUT it takes ages to kill it..

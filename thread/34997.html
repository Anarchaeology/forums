When you plan on using something when using false profession, this is what you check for:


Visual Profession



If just says profession, then you cannot use it. It must say Visual Profession.

As for pets; Agents can not use any bureaucrat pet, or any engineer pet. They can, however, use MP pets. All pets except for the Highest level ones.(all demons, and last 3 heal pets i think).

Becareful what you buy, you might end up wasting money.

It's meant to be this way. when you bring up your list of nano programs that are running (Control + 9) you'll see the false profession nano. If you try to end it by right clicking on it, it will tell you that it's unable to remove the hostile program.

The reason it's this way is you would otherwise be able to buff up HP as an enforcer, cancel the false profession, then buff up HP as a doctor, cancel, buff NT buffs, engineer, etc and that would end up being over powered....

there are a few other nanos you cannot use, and I think some of the engi warp nanos would be in that list, and some others..

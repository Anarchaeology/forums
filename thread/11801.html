I feel like a broken record stating my views on FP, AP, and MP. But once more for the sticky thread.

FP is for buffing.

AP is for buffing nanos with high nano cost such as HoTs, reflect shields, crits. But due to the -80 nano skill penalty, you are limited on buffing the higher level nanos.

MP is for casting. You can break the nano initiative penalty in MP. But due to the -140 nano skill penalty, you are SEVERLY limited on what you can combat cast. You need to consider the trade off between giving yourself/team a nice buff or being able to combat cast a nano so much lower in level to yourself. With such a large nano skill penalty, your teamates would rather have you use FP and give them nice buffs rather than to be able to cast some low level nano.

The duration proposed with 13.8 is totally backwards thinking. Making MP a shorter duration makes no sense because you will never buff with it and you would rather be in that fake profession for a longer period of time so you can combat cast. Having to refresh MP every 20 min is like having to refresh Ruse every 20 min. You would rather have the buffing lines of fake profession shorter duration.

The duration if anything should go FP - 20min, AP - 25min, MP - 30min. Not the other way around. But even then I don't see that as a solution. MP should be the longest of all the fake profession lines. Its hard to say how long AP should be since it isn't terribly useful because FP is better for buffing as long as you can meet the nano pool requirement.

Currently, I don't see any need to change the DURATION of FP and MP. The times on them work fine the way they are now. However, because AP isn't great for buffing and cannot be used for combat casting, its duration is a bit tricky to place. I would suggest it be the same duration or shorter than FP (30min) because it can only be used for buffing, although limited.

The whole discussion on how the nano skill penalty, nano cost, etc... is a separate issue from the duration.

MUST Assume Profession be "in line" with False and Mimic?
False Prof is for Agents to use buffs from other classes at lower levels, and the disadvantages seems balanced.

If Mimic can indeed be used by high level agents with some reasonable effectiveness at "combat casting", then the real question is "what the heck is Assume Profession good for?"

Currently, nothing.

However, everyone assumes that FP -> AP -> MP should be a linear change. What if AP were redesigned entirely? What if AP was a "higher level" version of FP but allowed for faster switching, thus making it a slightly better out-of-combat buff nano? Keep the same stiff nano skill penalty (-80), but make the duration only 10 minutes to allow for some useful multi-class stacking:

Assume Profession:
  • Duration: 10 minutes
  • Set NPCostModifier to +70% On Self
  • Set RangeIncreaserNF to -25% On Self
  • Set InterruptModifier to +50% On Self
  • Modify NanoProwessInitiative by -1500 On Self
  • Modify [All 6 Nano Skills] by -80 On Self

This would make it a useful nano, but would not make it overly powerful. Groups would like that our agent could go AP: MA and do the lower level crit buff if we didnt have a real MA in the team, then 10 minutes later go AP: Enforcer to refresh a "decent" Essence if we lacked a tank. 10 minutes after that we could go AP: NT and cast Humidity Extractor on the doc, etc.

Keeping the high nano init penalty keeps it from being overbalancing in combat, and keeping the -80 skills penalty prevents any unbalancing buff stacking. It would, though, allow for very useful buff stacking...while currently this nano is completely useless. So you would end up with a well-rounded (versatile) team player (or even solo player), but without the combat casting abilities which would be unbalancing. Furthermore, with the -80 penalty to nano skills, it would still ALWAYS be better to have a "real" version of each class in your team rather than an agent using Assume Profession.

Good idea? Or just plain crazy?

High-speed fighter craft probably won't be implemented... and why?

The 40-meter character-view limit.

If you whiz past at 30 meters/sec (in AO, this is reasonable 'fighter' speed), you have 1.33 seconds to find, target, maneuver into position to aim and shoot at an enemy. A lot of actions to be done in so short of time.

Thus, the client code would need rewriting if this was to be made possible, so you could see people at a longer distance.

But we can always hope.

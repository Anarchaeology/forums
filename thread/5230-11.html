Not That Anyone Will Read This...
I would LOVE it for the black market to be implemented, BUT it should only be accessible by the Fixers. Fixers are like the dirty-underhanded punks, and having this ability would make them more useful and wanted (kinda like the evil trader, hehehe). Fixers need something (i.e. specialized SMG's), and this black market could be it. Agents MAYBE, but I'm not too sure, because Agents are like the spies/assasins, pretty dark, but I'm not too sure; maybe they can have limited access? Traders definitely not, becausen of the fact that we could create a whole new profession relation between traders and fixers. Soldiers/Enforcers/Nanotechnicians/MP not, because then Fixers could do some dirty underhanded dealing (hehehe), MA's I'm not sure...

Not only that, but this would also be a step towards getting a penal system in place. If you're caught with these items (terminals, guards, etc.), you will be chased till a certain point, hence the illegalness of these items...
I agree with the idea that you should be able to sell items without the blister packs and such, but I stand by my belief that ONLY fixers can get these items. Think about it, Fixers would be able to fix (get it?) people up with boosted stims, special nanos, and tweaked (c'mon, that would be a big selling point) weapons.

I honestly think that this can be implemented by patch 14.0, this is one of those things that will truly renovate, and revolutionize (may be not revolutionize, but along those lines) AO.

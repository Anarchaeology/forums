Well, as he has Win98, windows\system is correct, windows\system32 would be for WinXp (and Win2K if upgraded from Win9x) and WinNT\system32 for NT or Win2K.

Basically look for whichever one on system or system32 in your windows install directory has the most files (you may need to tell windows to show you the damn things first of course) and put it there.

Muzzleflash (the author of AOMD) is using WinPcap to drive AOMD. If I remember correctly, WinPcap is a packet capturing API for Windows similar to UNIX libpcap. The reason WinPcap exists is because the native Windows API does not provide support for packet capturing. This is where the Ethernet only business comes in because WinPcap only supports packet drivers for Ethernet cards.

I'm no expert on this matter by any means. However, I have seen a similar utility avilable for Diablo II (long in the past now) that achieved a similar goal: sniffing out the packets sent from the Diablo server to the client to gain extra information. I wasn't aware that this used any packet capturing APIs. Therefore, it is possible that AOMD could be altered to circumnavigate WinPcap thus giving support for the modem users.

If I have time, I'll also have a look and see if I can gain any extra information on this.

I just wanted to throw my 2 credits in here and say something which I had said in another thread regarding AOMD:

As you all know AOMD (as it Muzzleflash's lastest version stands) does not work with 13.6, but it must be said that this is not our responsibility. When we do updates to the mission system we will not take the functionality of 3rd party tools into consideration. So, unless Muzzleflash does some tweaks to AOMD (or someone picks up his source code and works on it), or we change the mission system for reasons unrelated to AOMD that results in AOMD working again, AOMD will remain "not working" with 13.6.

We have no plans right now of making it an official addition to AO. I know it's a big help out to may of you, so if anything, I can only suggest some of the programmers out there work on it (as it seems MORB is doing). Props to you.

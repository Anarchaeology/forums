if you had read the previous page
(or any number of pages before that)

the current formula is:

(1 + (ATK / 400)) * (Damage + Crit if any)
= damage total +added damage modifiers [like rings]
-minus armor = damage dealt.

the new formula with funcoms scale, or any scale.

(1 + (ATK / 400)) * (Damage + Crit if any - REDUCTION% HERE)
= damage total +added damage modifiers [like rings]
-minus armor = damage dealt.

so +damage modifiers are the last thing added
after ATK multiplication and before armor subtraction.

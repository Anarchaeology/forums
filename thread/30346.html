Pet Pathing workaround idea
Hmmmm, well pet pathing has been a problem for a while now as I'm certain you're all well aware. I've seen a lot of ideas put forth, and one of the most popular is a '/pet warp' command. Sounds simple enough, right? I mean the code's already there isn't it? Well, here's the view from a proffessional programmer. It might be easy after all, but I doubt it.

Implementing a new command has lot of problems. It adds on to an existing command structure. Now if AO's framework was written well in an object oriented fashion, that's not a real problem. But rarely does a team have time to do that like they'd prefer to. I'm going to make the assumption that's the case and that adding a '/pet warp' would require some serious coding. Doesn't kill the idea, but puts a damper on it.

Then you have the balance issues. Lots of ideas out there for that, too. If it's rooted you can't warp it, for instance. It might have PvP exploits of catching people off-guard by warping in a pet from timbucktwo. Hmmm, well that's not so great. Generally, you want a new command option to be simple from the game balance perspective. I mean, when was the last time you saw a dev team change how an actual command worked for game balance alone?

Now don't get me wrong, I think '/pet warp' is thinking in the right direction. But we need to try to make it easier to implement and tweak for game balance. So I've got an idea. EQ solved it by adding a spell to summon your pet. AO's engineers have a nano to summon players. Let's borrow some ideas then.

Adding new nano formulas seem to be one of the easier things for the devs to do. I know some folks don't want a new nano, but if I have the choice of a nano solution relatively soon or a new command who-knows-when... well, I'll take a nano.

So here's the idea, make a line of nanos for each pet class. Name it things like "Robotic Relocation Beacon" for engis and crats and "Center of the Id" for the MP's manifestations. whatever you think sounds good. But what it does is warp your pet to you if it's within a certain range. The process is similar to Beacon Warp, but only works within the current playfield since pets loose contact with the masters if not in the same zone. For skill requirements, T&S and MatterMet for the robotic versions, and maybe T&S and PsyMod for the MP. Feel free to argue the reqs, just throwing some ideas out. However, notice I said to make it a line, not a single nano.

By making it a line you make it easier to balance. The way the game is played changes as you level, so balancing a single nano for all levels is harder then balancing one for a small level range. As the line progresses, you can warp your pet to you from greater distances. You can even split it into 2 lines. One line is fast-casting and low nano-cost with lower skill requirements, but doesn't work if the pet has hostile nanos like root and snare on it. The other is longer to cast, higher skills needed, and eats a noticable chunk of your nano pool to cast, but will warp all your pets to you regardless of anything but range. I'd imagine casting a warp nano would also reset the pet to /pet follow, but that's certainly up for debate.

This would still require some coding I imagine. The effects aren't exactly like Beacon Warp, but with Beacon Warp already in the game, there's something to base them off of that's been proven. This also means if they need to tweak it's effects, it should be much easier to adjust a nano effect then adding special coding to pathing mechanics.

So my question for the rest of you is this: If the dev team would consider something like this more readily then a /pet warp command, would you be ok with a few more nanos?

Oh, and as a note to FunCom... Make these nanos available in stores or as a regular mission loot, not some BS about only dropped from team mission boss mobs, please. This is meant as a fix/work-around for the poor pathing, not a luxury item.

And thanks to everyone for reading my lengthy post, I hope I made it worth your while.

(and as a disclaimer, I'm sure others have mentioned something similar, but I'm not digging through every last post to find them, sorry)

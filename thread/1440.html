News/Guild Ingame Boards (Feedback please)
An Idea spawned in my head - Not a new Idea.. But much needed

In Game Bulletin Boards for Guilds and a News system for everybody. This could be done in 2 ways.

#1
The first way is the one I like best and would be best seen from the In-game perspective - but prolly also the hardest to implement.
Place "Info" booths or screens in towns and other areas like mission booths. When a player wanted to read the News/guild board he would find an Info booth, walk up to it, click on it - and a window would pop up with the ordinay news that the FC crew would post.. Like Clan news for clanners - Omni news for OT's and maybee some World news, for both sides (Neutrals should be able to read all news). The layout should be like a window were there would be some Headlines - and when u Shift+clicked on it, it would display the full news.
If u then are in a guild - there should be a Login function, when u clicked on it - the server would do a crosscheck to be sure what name/Guild rank the player logging in had.
When that was done - A window like the News window would appear, but the buttom of the window should contain more options.
First a read - Were u could click on a Topic Headline and then on read (or Shift+click on the topic)
Then a Create - That would make u able to make a new Topic - A window were the option to make a simple headline and a text box were you should be able to type would appear. When finished writing u'r message u would just click "Accept" and the message would be created. (The Body text Window should also work with dropping items stats into it - So other players could read the stats on an item (like the Trading chan))
For the Second-in command and the guild leader there would also be a "Delete" - were u can whipe the board clean.

#2
The second way to do this - would have the same features, but would the easy way out in the line of programming. This would be doing the exact same things as the features above - But would instead be simple Chat commands.

/org board - Would Display messages on the guild Bulletin Board, each Headline would just be the first 3-4 words of the message. There would also be attached a ID# for the message. Ex:

ID13 - Just wanted to say tha...
ID12- Looking for a new QL80...
ID11 - Hey im the new memb...

When u then wanted to read a certain message u would type this:
/org boardID 13
And u would get the ID13 message diplayed in the chat window.

/org boardmsg <Text here> - Would create a new message on the board
/org boardDEL would be the option for Guild Leaders and second in command for whiping board clean.

/news - Would display the global news
/newID # would display the news with the current ID (Read guild ID discription above)


Well - that was the idea that spawned while drinking my morning cofee. Comments are welcome

First, I think those info terminals should be available at your apartment, if you chose to buy one.

It should display general news, such as the ones on the website.

Short notes could easily be sent with a set of /org message commands, and they should be acessible anytime.

The leader and high ranked personell should be able to set a MOTD, which would be displayed whenever you logged in.

Longer notes, like reports on events, histories about members and such should be present in terminals or similar.

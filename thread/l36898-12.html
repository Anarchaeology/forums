It may sound overly simplistic, but I think the solution to the whole issue is to:

1. Leet form: make levels of "leetness"
Lev 20ish buff +30 conceal, lev 40ish +60, lev 60ish +100, etc.... Not stackable with agent concealment buffs.

2. Cloaking Devices: Make them Agent only. Agents really are supposed to be the sneaks.

3. Agent concealment buffs: Shadow crown, nice boost, not extreme, but sufficient. Ruse of Taren, not there yet, so I can't say yet, does it stack with SC? if so, it shouldn't. Agents using false profession advent and then leet form, see #1, that balances it out, still up in the air whether or not to have it stack with the "agent" buffs.

Before the nerf, err, patch, I could not sneak through a full red mission. My conceal was about 250, using SC, concealment expertise. I do not have any implants pumping concealment, and haven't pumped my nano skills enough to use the leet form adventurer nano. I use a cloaking device, and could break aggro by going 2-3 rooms away, smacking "esc" to lose target, so as not to counter-attack. and hitting hide. IMHO, that's the way it should work, we should be able to run away, and hide in a corner, and leave the mob saying to himself "WTF, where did he go????"

Bottom line: Agents are supposed to be the main sneaks in this game. Our "skill tree" is set up to encourage us in that direction, don't take away our forte.

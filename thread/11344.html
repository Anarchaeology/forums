Well, I can explain a bit from what I've noticed in 13.81.

When fighting aligned characters (i.e. Clan NPC) you can sometimes get find a Bravery Token on the corpse. When used, it adds 1 point to your token count.

I think this token is a random drop. The chance for this token to drop might be influenced on the POD of the NPC, I'm not sure. I'm also not sure if the token drop only occurs from mission NCPs or not.

Funcom has also changed the Mission Token so they can add more than one point to your token count when used.

For example, at level 19 a Omni character gets 2 points per Mission Token and a level 84 Omni character gets 4 points per Mission Token.

Note that this could change since 13.81 is not the final version of the 13.8 patch.

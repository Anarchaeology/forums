>> Solo XP --> What could be learn from E&B <<
Earth and Beyond developped an xp system where you can gain :

- Combat XP, well, just by killing stuff around.
- Trade XP, by selling with profits items to vendors / players or doing tradeskills.
- Exploration XP, just by discovering check points in zones that you never visited before.

I was very supportive of something along these lines a few months ago, and now know that it's really something fun that let you develop your character XP-wise, while you're having fun, not doing over and over the same repititive thing.

I keep up my suggestions for AO :

- Let Adventurers get some XP the first time they discover some places.
- Let Engineers get significative XP when creating stuff.
- Let Fixers get significative XP when hacking stuff or pick-locking doors and chests.
- Let Crats get XP when saying "Your call is very important to us, please hold on the line" if their team request some urgent mezzing.

Heya, intersteing idea
Its kinda like what you said, but multiple xp bars

Think of it, tie map nav to amount of the world explored, not a skill thing. Give a bonus to run speed for those who have explored more. It would make sence that you get more maps as you explore more. It would only make sence that you have a map for something you have run over many times.

Tradeskill Xp, This would solve one major problem with tradeskill people. As it stands, you have to use IP, which are common, and can be used anywhere to funnel into tradeskills. This means my engie who can build things is terrible in combat. If there was specialized XP, then I could build things to my hearts content, with the goal of building better things. It means that I would not have to make a decision about should i be able to build x or stay alive.

The same could be said for healing xp, or most major buff lines.

While this would make the game more complicated, it would make a tonne of role play sence. In real world, making a weapon does not improve your ability to use that weapon, but to make another one like it. Conversely, killing something does not teach you how to build items.

While this change could not be implimented without tonnes of complaints, its a level of complexity I would deeply enjoy. Perhaps if at some point as well.

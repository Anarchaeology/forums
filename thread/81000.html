Soldier Skill Request: Stabilized TMS Nano Line
The stabilized TMS should work like the TMS, but with the following differences:

- Nanoshutdown only for the time the shield is active.

- Only 50% reflect AC (Reflect*AC 50).

- No damage reflected (MaxReflected*AC = 0).

* = Poison, Melee, Energy, Chemical,Radiation, Cold, Fire, Projectile

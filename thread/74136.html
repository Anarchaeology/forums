Add more options to disable graphics
Please add 3 more options for disabling graphics:[list=1][*]Show others armor[*]Show others weapons[*]Show others height/weight[/list=1]By default, these options would be on and graphics would display as they do now. If the first option is turned off, all other chars would be shown wearing a simple white cloak. If the second option is turned off, all other chars with ranged weapons would be shown holding a solar powered rifle; all other chars with melee weapons would be shown holding a baseball bat. If the third option is turned off, all other chars will be shown with standard height/weight for their breeds; but size modifying items/nanos should still alter scale as normal. These changes should effect both other players and NPCs.

As a lot of the lag problems are caused by the delay loading graphics, this would give players another option to reduce the delays they experience when they go into heavily populated areas.

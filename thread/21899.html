HOWEVER

The reason the fix is so painful is the dark blue nano skills that fixers have. The requirements are so high I'm not sure it is possible to self-equip grid armor and have it be useful against yellow mobs. Fix the nano skill issue and the grid armor issue becomes less important. A fixer may have to choose whether he/she is going to be a grid armor fixer or a root/snare/heal fixer, but, it becomes possible to make that choice once nano skills are addressed.

I wish FC would get to work on the NCU Hacker Interface (is that what it was called?) that would add to fixer nano skills. The goal of the Interface should be to simulate the effect of changing some nano skills to light blue, aqua, or green. So FC needs to do the simple math and determine how many additional skill points a fixer at a given level would have if that skill were a lighter color. Then add those skill points via the Interface. One thing I would like to see is several different models of Interface, each one increasing a different grouping of nano skills (and of course only one could be equiped at a time). A fixer would then choose to equip the model that best suited his/her nano formula concentration or maybe even select the model based upon the mission he/she was going on. But, enough on the Interface, it should be implemented at the same time that the grid armor OE rules take effect.


In fact, with the overequiping change, they could take away the nodrop status from grid armor (though still maintaining the fixer only requirement). Bit of a solution to the rarity of the instruction disk. I can see myself walking up to Intra and asking him to summon up some grid armor so I can blitz a mission. As long as I met the wear requirements I wouldn't need to have the nano formula, just a friendly fixer.

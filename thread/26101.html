Macros
As another MP, I would have to agree with the first guy, I never exit except using the exit button however, if I shut down the computer immediately then the macros seem to get lost. Letting the AO Login screen sit there a minute or two seems to help some (maybe some background saving).

My recommendation (and it is not a fix) is to make the text etc. in a Script and then the macros themselves are much smaller:

/macro Mastery /mastery

Just put the script in your AO script sub-directory and away you go. Then if you want to change the text slightly just edit the script and your macro still works fine.

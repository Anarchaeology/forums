Easy solution to PvP
This has been suggested to feedback@anarchy-online.com some time ago. Feel free to send your own mail with this suggestion too. Only way to get things done seems to be mailbombing feedback about the same issue.

- FIX nanoresist! Does anyone spend IP on this, seemingly useless, skill? It needs to be far stronger than it is.

- Add nanoresist to all types of pets (Engineers, MPs and crats). Make nanoresist either propotional to the level of the pet, or make the pet inherit the resist of the caster.

- When a hostile caster tries to run a debuff (any debuff, roots included), a check is made between the requirements on the program and the nanoresist of the pet. If equal, theres a 25% chance for the pet to resist the program. (This value may be higher, but since we are defining the attack as the requirements of the program, the value should NEVER be above 50%. I feel 25% is a nice place to start)

- And now the important thing. For EVERY 15 seconds, that a hostile program is running on the pet, a new check is made against the same values. If the pet resists, the debuff is shed (or root broken if you like), and the pet can again move. This is crucial, since as it is now, a debuffed pet remains debuffed for the entire duration of the program. In PvP, where fights seldom exceed 2 minutes, the current system is too overpowering on the pet.


Implementing this would help making all pet users stronger in PvP, and especially the engineer that relies alot on the pet for damage. The 15 sec checks on nanoresist could also be implemented for players too. It would shift the balance of power in PvP over to an unknown profession (players would in some ways adapt new strategies).


PS: If you are a trader, please ignore this post. This is a major NERF to your far too good PvP abilities.

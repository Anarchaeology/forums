Is there a cap on % nano cost reduction?
I was wondering if there was a cap on % nano cost reduction. The reason is kind of obvious, I guess: if someone were to acquire enough items, they could possibly get the reduction to 100%, which would make nanopool useless. Here is what I'm thinking:

gaily painted hood = -15% cost
ql 200 faded cluster = -1 %
ql 300 faded cluster = -2%
ql 200 bright cluster = -2%
ql 300 bright cluster = -3%
ql 200 shining cluster = -2%
ql 300 shining cluster = -5%
breastplate of azure reveries = -10%
ql 200 hardcore cpu upgrade = -15%
enhanced ncu chip with recompiling core = -1% (can wear up to five, I suppose, with the hardcore cpu upgrade)
(MP only) mocham's guard = -10%
(MP only) bitis striker = -3%
(MP only nano) mocham's neural-interface web = -24%
(NT only nano) izgimmer's obfuscated recompiler = -28%

This is a list of nano-cost reducing items, etc. that I thought would be relevant to stack. Let me take these from the list:
gaily painted hood + ql 300 faded cluster + ql 300 bright cluster + ql 300 shining cluster + 5 enhanced cpu chips + ql 200 cpu upgrade + breastplate of azure reveries + bitis striker + mocham's guard + mocham's neural-interface web =
-15 - 2 - 3 - 5 - 10 - 15 - 5 - 10 - 3 - 24 = -87% nano cost.

This is from an MP. As you can see, this is not -100%; however, it is staggering. Add the best NT humidity extractor, and the MP could expect to basically never run out of nano energy, without using nano kits or even first aid, EVEN IN AN INFINITELY LONG FIGHT (I could be wrong). At any rate, anyone who has been able to get this, I commend you.

Does anyone know if there is a cap? Does anyone know of any other items that might add to nano cost reduction? This is something that has been on my mind for a long time, but I never got around to asking. Thanks for any replies!

The max NCU for Enhanced NCU Chip with Recompiling Core is +24. QL90 is the highest. Anyone able to equip the rest of the items you mentioned would be horribly gimped if they had 5 QL90 NCU chips in just for 5% nano cost reduction, so I wouldn't count those.

Gaily Painted Hood isn't easy to get. Note I don't have one and I go to Camelot quite often.

To my knowledge, 1 person on Atlantean has the Breastplate of Azure Reveries.

I don't think the cost reducing nanoclusters are actually dropping, and if they are, they're about as hard to come by as the above two items.

Keep in mind a fight will not be infinitely long for an NT because they have no healing. It's also easy for most professions to outdamage an MP's healing from Belamorte. If a Doctor were able to achieve that high of a cost reduction, then yea, I can see that being a problem.

But, for those who actually do get all of these very difficult to find items, get the clusters put into implants and equipped, and get nanocost reducing buffs from an MP or NT, they probably deserve the outrageously high cost reduction.

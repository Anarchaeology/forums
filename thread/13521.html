When the game was released, the servers got overcrowded and overloaded. RK2 was FC's response, to split server load and game worlds.

Server load has been mostly taken care of. The game is mostly stable, the servers don't go down (in the first month, the server was down as much as it was up - I think everyone remembers checkign the server status pages so much that those pages overloaded their servers. The red and green mixed equally, with long blocks of downtime. It was AMAZING when we went through the first 24 hour up period).

As a response, FC is working on making migration possible. I am sure they will leave RK2 as an overcrowding measure, though.

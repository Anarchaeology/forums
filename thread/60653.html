Gammel og grå :)
If you have several pets, you can easily make macros like this:

/macro "Fury Externialization" rename "Rookie Pathfinder"

And you only need to make new macros when you switch to a new pet (e.g. one that gets a different initial name). Important thing is that you use quotes around the names if they have two or more words in them - that goes for both the old name and the new name.

I've been doing this since I was level 12, and I've not had to make that many macros, so it really is no problem

Soldiers Total Mirror Shield, Suggestion
Hi.

Do Funcom see the Total Mirror Shield for soldiers as a balanced and useful tool for Soldiers? If Funcom is looking to change the Total Mirror Shield to suit the Soldiers more, then here is a suggestion.

As the Total Mirror Shield work at the moment, it is not used regulary as the Soldiers best friend, which its described to be. The shield is used mainly to aid the soldier to escape difficult situations with the sole purpose of protecting the soldier while he/she escapes.

Here is a few suggestions which is taken from the soldier forum.


*Suggestions for TMS*

- Remove Nano skills inoperative.
Lock instead Matter Creations for 120 sec (just a suggested time), then we can still use other nanos while the Total Mirror Shield is down. This would be well needed change for Soldiers and it would already be enough to make Soldiers use this tool more frequently.

- Up the damage thats reflected to the attacker
Double it. Attacking a Total Mirror Shielded Soldier should hurt. This is the Soldiers trademark and one of the reason why Soldiers are different to other professions.

- Use different strains for Reflect and Mirror shields
Put all TMS in a completely new strain and add code to TMS:
Remove Self nano_strain_2
So you could use the MK5 for example while having the RRFe running without cancelling it manually. (Maybe add Nullity Sphere to the same strain).


Thats it, all three changes together would make the Soldiers use the Total Mirror Shield alot more often.

Most importantly is the wish to let the Total Mirror Shield override all other shields to get hold, or to let it get hold along with other shields.

Does Funcom have any concern about the Soldier profession or is these changes not needed?

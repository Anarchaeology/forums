Explorer UI Inventory Client
How about a non game client that looks like the windows explorer where your account is like MyComputer.

Each world RK-1, RK-1 would be the C: Drive, D: Drive.

Each Drive has 8 Bank folders (1 bank per char) and 8 Char folders (1 per char).

Each each bank/char folder has additional folders (bags) or items.

You can open multiple folders and drag and drop items into various folders, to sort them or give them to other chars.

Doing a properties on an item, shows u the requirements and stats.

Doing a proerties on a char, shows u the char's stats.

Opening a folder (bag) shows all items in it with the View AS, byICon, ByName (Sortable by Type, Name, QL)

Include a file file, search for items by name (wildcard) or type (Armor, Weapons, Nano, etc...). Double click on the item in the list opens the folder it is in. THe search can be limited to 1 char/bank or all chars on 1 world.

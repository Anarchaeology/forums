Here's what I think
I don't think that training monsters should be considered harassment (fyi, I've never done this. So don't accuse me of writing a self-serving post!). It's just part of the game mechanics. This aspect of the game has always been around, and it's an excellent pvp tool, in my opinion. If the developers feel that training is something that is too much of a problem, I don't think the solution should be to ban people for it, because this relies on more of a subjective, and not objective, view. Instead, the game should be altered to where training is not feasible. I have the same opinion regarding exp macroing: to combat it, don't ban players who "appear" to be macroing, simply make it to where the game is not feasible for macroers.

I don't think Aberic should be banned. If the Code of Conduct says that training is bad, then he should be punished if he did it. I actually tried looking for the COC; does anyone know where it is? At any rate, I don't agree with that part of the COC, assuming it's in there.

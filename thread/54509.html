renew post: PVPworth & tokens over 1k
2 similar ideas.

2 new shop machines.

1. PVP

PVP in diablo drop ears. since FC obviously picked up the idea for dynacamps from a diablo-esque environment, why not this as well.

but take it 1 step further.

make the ears worth something. PVP. kill someone, and something like a Bravery token drops.
it should drop every once in a while.
it can be traded in this PVP shop for creds, for items of purely social use (like rank/regiment titles, etc... perhaps an item that takes up a neck slot.
if u wear it, it will show a title in your 't' button view, or even on your name. something like adding a tag to your visual name. "Freshman Rayfield the Butcher" or whatever)

2. token shop.

a shop to pawn off tokens. for those who either have more than 1k tokens or don't care for the token board. should be easier to code with this idea (since currently 'using' a token will make it automatically go into the token board).
a machine/npc that u can redeem tokens for creds or for a coupon.
the coupon can be saved up(nodrop but not unique) in a coupon book(just like the token board) and can be traded in for items in the token shop.
these items can be of use compared to the PVP ones(farming tokens takes time, farming PVP count doesn't). the items can be thought up whenever by whoever, but this idea should give the 1k+ tokens characters some hope to fight on, rather than(as some say) with 5k+ tokens and bored to death.

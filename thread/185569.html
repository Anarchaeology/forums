Cluster Armour
I've been browsing the forums recently and noticed a dilemma developing around the new profession perspecific armour now availible - that dilemma being the profession/breed issue.

Well that got me thinking about a much more customisable armour type which could be talered to the individual, thus not being forced into a template.

Well this armour could work in a similar way to implants - you are able to place clusters into the diffierent pieces, and like implants the clusters could change the requirments of the armour. This would allow players to customise a suitable set of armour toward their character and not someone elses vision.

I'm not saying existing clusters for implants should be used but you get the idea. Oh and it should be tradeskill only of course, can't see it working any other way :0)

Game balance as always is an issue - but it would be with any new content i suppose.

Well its just an idea P

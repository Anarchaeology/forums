Better memory management
The poor memory management in AO is ridiculous. AO just malloc()'s memory endlessly until switching to much slower virtual memory, and once it runs out of that, Windows has to make the enlarge the swap file, which seems to always result in a crash. This is so bad on my machine that when I was doing a team mission today, as soon as i looted the boss, my pc crashed, giving me no loot, but the boss corpse disappeared anyway, making the team think i stole all the loot and logged, evoking VERY angry messages from my former team once i got back on. AO needs to free() memory as soon as it's done with it.

Edit: malloc() and free() are C++ functions that allocate and deallocate memory. I should've mentioned this before.

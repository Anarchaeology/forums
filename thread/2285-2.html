Here is an idea. Create a new vechical that allows you to map out an area. This would eliminate people from speeding around a zone in their Yalm snapping pictures. The vechical could either require a ton of Adventuring skill to use, or just require the Adventuring profession (though, then Agents would still be able to use it).

You wouldn't even need to make a new vechical. Something like the Probe (a modifed Mid?) or Waste Collector would work for this type of thing. Looking into it deeper, since Funcom loves to make professions dependant, they could release a new trade skill item requiring Mechanical Engineering that can be used on the Mid, altering it into an adventuring-map making vechical. It would keep the same QL and requirements as the Mid, maybe with a new adventuring requirement, and a lot more concealment. Since getting knocked around by a red MOB in the middle of nowhere would make this kind of pointless.

Of course, in order to mod the Mid, it would have to lose it's NODROP, since a Trader or Engineer would need to do it (unless Meastro and Expertise would be enough?). Maybe having a whole new vechical would be a better idea.

Hmm, thinking about this some more, it would probably be a much better idea to make the vehicle require the Adventuring profession. Then Adventurers could use this item for map-making, and Agents could use it for recon.

Mids are really not that valuable in the game, so killing their NODROP wouldn't be a huge game altering change. You wouldn't even need to make a new trade skill item to mod them. Just have the GPS Link Computer go together with The MID. Maybe some other items to make it not quite so easy to mod.

The only reason I am stuck on the modifying process is that having a new NODROP vehicle just for Adventures would make finding this vehicle pointless for everyone else. I already find enough junk loot in missions. It could work if they are reward items from team missions, or something you get from a static dungeon. There are too many nano professions in the Steps of Madness, so Adventurers could really use their own static dungeon to horde. :]

As far as getting the map data into a physical form, it could be much like the process for making a Kamikaze bot. The Adventurer could equip their vehicle to start the recording process. They could then right click on it in order to see the percentage of the current playing field they have recorded (like right clicking a token board). Once it is at 100%, the Adventurer could use an Expendable Hologram Camera on the vehicle to create Hologram Data, and then use the Calculator to create the Nano Building Data, which can be uploaded into an Empty Instruction Disc. This process could be repeated as many times as they want, as long as they are still at 100%.

Once that is done, the Map Instruction Disc (Broken Shores) can be sold or given to trade skill professions to be used in the same process as creating a Nano Crystal. Except that the end result is an uploadable Map, instead of a Nano Crystal. Doing this would give Adventures a huge value boost in the game.

The only downside is that you wouldn't be able to make a map of indoor playing fields unless the vehicle could be equipped indoors. As long as it could only be used in static indoor playfields (bars, static dungeons, etc.), and not missions, I don't think anyone would have a problem with this. It would be kind of neat to have Map - Steps of Madness, Map - Happy Rebel. :]

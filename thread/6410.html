All implants carry "secondary" requirements that usually involve one of your main Abilities ... like STR, AGI, PSY, INT, etc.

You have to have enough IPs in the secondary to be able to insert the implant.

Just because you have enough Treatment skill does not allow you to install the implant automatically.

If an implant does not install, you should see a message in your chat window that tells you what the missing secondary skill is and how many IPs you need in that secondary skill.

Hope this helps ...

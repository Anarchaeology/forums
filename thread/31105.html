Updated release of my AO World Map v4.1
Just dropping a post to let people know i've updated my world map (Dovve's Map 4.1) with some handy new features thanks to lots of feedback I got from the AO community. It now includes:

- Whompa Routes from 14.2
- Custom Player and Mission Markers
- Major Cities
- Grid Points (With affiliation)
- Outposts (With affiliation)
- Supression Percentages
- Accurate zone boundries
- Points of Interest
- Dungeons

You can view and download the map here:
http://peacefairchild.tripod.com/map/

Let me know what you think. I'll keep updating this as I get feedback from everyone

---------------------------
UPTADTE!! This version is not compatible with AO Patch 14.4. I am in the process of updating the map now. I'm estimating I'll be done this weekend possibly July 7th. Keep an eye out.

Dovve
Leetas
I have taken good look at the new maps in 14.4. There is a much better level of detail and accuracy in it so this is defiantely good news for everyone.

It definately could have a lot of things added to it as its just a plain map. It has no outposts, points of interst, whompa routes or locations, etc. and so on. Its completely stripped down. which does leave a lot of room for 3rd party people to have fun with it.

On the downside for me all of the work I have done on my old map would have to be done again for 14.4 as all of the scale has changed. So it's back to square one for me or anyone else that wants to take this task on.

In the long run though I think the change was a very needed and very welcome one.

I did try to figure out how the new bin file format they store the maps in works (in 14.4) and its way over my head i'm afraid. Hopefully someone more informed than myself will figure out the process for replacing the new maps. It doesn't seem as easy as the textures in the skin file...darn.

So Dovve's map may be AWOL for a while come 14.4. Just a heads up.

The new map is a single file that is in fact a concatenation of lots of smaller files, the text file contains the offsets. The individual files are just 128x128x24bit PNG files, one set for zoomed out, another for zoomed in.

So not as easy to work with as the original, but it shouldn't be too hard. We'll need a tool to extract the bits based on the text file, and another to put them back and write a new text file.

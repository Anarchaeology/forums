Vehicle Air
With new vehicles on their way into the game that start at QL 150 and higher that have reqs that start in the 900s it would be nice if we could equip these vehicles should we get our hands on them. Right now Fixer, Adv, and Trader are the only professions that can equip these vehicles and it takes all 3 clusters for them to do it.

What I suggest is adding some new modifiers to the 1k token board. +140 or +210 Vehicle Air, Ground, and Water. To use the new vehicles most everyone would still have to have implants as well as maxing out this skill.

Actually looking in the NDA breaking database there is only one vehicle with a skill so high that only those three professions can use it.... The Stiletto. 919 Vehicle Air req. There are no buffs for this skill. There is only one item dropping in game that raises this skill, and it doesn't bring the other professions close to using it. The other vehicles all professions should be able to use just by maxing the skill.

Bah... anyway, please give us something that allow everyone to use that vehicle when they get to the highest level.

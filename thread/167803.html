Bureaucrat Nano List! - updated -
Hi fellow bureaucrats!

Beeing relatively new to the Crat profession I spent time in the start trying to find a list of Crat nanos sorted in a somewhat readable way, with no luck. So I've spent some time gathering some info on our rather large quantity of nanos, resulting in a list sorted by nano-lines. Starting as a excel sheet it has now evolved into a basic webpage. Nothing advanced, but it contains some extra information so you wont have to use aodb or auno.org to look up nano effects all the time. Links to these pages have been made for conviniency tho. It also contains which nanos are available in shops atm. The list should be up to date as of patch 15.0.1. Also incorporated Elizabetha's and Ityn's info on pet health and nanopoints + info on pet levels. Hope this is usefull for someone and feel free to make corrections if you find flaws

Thanks go to Meister (Stratics guide), Elizabetha and Ityn for the info they have published, and the people behind aodb and auno.org

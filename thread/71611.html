Revamp ICC HQ.
With the new, heavier presence of the ICC on Rubi-Ka, the facilities of the ICC HQ are overcrowded and inadequate.

The following is my proposal for a revamp:
  • Add an neutral superior shop (with nanos).
  • Add an actual ICC HQ zone with NPCs. Use one of the doors off of the main area. (Perfect for adding quests!)
  • Add a bank.
  • Add a save terminal.
  • Add mission terminals (perhaps inside the ICC HQ zone.)
  • Add a grid terminal (put it on the ground floor of the Grid)


Make it a true neutral gathering place on Rubi-Ka. A good place for tradeskillers of all affiliations. Perhaps add a Services channel, viewable across the main omni, clan and neutral cities, that can only be broadcast into from ICC.

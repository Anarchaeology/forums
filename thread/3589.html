ADDED 13.4 : Nano attacks in PvP will trigger auto-attack from the target
Using offensive nano programs on an enemy to initiate PvP will now trigger the target's auto-attack if (s)he has the def-agg slider set high. This is the same functionality as when attacking with a weapon.

Currently the auto-attack will trigger at the start of executing the nano program, not at the point where it strikes. We are aware that Nano Technicians in particular would like it to be triggered at damage dealing, and will look into this.

Cz

RSIP, an idea for a permanent respec
Greetings,

I don't know if anyone has thought of this before but I've got an idea.

While we are all happy to have the ability to respec points, the limited number can be frustrating for those of us that "experiment." (or for those new players that don't know better). A more permanent way to get points back would be nice.

So, simple idea: Negetive experience. There are several ways to implement this but the basic idea is that you undergo missions which give you RSIP (ReSpec IP) rather then XP. You won't grow as a character but you will be able to use these RSIP just like IP; except instead of increasing a skill, you would decrease a skill with the RSIP you gained (which returns IP to the regular IP pool).

This solution should work for all types of characters. You will have to work to be able to change skills but at least you'll be able to do it. That's pretty much it... flame away pointing out all the little problems

The problem with the Respec now is that I can run out of them. If I respec a line and then spend the points else where, what happens if the new point allocation doesn't work? I'd have to use another RS point. Or what if I need points back from more then a few spec lines? Bottom line is I only have so many chances to get points back.

Now if there are static missions that give RS points as rewards, that'd work.

A better solution, imho, is a system that would allow you to get IP back from a line without having to wipe the whole thing. More over, the system I described would allow you to take some points from one spec line and some from a different line without having to wipe the whole line.

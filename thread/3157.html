Both exist already...

And err.. 3. Merkaba715 - choosing commonly used channels to chat in with the mouse at all is very painful - I recommend not doing it that way Instead on the chat line type "/ch t" and enter - and it will select team channel (unless you have another channel that starts with "t" that is. Shopping is a bit harder - there's too many ambigious channel names up until the level number for it to be easy to change on the chat line - so just use the mouse for this - besides, you never need to rush so much if you're just changing to shopping.

I do agree the interface could be better though - but they did say they're working on that only a few days ago, and are accepting suggestions - check the news page.

New Rank systems needed for orgs
I think we need some more options when chooseing an org structure (not houses, but rank structures). The ones we have now are nice, but dont cover all the bases. What I would like to see is a few more added, specifically Crime Syndicate.

I dont know what all the ranks should be but someting oriented towards a criminal organisation (Boss/Crime Lord/underboss/etc). There are so many orgs that dont fit into the molds provided by the few rank structures we have, why not add more?

What about also Military (General/Colonel/Major/Lt/Sgt/Pvt)?

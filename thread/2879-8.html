How long do you wait, Brap? It can take 3-4 minutes till everything is loaded.

Be sure to start it in windowed mode the first time in case you use a desktop firewall. They will ask for a permission and you will not see it in fullscreen. Also, on a Cable connection, it can take some time until the client connects to the server.

Also, check the task manager - AO might not be responding fro a minute or two during launch but should be ok later. Be sure though to start the task manager before you start the game - hitting CTRL-ALT-DEL can crash AO.

Do you get timeouts? After some 5 minutes the client should give you an error message if AO didn't load.

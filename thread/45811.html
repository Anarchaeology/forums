I have to agree the scripting language kinda sucks in ao
needs alot more things added to it like
  • randomization like you mentioned
  • if X then Y else Z ability
  • %a and %A (what i'm currently attacking/what attacked me last)
  • %c and %C (what i am using an attack nano on last/currently and what did so to me last with AOE filled in for aoe's)
  • %h and %H (who/what i'm healing last/now and what healed me now/last)
  • %hp %np to dispay current hp/np in %
  • the ability to link up nano's to a script by name (i.e. /cast "advanced survival technique">client checks if you have it and executes it normally if you can)
  • the ability to define nano's as a variable and set that via command line in game (i.e. /setvariable bestheal "ref to best current heal", /setvariable unbuffed heal "ref to best unbuffed heal", /setvariable debuffdheal "ref to best debuffed heal", etc)
  • ability to have scripting check if you can currently cast the defined nano otherwise to fallback on the lower level version (i.e. in the above example of heals)
  • the ability to set events/variables on >%HP#<%HP# <%NP# >%NP# for a % of your hp or np (i.e. if <%HP5 then /cast "fastgrid")
  • the ability to setup events that trigger on events rather than alias's that trigger when a player calls them


there's alot more things that would need to be added too like how far away someone is and other fun things

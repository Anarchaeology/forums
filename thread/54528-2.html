Go PvP...
Well, I would love a server that was all 25% (or mixed 25%/0%) if the following were done:

1) Fix the current bugs.
-Nuff Said

2) Overhaul the weapons
-Go over the list and define about where you want weapons of each type to be. -Make at least 10-12 base weapons of each skilltype based on that baseline (different damage types, trade offs for dmg vs crit vs speed, etc).
-Delete all the current worthless weapons from the game.
-Make all standard weapons buildable
-Let players modify all base weapons (add effects, change damage types, etc) via tradeskills.

3) Overhaul Nanos:
-Define what you want each classes pool of nanos to be (mostly defined already, but flesh it out).
-Go over the nano list and ask yourself if they all have good use/make sense
-Fix any worthless nanos
-For PvP breaking nanos (root/mez/charm/etc), add alternate PvP effects (and/or ways to counter them).

4) Fix Atrox
-Make them actually get more health/stam/etc for their lack of mental abilities

5) Fix Nanomages
-Make them actually get more nano/etc for lack of physical abilities

6) Re-implement weight:
-There was originally a reason that not everyone carried the largest guns/wore the heaviest armor...inability to move due to burden.

7) Fix Skills:
-Every profession should have at least 3 good weapon choices
-Merge/remove/fix worthless skills
-Add vehicles with hardpoints, special hardware slots, etc for all types so that people can tweak them and actually use them (tanks/mechs/carriers/etc)

8) Fix Overequipping:
-Remove level Reqs
-Remove breed/profession reqs from everything except nanos
-Tweak the nanos that make gross overequipping a problem (and if this requires a gross nerf, so be it, just make sure to add good, useful nanos to make up for the loss
-Tweak ncu/implants so that you can not do the old add ncu, buff, add implants, upgrade ncu, wash repeat stacking. (maybe remove comp lit implants)
-We dont need all these extra eq like caps, we just need the core problems that let overequipping get out of hand resolved.

9) Fix inits/resists
-Yes, this would require going back through mobs and making sure that they were not insane/wimped.

10) Bring back melee/ranged combos.
-Common, some of us like the idea of using an eblade and pistol together. Just give weapons dual multi-reqs.

--Edit--Adding one more thing--
10.5) Fix specials(fling, burst, etc)
-Treat them as normal attacks instead of making them hit almost always.
-Maybe make burst/full auto/etc have a better chance to hit at reduced effect (i.e. if you would have hit normally, full effect, if you would have missed, but were reasonably close to a hit, hit with less bullets than normal (scaling damage down accordingly))

11) Open PvP server, let fun begin.


Anywise, I would love to see 1-10 done regaurdless of 11...

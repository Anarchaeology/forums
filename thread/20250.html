Totally agree with you on this.

However, there are alot of other rooms that are just as problematic. I wonder if theres a better solution?

Not real up on mob pathing, but I understand that in any given room (or equivalent area) there are various specific points set up. So if you looked down at the room from above, you would see a grid of possible points, each point representing a possible location that a pet (or NPC) could reside. The grid of points is not neccesarily evenly spaced.

Now, in a perfect world, with infinite processor power, you could have a very fine mesh of points, and accurately model the objects in the room, thereby allowing you to compute the best path from a starting position to your target location. Unfortunately, the servers this game runs on has to handle how many thousands, if not millions, of calculations to figure out where all these Pet/NPC's are and how to get them from spot A to spot B, and they have to continually relcalc that. Verrrryyy proccesor intensive.

So what's the better solution? Not sure, but how about simply making all objects (desks, chairs, conference table) invisible to Pets/NPC's? Turn of clipping for them if you will, but just for those problem objects. The problem with this is that there probably aren't any predefined "points" set up on the inside boundaries of the objects and these would have to be put in.

Of course, I could totally be talking out of my rear. I don't profess to know that this is even remotely accurate. Interesting subject tho.

Easiest solution?

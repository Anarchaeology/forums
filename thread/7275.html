Info Windows
I have read in the "in progress" section that there will be 2 separate windows for the description of shop item and for the items carried by the character. i think that it should always be possible to have 2 info windows, that the windows should be sizeable (or at least bigger) and that the set window size should be stored (that is remain the same every time you call up a window).

there are so many occasions where you need to compare different items and it's just to time consuming in the current state. especially when you compare armor pieces the window is too small to show all AC values and it's hard to keep them all in mind. so you have to open the info window, scroll down, note that stuff on a piece of paper, open the info window of the other armor...blablabla (not to mention that the sort order of thze different AC types isn't the same).

this would be a great change.

thx =)

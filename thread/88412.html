Changes on the bulletin board
Some small changes on the bulletin board:

The Community Corner forum is now open to posts from Funcom employees only. Most threads in the forum are closed, so I think it's easier to do it this way. I'll start discussions in other forums rather then in this one, when needed.

A new suspension status has been added; LinkDead. Being in this group means the moderators have a message for you, but we can't reach you, so please contact us.

This status will be used if we have a warning for somebody who have given us a non-working e-mail address, and have private messaging turned off.

The title for banned users has been changed to reflect that they're banned from the bulletin board. Some confusion rose about whether this reflected that the person was banned from the game, which it doesn't.

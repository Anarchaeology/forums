Armor, Weapons higher as ql200
Just a idea. Why don't you raise the quality of armor and weapons, etc. raise the max ql off all items. Why should you do this? Ok let me explain why.

The idea is that only the main classes for the armor, weapons etc. should use this high ql items - all other classes cannot use them, they can only use a lower ql.
Think about it: a agent can equip a ql200 X3 at lvl100-120 i think or? And after that? Other profs will be able to equip a X3 at ql200 too on later lvls. Make a ql300 X3 for example and only a lvl200 agent with ql200 imps and maxed rifle, aimed shoot skill can use them. All other classes cannot use them, cause they are not agents and not a "rifle-user" class.

Same thing with sols. We can use our ql200 Nova at hmm lvl100-120. All other classes can use them too on later lvls. Make a ql300 Nova and only a lvl200 sol with maxed skills and ql200 imps will be able to use them.

Enfs: Same thing with support beams, etc.

Only fighting classes should be able to use their new high ql weapons.

Breeds: Say a atrox is bad at nano skills but he is very strong ok? So only a atrox breed will be able to use a ql300 armor set. Other breeds hmm say 270ish for solitus, etc. nano breed only 200.
So if you want to play a atrox nt - you can wear 300ish armor but have less nanoskills etc. If you want to be a strong caster and choose a nanobreed you cannot wear 300ish armor.

I think this is a great idea or what do you think?

Cause every class and breed have now its strengths and weaks. And we don't need a atrox only amor, cause with this changes we have many atrox only armor, many agent only weapons, many sols only weapons, many enf only weapons, many, many, many great new things.

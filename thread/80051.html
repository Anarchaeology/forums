What would be neat is to be able to adjust the font in-game.
Currently the only way to adjust the font is to adjust it, log in and cross your fingers. If you don't like it, you have to log out and wait for the application to terminate, change the font and then log back in.

Yuck.

Being able to read the chat during battles is a task unto itself for the most part. Having a font that you can actually read despite what graphics lie behind the chat is a very important point because Funcom doesn't give us an option to adjust the opacity of the transparency of the chat background. Very frustrating.

Funcom, please, put in a slider to adjust chat background opacity. Even if we have to restart the client to make it work, I'm all for it. We need to be able to read our text!

Okay, so that was a suggestion and an appeal.

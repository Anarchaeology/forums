Fion,

When you install, you might have the same problem with the NW cd-rom as I did. It would not auto-run and install. If I manually ran the cd-rom, then all it would give me was a "play" button, while the "install" button was greyed out. So, I went into the game thinking I had installed NW and couldn't do voices. Well, I got the same message as you and found out that I hadn't installed it.

So, here's what to do if it's the same problem:

1. Make sure cd-rom is in the drive.
2. Open Windows Explorer.
3. Open the AO files in your cd-rom.
4. Double click on the blue "SETUP.EXE" icon.

That should install NW for you, if we are discussing the same problem with the NW disc.

I hope that helps!

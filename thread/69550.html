We need a CRM for AO!
Dear FC, if you have been reading up on norwegian (and probably other) computer magazines this last year you will have noticed that there are a lot of CRM (Custom Relationship Manager) systems out there. You don't have to use an expencive system with all the special bells'n'whistles. All your customers are asking is a bug-tracking system where we get a ticket, a case id, if you like and where we see which bugs are already reported and how the progress on them are going.

I bet the ARK are using them, but we want to have a peak into that system too!

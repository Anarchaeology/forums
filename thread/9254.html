Well, if your image program doesn't support PNG, which all modern image programs should but perhaps some old ones don't, you can view a PNG image in the Internet Explorer 5.0 or higher then right click on the image and select "Save picture as" then you have the option of saving it as a BMP or a PNG. Save it as a BMP, then pretty much any image program can load the BMP and save it in a JPG or GIF format.

I wouldn't recommend this method if you are converting more than a few files. There's bound to be some sort of PNG to JPG converter on one of those freeware/shareware web sites like www.download.com or www.shareware.com that would be a lot faster and easier to use or you could upgrade your photo editor.

Two humble suggestions.
Funcom, I can still read the health bar text sometimes. That text is really interferring with my gameplay. Who the heck wants to see the name of the mobs, right? Just get rid of the text altogether.

Secondly, I can still read the text in the chat box on some occasions. My suggestion is to just get rid of any sort of background to the chat altogether. None of that text is needed anyways.

Sarcasm aside, please, Funcom this stuff has been asked for since beta.

Gee whiz. Just pop a black rectangle behind the health bar text or something so that we can actually read it. Not like that black rectangle would block vital graphical information or anything. Have it automatically adjust to the size of the text.

And could we please have a slider in the Options GUI that allow us to change the opacity of the chat background in 10% increments?

You're adding new content, why not add this new content too?

Please?

5.2. Secondary Skills
Map Navigation - Raise to 80 and use temporary implants to install maps and upgrades as high as you can.
Would recommend not raising map navigation at all. Base skills alone will raise map navigation to well above 80. As a person levels they can use various quality temporary map navigation implants (i.e. 10, 20, 30, 50, 70, 90, 110 and so on) to install higher maps. This should help save IP for the primary areas, or other secondary areas.

A character should be able to install all maps up to ~350 map navigation using expertise (sense, intel and psychic) and ql 200 implants by the time the character is breed capped in abilities. Of course, there are other items which add to map navigation as well, so players could potentially install even higher maps without having spent IP in map navigation.

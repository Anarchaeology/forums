Weapon Smithing - My ideal world
well my main char is a MP but i have loads of alts for different tradeskills (a doc for those Monsters Parts, an Engi for rings and other stuff and others for other skills), the one thing i like about AO is the trade skills and taking things to make other things.

well i know weapon smithing the way it is isnt riveting and it certanly isnt vaible as a method of trade or fighting - and the only good use is to say "this is my weapon , it is like many others but this is mine"

well heres what id like to see (ill od it in stages as i think the idea i have is complex)

stage 1 = the first stage is making a note book for the weapon u will create - to do this u would combine a weapon construction kit (pick the correct type for the weapon u want) with a Memory read console (new item would be needed) this would create a Memory read Console set up for the weapon type u want to make - from here on it becomes the kit for this type of weapon and can be reused

Stage 2 = Gather parts together - ie if u r making a simple hammer u would get a hammer head and a handle - u would combine the 2 with the read device - this would create a Hammer prototype mk1 and a memory storage disc with the order of items added to create it (blueprints) - from here on this weapon does so much damage at sucha speed - if u got lucky the prototype would be good first time and wouldnt need modifications BUT in all likly hood a basic hammer wouldnt be much different (probably worse) than a current hammer u could buy or find and so u add more items into the mix ie u first add the disc to the memory reader (telling the kit u making a new version of the same weapon) then add the parts, now including a electrical discharge unit - this would create a Prototype hammer mk2 - and would give a new disc - whats the difference between mk1 and 2?? well 1 is a simple hammer while mk2 discharges electricity a hit so would change in damage type AND may add more damage and may be faster/slower.

Stage 3 - after making and modifying several prototypes to get the best hammer u could want u combine the relevent Disc with a blank manual (book) and this will make the weapon namable eg u call the prototype 2 hammer - Moodymans lightning hammer

the prototype discs would be no drop as would the prototypes BUT after the manual is made it can be copied like a key and spread around

Stage 4 - when making a weapon from a premade manual u dont buy the kits u combine the peices with the manual (ie u r refering to the manual to find out how they go together)

ok heres the coding bit - the maker of the weapon has no control over what stats the weapon comes out with - thats all server side - amd so it should be totally random as to what the stats look like. Also no 2 hammers made in the same order by different players should be the same UNLESS they were made from the same manual to make it even more differnet.

this would make weapon smithing a viable skill as its making weapons that arnt buyable or findable and would make showing off ya own items a social option

just my 2 penies (ok im british we dont have cents ) on this subject

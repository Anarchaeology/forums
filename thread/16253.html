Artillery fire
I'm was just sitting here in borin old class and came up with this wild idea. How bout you give players the ability to call for artillery fire.

It would be a multi profession system and only used for pvp (like DAOCs catapults and battering ram system), meaning your going to have to have more then one character of a diffrent profession to implement the strike and that its not going to be able to be used for mob killing.

You would need an engineer to build the artillery cannons, an adv would plot coords for best geographical targets, the soldier that would be responsible for moving and operating the aritllery agent that would sneak into (once FC fixes concealment this could be implemented)enemy territory and paint the target with a laser of some sort, you would then have crat give the authorization for the artillery fire. You could also have the fixer be able to summon parts for the cannon and maybe for diffrent types of shells (poison gas Baby!!! )

The level of the artillery would determine the extent of the damage it does and the level of the artillery would also determine how long it takes to recharge, it would also determine its range (so that if you have say a lvl 50 cannon it would do smaller amounts of damage and wouldn't have as long a range but would recharge faster then say a lvl 200 cannon that would do a lot more damage but would recharge ten times slower). There would also be a lvl at which this can start being used (say lvl 50)

Well thats my out in space idea, would be kinda hard to implement but would be pretty cool, maybe they would be able to add this when they allow us to be able to take OP. But before this I would like to see the current problems fixed wouldn't want them to put something new in that would cause more problems.

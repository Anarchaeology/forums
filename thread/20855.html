Am I here yet?
Sold individually, those items give credits. Combined together, you can sell the for more credits than their individual price.

Gold/Platimum/Jewelry items can be made into ingots using a precious metal reclaimer tool.

The ingot can be turned into a liquid using a personal furnace tool.

The liquid ore can be turned into wire using a wire extractor tool. Note: wire has more than one use

Wire can be wrapped around a ring template to make a silver/gold/platinum filigree ring.

Now for gems. Gems can be cut using a Jensen Gem Cutter, enhancing their value. Note: gems can have more than one use

The cut gem when combined with the previously made ring produces a silver/gold/platinum filigree ring set witha perfectly cut <insert gem type> gem. This sells rather well as noted.

One more note: the final QL of the ring depends on the QL of the ore used. So try to use the lowest QL gems possible on the ring. The final ring will retain whatever QL the ore was (so you can waste high QL gems on lower QL rings).

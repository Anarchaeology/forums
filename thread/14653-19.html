1) Person A opens trade window with person B
2) Person A clicks accept
3) due to lag person B sees the item appear 3 seconds later
4) person B clicks accept
5) the command person B sent is currently in transit, taking 3 seconds until it will hit the server
6) person A during this time thinks that a bug has caused something to go wrong with the trade window and hits cancel
7) the cancel command and the accept command arrives at the server
8) though one arrives before the other, the data each client sent conflict (one accept, one decline). As a result, instead of BOTH being executed (which used to happen, resulting in each person having a copy) the item is instead simply deleted.

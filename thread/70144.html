Actually, AO only has a teen rating. The person opening the account has to be 18, but there's nothing to stop parents from opening an account for their children.

While I agree language filtering should be an option to avoid things like this (and optional on the boards as well, on by default for those who read the boards without an account), there are other ways to handle it in org chat. For instance, when I used to run a mid-sized org (130-140 members before I left), I made it clear to anyone joining that there would be rough language in org chat, and if that bothered the new member they'd be better off with a different organization. Never had a problem because of this.

In org chat, it's really the leader's decision whether to allow potentially offensive language (as it should be) -- in some organizations it's disallowed, some have no policy, and a few such as my own allow/encourage it

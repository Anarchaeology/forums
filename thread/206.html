Skill problems on items/professions
Some skills seem to be improperly assigned to items or to professions

For instanct
if you read the assault rifle skill it says it is associated with NON-ENERGY weapons. Yet there are several weapons that combine the assault rifle skill with ranged energy. According to the description of both skills this is an impossibility.

Also some skills seem to be incorrectly assigned to many classes. For instance my adventurer has aqua mech engineering yet there is absolutely NOTHING the profession can use it for. Likewise the classes that use heavy weapons skill most often (enforcers/adventurers) have very dark blue in the skill.

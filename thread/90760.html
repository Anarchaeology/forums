Would it actually be so difficult to link an item such as "Item Backpack" (Funcom's server named item) with a file on the client computer which had the "renamed" bag name?

As I understand it, an item has a unique ID number in Funcom's database... it also gets another number that's linked with the user that owns it (otherwise, you might open up your implant bag in the bank and get someone else's implants).

Both of these IDs could be correlated with a "bag name list" in the client computer.

If the bag was transferred, the Funcom database name ("Item bag") would be used until the new owner renamed the bag.

In this way there's no real server overload... all the work is done by the client computer.

Ingame Nano Listing
I have been working on a ingame help file listing all nanos for several months. I stopped for a while when Funcom nerfed the /start command in scripts, but since they fixed it, I was able to continue. I think I've got it finished enough now so that it is useful, so I'm publicly releasing it.

http://users.ev1.net/~jesterr/AO/mytools.html

Just target your root hard drive, C:\, D:\ etc, where you have AO installed, and use either the zip file, with "use folder names" option selected, or the Exe file which is a self-extracting zip file, which works mucht he same way. Hope it's useful.

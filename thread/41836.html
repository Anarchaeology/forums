more thoughts...
For using items, perhaps the command could be based on slot number in your inventory. A little weird but probably a lot easier to implement than the alternatives.

I'm going to throw out a laundry list of script commands that I think would be really nice to have, in case this should turn out to be something that can be added easily :-)

(having distinct sit/stand rather than a toggle like 'x' would probably prevent a lot of scripting mishaps)
/sit
/stand

(maybe 'target' instead of 'select', but you get the idea)
/select_self
/select_pet
/select_party <member_number>
/select_player <nickname>

/use_inventory <slot_number>
/equip_inventory <slot_number>
/use_nano <kind> <slot_number>

What would be really slick (but probably a *ton* of work to implement) would be a feature where you could name items in your inventory/etc and have script commands refer to them by name.

Looping constructs and local variables would be a lot of fun but probably to prone to abuse to consider... being able to use stuff like that to script pets would be fun.

hmmm sounds like you had the same problem as me.

after you extract the clicksaver into whatever folder you do go into C:\Program Files\Funcom\Anarchy Online\cd_image\data\db

assuming thats where you installed AO.

In the DB folder you will find 2 files. ResourceDatabase.dat and ResourceDatabase.idx Copy these 2 files into the clicksaver folder where ever you placed it. Then delete the Database part of each the names. So you are left with Resource.dat and Resource.idx

Then open up clicksaver tell it that your AO is installed in this directory. C:\Program Files\Funcom\Anarchy Online Assuming again you use defaults.

And then you are good to go again.

This whole process is supposed to be automated but it appears that the automated process isn't working consistently on systems running win98.

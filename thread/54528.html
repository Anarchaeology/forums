Sign here if you'd like a PvP server.
im not proposing this as an umbrella fix for the pvp situation, as some seem to think when this topic comes up, but rather, a different server for a vastly different taste in gameplay.

im not arguing that pvp sux on rk1-3, and this is the conclusion. I'm simply saying i see/hear SO many people who crave this style of gameplay and a setting on rubi-ka where you only see 0-25% suppression.

If you agree, toss me a bump, if you dont, make a big long post about how this is a stupid idea and you'll gank me in MMD.

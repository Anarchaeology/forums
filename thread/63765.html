Org tags
I played test today and joined an org, I was delighted to see my org's name above our heads, very very cool. I was thinking of an idea to enhance this feature, I dunno if this is already planned or implemented, but whatever. It would be nice if the org leader had a command to change the color of the org's tag, sort of how pet classes can change the color of their pet's names, this would make it easier to pick out different orgs in a crowd and make things generally more vibrant. I do see a problem there, it could get pretty annoying at times, so another good command would be for us to have the ability to turn tag colors off sort of like how we can turn off names.

Cave Type Mapping Project
EDIT: Changed data format to more sensible variant.

I feel a strong urge to avoid those annoying brown caves on my blitz missions. So, I have started a new habit. Every time I get to a new mission, I note down in a text file that I keep open:

Cave type <tab> My lvl <tab> Coordinates <tab> Mission lvl

Eventually, I want to have collected enough of this data to be useful in Clicksaver, helpbot, or in some stand-alone app. Obviously, this will take ages if I do it alone, so if you'd like to start this habit as well that would be an immense help.

One cool thing with doing this is that even if I abandon a mission, I may at least have mapped a new cave, so it doesn't feel like a complete waste of time.

The project depends on a few assumptions, that I have made after reading comments from more experienced blitzers:

* Cave type is always the same at the same location. With the possible exception noted below.

* Cave type may depend on your level or the level of the mission.

Someone more enlightened about these things may be able to correct me in my assumptions.

Eventually, I want to be able to avoid brown caves before I run to the other side of Varmint Woods.

I will put up a web page for the project were people can follow developments shortly.

Don't hesitate to contact Tenfour on RK1 when I'm online with questions or comments.

EDIT:
I should clarify that by "location" I mean coordinates. Sometimes coordinates aren't shown in mission descriptions for some reason, then you have to look them up on the map yourself.

Cave type is determined by these paramters:

0) Location of Mission Terminal
1) Mission Type
2) Mission QL
3) Mission Location (this is not an absolute, it's in "clusters" of nearby locations)
4) Mission pickup item (for those observe item mission)

I can only say for the observe item missions, coz I've done extension testing with this type of mission. Can't say for others.

If u pick the same settings for the above 5 parameters, u can be sure to get the SAME type of cave every time.

Oh.. not exactly the same, but rather, same set of 2 or 3 caves, for one set of the above tuple.

And lastly, mission reward does NOT matter.

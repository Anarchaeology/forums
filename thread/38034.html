Remember "Cherry 2000" the movie?
My latest idea based on a movie I saw quite a few years ago is a servant for characters:

1. This NPC/PET should be no greater than QL1. Upgradeable like a QL 1 /PET. Once destroyed buy damage, all items on the NPC/PET are gone.

2 Should be able to serve drinks/food (Character must purchase the food/drinks first and give to NPC/PET). It should be able to carry items in an inventory that I can view.

3. Should be able to do e-motes and phrases at my command. Like /primp me(combing my hair, dust clothes I'm wearing, shining shoes etc).

4. Should be able to wear clothing/armor that I buy for it. If the servant is wearing armor it needs to be QL1 or of an apropriate QL.

5. I should be able to drop the icons under my knoledge tab on the NPC/PET. Using the NPC/PET as a data base for me or others to view.

6. The servant should be able to follow the character like a pet.

7. The servant should be stored in an apartment(as a butler) and not a bank or inventory.

8. Sould be able to name the NPC/PET as a pet can be renamed now.

9. there should be both male and female models for each kind of race of Rubi-Kan.

10. Idle Banter: I should be able to type in responses to possible questions/statements people might throw at the servant. Like AO does with Player to NPC. Like Alvin/Dodga NPC's.


Any Add-ons?

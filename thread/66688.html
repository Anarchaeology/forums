Originally posted by Roach
I got Clicksaver the other day, and.. No idea what it does. I mean, I have an idea, but.. Could you explain?


I think it has documentation of some sort with it, but here is the basics:
  1. Start Clicksaver the first time without AO running so it can update it's database. You may have to do this twice, there's a bug of some sort it seems.
  2. Now quit Clicksaver and start AO in a window. You can run in full screen, but it makes it much tougher.
  3. Go to a mission booth. Open the mission chooser and set up the type of mission you want to draw.
  4. Start up Clicksaver
  5. In AO, click the "Request a Mission" button.
  6. Switch to the Clicksaver window


You will now notice that all of the missions are shown in the Clicksaver window. You can read the particulars easily there without using all the mouse clics in AO.

I won't go into how to get Clicksaver to search for you, but that is the most important aspect, and worth learning how to do.

Click saver is used for getting missions for exactly what you want.

Example if you need ncus run ao in window mode and open click saver. On CS add NCU to item list (make sure you mission slector is in the far top left hand corner of the screen) run CS and what it does is scan each mission for items with the letters NCU in them, When it finds a item that matchs it stops searching and tells you which mission you need to select.

This is a good tool, since with out it you have to shift left click each mission. and scholl through each 1 to find the items you need. it saves you about 20 mins or more from looking for what you want.

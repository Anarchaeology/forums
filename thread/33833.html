Implanting Others...Doctor Tradeskill?
Can we do this? Can doctors implant another character? If we can do this already, then ignore this post. But so far, I haven't been able to figure out whether or not this is capable from character to character. Of course, a doctor should be able to install implants into another character. I've seen descriptions on items that imply this. But have never seen it done. Please correct me if I'm wrong here...

Of course, a doc could do it using the treatment skill and a surgery kit. They should also be able to use the surgery machine in the shops.

The scenario? Doctor clicks on the med center, picks up the implant from his inventory and places over the character that needs the implant. They get one of three messages: 1. Implant a success! (followed by some XP) 2. Target does not contain a valid [ability] number to use this implant (such as agility needed must be 231 as stated on the implant) 3. Target slot is not empty...please remove the target slot implant before trying again!

I think that sounds like a winner don't you?

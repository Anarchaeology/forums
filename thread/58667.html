There was a time when I thought this problem would never be solved because of the changes required to the funcom database and the storing of dynamic text information. But after thinking on it some more I realized that there is actually a very easy and practical way to solve this problem. Store the labels in a preference file on the local machine the same way hotbar information is stored. The labels would not be transferable and would only work within your inventory, the bank, and the reclaim, but this would still be extremely helpfull and not require changing the database on the server.

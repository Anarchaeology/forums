have to use /follow and pet can't be rooted
We've run into this a lot.

The pet has to be in /follow regardless of inter-zone or intra-zone warping. Because you leave the zone momentarily from the pet's perspective.

If your pet is rooted, we've noticed that it will always be left behind regardless of /folllow.

/follow seems to be the only command that works well all the time. /behind doesn't work all the time.

This also works for when leaving missions/stores/zone, etc.

hope this helps somewhat, even though it is a pain,

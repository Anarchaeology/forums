i dont know why i would help you, but here goes.
Installing a Vid card is easy.


go to

www.nvidia.com

get the detonator referance drivers ( the manufacturer drivers usuallyl suck bad )

Turn off machine. tityally power down. Then unplug machine from wall to let the capacitors discharge.

Get a philips head screw driver ( 99% of the time its phiullips that is )

The card will be ( on a tower config ) usually the top card. Im sure you can line it up visually from where the monitor plugs into it ) monitor plugs in to the machine.

Once the machine is powerd down, unplug the monitor from the computer.

Unscrew the 1 phillips screw trhgat holds the vid card in place ( as i said, usually the top slot, if you are unsure, refer to your motherboard manual to identify the AGP slot )

Pull old card out,

push new card in.

screw card down.


Turn computer on. It should detect new hardwar and ask for drivers.

ignore it., cancel all the thinghs it asks for.. let it get to crappy windows 640X480X16 garbage.


go locate hte file that you grabbed from

www.nvidia.com


run that and it will auto install the drivers. for you.

it will ask you to reboot. do so and you should be good to go. you might have to go into your properties to adjust the resolution/color.

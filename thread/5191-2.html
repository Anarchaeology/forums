The only 2 video drivers I've used for my GF3 are the XP drivers that come with XP and the xp/win2k drivers from the nvidia site. Both result in the same crash. It is a memory leak related to video memory not releasing properly, not system memory. The memory does release over time, but if you zone many times quickly, fly for a while in a llamaha or go in and out of several cities it will usually crash. The game freezes, and if you wait a few min you go to a blue screen and get a series of errors.

Your system then starts a crash dump and at reboot you send an error log to MSFT AGAIN.

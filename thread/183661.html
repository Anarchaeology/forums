Mobs Shouldn't Turn When Stunned
Running my new shade a bit recently. Using brawl (YES it's a waste of IP, so I hear). Few times I've stunned my opponents, run behind them for the backstab and.... there they are, face forward... having turned on a dime while stars are still swimming around their head.

This wants fixing. If someone's been stupified with a punch they're not going to follow you as fast as they would normally. Assume they can't run if they're stunned, so make them not be able to turn.

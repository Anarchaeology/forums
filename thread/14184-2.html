Msag --

Your suggestion that FC needs to run some kind of damage test is a good one. And as others have pointed out, reducing the power of crit buffs might require some corresponding changes, including a weakening of npc mobs, or something to kill besides veterans, which are so optimal relative to anything else (except perhaps frightened rollerats ) it is ridiculous.

However, my argument against crit buff/items is that is an optimal angle available to almost every class, including the ones that are certainly not intended to be primary damage dealers. This breaks down class distinction. It also makes it very hard to make any other changes without causing big imbalances. This is why it is so crucial to change the crit buffs or the crit system -- it will give the game some breathing room to make other changes. You cannot have a good game with an optimal or near optimal angle.

FC has mentioned that they want to weaken mobs for a long time, since for some reason they think it is crucial to retain the ability for each class to solo. Why this is necessary is completely beyond me, given that this is a MMORPG. But that point aside, note how hard this is to do without some change to the crit system. Many things would become far too easy. These two issues stand together -- along with several others.

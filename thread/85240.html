Printable Nano List
Okay, been promising that I would do this, so here we go. Took all the data (including the new nanos) for every single fixer nano, and put it in a print friendly form. Overall, its about 8 pages.

Here are a few formats for people, depending on what kind of system/programs you have:

1) If you are running windows and have microsoft word, click here. Should already be in landscape format and ready to print. No idea if this works with the mac version of word, but its worth a shot.

2) If you're running windows but dont have Word, click here. That file should work with winword, which comes bundled with windows. For this one you *must* set it to landscape (File -> page setup) for it to print nicely.

3) For anyone who either has problems with the previous two or is not running windows, click here for everyones favorite .txt file. Again, you have to set it to landscape so it will print properly. Should work the same way as it does in the previous example.

Use the "highest" one you can. You might have to tab a few pieces of data to get everything set up with the txt one, but for the most part you should be fine.

Ive been working on this all day, and hopefully I havent made any mistakes. If I have, please post here or email me so I can fix them asap.

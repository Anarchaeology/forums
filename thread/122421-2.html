Map Selection
Was anyone else having problems switching between maps VIA the "?" button on the map screen? I was... and after a bit of nosing around I found an awesome solution posted by CZ. In the off chance that someone reading this is having problems I will try to explain it in a way that can be understood by anyone.

The general problem was the .TXT file for the planetmap.bin file is used (among other things) as a pointer to the .bin file. Inside the .TXT file are two sections that point to the location of the .bin file under the directory normal (which is located under Funcom/AnarchyOnline/cd_image/textures/PlanetMap). Before the addition of the "?" button, we all just replaced the two files located here with the map we wanted to use while playing.

SOLUTION:
Create several directories under /PlanetMap and name them for the type of map they will have. On my system I have several directories:
BigMap (the huge map compliments of Nepentheia)
Dovves (Dovves map)
normal (original AO map)
raikosmap (raikos spawn map)
TravelTo (the regular sized map compliments of Nepentheia)

In each directory I placed the map files I wanted to use and then renamed the files (Both of them) to the name of the directory they are in (makes it a bit easier for the next process).

Open the .TXT file in each directory and edit the TWO pointers inside them to the correct directory:
File BigMap\BigMap.bin
File Dovves\DovvesMap.bin
File normal\PlanetMapGfxNormal.bin
File raikosmap\RaikosMap.bin
File TravelTo\TravelTo.bin
(in the huge map, the second pointer is a bit of the ways down make sure you find and replace that second pointer)

While you are in the .TXT file, go ahead and add a name to each map which can be used to identify what map you are selecting. The name goes in at the top of the .TXT file (above the File pointer part) and it will look like this example here:

Name "BIG Map"

And thats it... hope this helps anyone out there who may be having problems with the map selections while playing AO.

Greetings.

If one downloads the latest maps, which were available the same day 14.8 was patched to Live, all the necessary changes to ensure proper functionality with the new Planet Map 'Options' and pathing changes were made to the .txt file, and the .bin and .txt file were placed in a seperately identifiable directory, before being zipped up.

The only thing one needs to do, after downloading and unzipping the 'Huge' or 'Regular' map files, is just move the directory (either 'HugeMap' or 'RegularMap') into the Anarchy Online\cd_image\textures\PlanetMap directory. The link for the map will show up in the 'map selector' window when the Planet Map 'Options' button is clicked (the '?' at the bottom of the Planet Map).

There are a few folks out there, however, who are experiencing some issues with that Planet Map 'map selector' window not coming up when they click on the '?'. This is a rare issue, and has yet to be acknowledged or corrected by Funcom. For more information on that issue, please view this thread, to include a workaround.

Again, all updates to files, to ensure correct functionality with the latest Planet Map changes, which were introduced with the 14.8 patch, are available with the latest 'Huge' and 'Regular' map downloads.

Be well.
